public.literature.search sends the episode's literal query to Europe PMC. The query is search syntax, not instructions to a research agent. Distinguish the scientific question being investigated from each query chosen to find relevant sources. Inspect actual result identifiers and returned metadata; snippets and titles do not establish a scientific claim.

Search by the identifiers, source subjects and terminology relevant to the question. Query revision and source selection belong to the episode and can change after earlier outcomes. No particular query decomposition, database hit count or fixed search sequence is required.

For raw protein input, public.literature.sequence_identity derives a UniProtKB checksum query from subject_ref and verifies the entire returned residue string. The optional reviewed boolean selects curation status, not experimental validity. Omit it to include both reviewed and unreviewed records. Follow next_query to obtain more identities. All equal records on each page remain distinct: the same sequence does not determine a unique source organism. These records provide names and publication leads without supplying an experimental assessment.

source.sequence.references takes the received identity response's source_ref, record_index and subject_ref. It returns a page of citation identifiers, titles and database-reported scopes with continuation. Select citations by the experimental question; acquire their papers and supplements and examine the actual measured construct. A database citation scope or protein description is not a recovered experiment.

Publication queries match indexed text. A sequence printed with hyphens, whitespace, XML markup or line wrapping can be indexed differently from a continuous residue string. Shorter arbitrary substrings need not match longer indexed words. Use the provider's documented wildcard/phrase syntax when generating candidate queries, inspect returned identifiers and then verify the actual source sequence. Never treat a fragment hit alone as full molecular identity.

source.sequence.scan recognizes candidate blocks in a received original or text source window. It returns normalized strings, original byte witnesses, exact containment and any extra residues or literal differences. Whitespace, numbering and soft hyphens are represented as formatting removals. Hard hyphens remain in the string and produce a conditional comparison. After source inspection establishes that particular hard hyphens are layout separators, their exact byte offsets can be supplied as formatting_hyphen_offsets. Alignment gaps, tags, unknown residues and substitutions remain meaningful. A block touching a bounded window edge may require a larger or overlapping window. An absent candidate means no block was recognized in the selected representation/window, not that a publication lacks a sequence or experiment.

An API error is an access outcome. A successful empty search means that query returned no records under the actual service behavior, not that the organism lacks a function or that no relevant publication exists. HTTP 503 reports service unavailability; it does not prove a query is invalid. A retry is an episode choice using the actual diagnostic.

Articles and supplements can repeat one underlying observation. Preserve each representation's provenance and scientific subjects. Shared publication identity or rounded matching values alone do not establish equivalence. Use the existing source-claim equivalence representation when reasoning establishes the same proposition; reading another representation alone does not establish independent evidence.
