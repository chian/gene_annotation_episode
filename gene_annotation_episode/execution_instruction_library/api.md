Service and stored-result operations

Use the actual API binding for remote services and original source readers for
saved results. Moving a lookup or saved-result read to Aurora adds no compute
capacity to that service. Respect provider pacing, continuation and request/job
identity. For asynchronous services return the original handoff and monitor at
an informative time. A dependent native preparation or analysis can have its
own local/Aurora decision; retain its exact input/output links.
