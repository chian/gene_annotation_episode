# Notes for the later episode schema pass

This gather pass changes physical code ownership only. The following are suggestions for a later contract pass; they are not enforced here.

- A parent request should express a proposed annotation, its subject and scope, the scientific goal, and enforceable constraints.
- A grader-defined return should provide typed results, with the original evidence references and qualifications available to its receiver.
- An axis summary should expose annotation-specific earned credit, expected additional credit, waiting and dependency status, scientific contribution, and received evidence references. These fields should stay distinct from one another.
