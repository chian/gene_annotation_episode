# Saved Launch/Results carrier probe

`private_saved_carriers.py` owns the reusable test mechanics for A107 and A110;
the A110 test entrypoint supplies its literal axis. No application implementation
is shared between axes. The helper imports only literal reviewed private factory
paths and uses the selected axis's actual Store, Journal, runtime, method_loop
identity types, binding registry, constructors, receipt manager and archive.

Run capture **before** the Launch split. Run the read/reopen probe against the
same captured directory both before and after the split. The coordinator driver
lives in `runs/hpc_results_private_20261111_a107_a110_preparation/` while this
reusable helper and its inputs live with the tests. Use only the established
single-workflow launcher; the driver adds no execution limits or stopping rules.

Actual boundaries:

- `_run_bound_workflow` constructs all 31 A107 or 27 A110 bindings and publishes
  the original complete descriptor list in both runtime_runs and run.json. A
  controlled exception intercepts the first root build after publication, before
  a provider action. No descriptor row is manufactured or hash field omitted.
- `Workflow.build` creates each of eight Launch/Results child requests with its
  actual source type, full typed request, inherited receipt identity and Journal
  row. `Workflow.on_close` writes the real content-addressed archive and completion.
- A single controlled unavailable tool outcome and cumulative operational view
  enter the saved action/observation frame through actual completion slot,
  observation confirmation and source checkpoint methods. Actual `Workflow.facts` calls the
  original projection once and the actual binding captures its closed carrier.
- The exact original descriptor digest must match the captured carrier. The
  actual binding then reads that carrier without live projection or payload reads.
  The original report remains incomplete and its parent delivery is rejected.
- The later probe instantiates the current literal owner, tests the actual closed
  read and unrelated-context rejection, then attempts both real runtime resume
  through caller factories and real saved-descriptor reconstruction. Each result
  is reported separately. Reaching the pre-action boundary is not iterator replay.
- After successful resume assembly, actual `Workflow.build` reconstructs each
  complete immutable child request, and its actual source restore/checkpoint
  methods recover the original unavailable outcome and completion cursor with no
  unfinished own actions. The rebuilt source reads its original closed credit.
  Initialization remains controlled, and no next action or whole iterator runs.
- Whole logical Store table digests, original run.json, source manifest and archive
  bytes are pinned. Probe attempts must leave saved metadata and run.json unchanged.

Controlled ports and limits of the evidence:

- Ancestor typed requests/receipt manifests are engineering custody frames. They
  do not claim an admitted scientific invocation or executed HPC commission.
- Child assignments are explicit metadata operands. Launch's empty request map
  and Results' subject-reference placeholder are deliberately not native requests.
  Initialization, initial-reference discovery, initial report validation and
  scientific attribution are controlled. This probe proves closed metadata
  custody, not valid Launch/Results admission; the separate connected tests cover
  that boundary using actual plans and full assignments.
- Live projection and live scientific facts are supplied inputs. Three units of
  operational credit are a controlled numeric fixture, not measured progress.
  Completion says false and no scientific evidence is manufactured.
- Full-registry received-report fact aggregation is controlled here because its
  cross-context regression has separate tests. Closed carrier authentication,
  original binding descriptor, archive, receipt prefix and closure checks are
  never replaced. No `as_record` method is patched.
- No controller, native command, model/provider action, HTTP request, remote job,
  scientific interpretation or complete autonomous workflow is executed. An
  unexpected continuation-controller call fails instead of setting a new budget.

Expected baseline: eight closed reads and caller-factory resume reach their
actual boundaries per axis. Saved-descriptor resume may retain the independently
known `private_*_reopen_pending` failure and must report its actual exception.
Any failure before all carriers are captured means no valid complete baseline.
After a split, descriptor conflicts are evidence to resolve, not an excuse to
alias hashes, erase fingerprints or rewrite original receipts/settings.
