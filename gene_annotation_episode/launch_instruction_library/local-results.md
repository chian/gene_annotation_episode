# Local scientific results and failures

General local commands return synchronously with their actual exit status and
captured output. Infrastructure keeps the command's original process identity
and resource controls. An uncertain original outcome is retained as unknown;
recovery must not invent a successful exit or repeat that original action.

A native scientific handoff requires the actual assigned driver invocation and
its original scientific manifest, input/software identities and captured output
versions. An unrelated successful command supplies none of those scientific
facts. The purpose-specific result reader still checks all original native
manifests, numerical outputs, saved sheets and qualifications.

The caller requests either a usable scientific handoff or the declared job
outputs. Operational completion is derived from the original validated
predicates before that action's credit is reported. Scientific measurements and
their evidence scores retain their own purposes and units. The configured
iterator decides continuation using the original credit observations.

The host's selected-command receipt is the source for a receiving episode's
scope and immutable execution identity. Receiving a result does not rewrite the
original launch actions or credit. Native failures retain their complete
recorded diagnostics; missing scientific operands and partial outputs remain
explicit.
