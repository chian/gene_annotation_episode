`run_checks.py launch <attempt>` freezes the whole application and method_loop,
this test/helpers, actual knowledge/launch instruction assets, and the existing
scientific publication. It copies the normal application dependency closure,
interpreter and standard library, and authenticates the original484 native
software binding without reinstalling scikit-learn. `bounded_entry.py` pins
resolved native libraries and records imported modules inside the selected
20GiB RAM/4GiB scratch/zero-swap/no-wall-limit handle. `status` and `collect`
reopen that same original handle. Every actual outcome remains additive.

The optional `--retained-case` launch mode requires the original attempt's
terminal, quiescent receipt and completed case records. It pins those retained
inputs and runs only the corrected saved-sheet assertion path plus independent
numerical/example and allocation checks. Model decisions, native lifecycle
calls, native capture, worker preparation and network calls are denied. It
compares the ten original runtime history tables before and after. It does not
replace the original frozen test results or rerun native fitting.

No passing claim is made by this source trace. Attempt receipts and the final
verification report state what actually completed and any failures or limits.
