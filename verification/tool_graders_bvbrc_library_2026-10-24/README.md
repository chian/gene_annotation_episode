# D6c: BV-BRC Data v2 library information and factual target descriptions

This is the isolated D6c delivery for the current BV-BRC Data contract, sections
9–10 and additive corrections 002/003. It does not declare the full Data API
integration, every live collection, or BV-BRC AppService complete.

The authoritative attachment's objective and entire DESIGN PRINCIPLES block
were read verbatim at the start, after substantial implementation study before
editing, and before handoff. The current contract and corrections were reread
after that final reset. TASK_AND_STEERING was read; recurring prompts and
rendering were not edited.

## Boundaries

The new BV-BRC checks use synthetic Solr/legacy response fixtures, with external
network entry points prohibited. They do not execute a live BV-BRC request,
authenticate, run an AppService job, or establish all-collection native behavior.
They validate real catalog/owner/handoff/result-publication ports but do not
stand in for D6's full Workflow parent admission, recovery, possession,
saved-provider-input and credit/continuation verification. Those are separate
root/082/083 deliverables. Recurring result/receiver TASK/STEERING rendering and
the user's pending template feedback remain outside this delivery.
