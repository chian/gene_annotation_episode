construct a placeholder source snapshot. Defaults still require actual bytes.

received facts for scientific episodes. Forwarding copies exact received cells
and selectors through original parent forms. A changed or unreceived selector
returns `field_not_received`; it cannot acquire or reconstruct another field.
The closed scientific prefix is stored privately in existing `runtime_forms.facts`.
Later child arrivals do not enlarge it. Projection, admission and replay add no
own actions, acquisitions or observations.
