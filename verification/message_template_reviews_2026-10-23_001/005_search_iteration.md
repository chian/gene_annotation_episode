### Concrete gaps the draft must not conceal

1. This role's `decision_context` currently populates source custody only from a page assignment or `source_refs`. A search assignment has `search_result_refs`, so its custody array is empty. It supplies references and the earliest own acquisition/read metadata page; it does not already supply the candidate-paper table. Assigned references alone must remain “metadata not supplied” until the episode actually receives their relevant content. A source reference is not permission to expand inherited raw source bytes into the prompt.
2. Own outcome metadata contains neither selected query arguments nor result bodies. The current decision-exchange own-attempt detail lookup covers **selected inputs only**; outcomes are fingerprints and database locators, not readable older results. The template requires a faithful presentation of actual already-received query/results and admitted page returns, or must state that details are unavailable. The existing ordinary source tools remain available for a selected new inspection; a lookup must not quietly perform it.
3. Removing opaque IDs from readable input while retaining executable `source_ref/artifact_ref/question_context_refs/prior_delivery_refs` operands needs an explicit, deterministic binding to the existing typed JSON contract. The current generic reference schemas and provider serialization do not implement such a readable naming layer. Meaningful titles/publication identifiers alone cannot fill an internal source/artifact reference. Preserve exact operands, scope checks and replay records; do not invent a free-text parser or claim that the draft alone resolves this. A later implementation must make this mapping concrete and reviewable without dumping those IDs into the prose tables.
4. Native search metadata has no normalized, validated organism/construct/condition extraction. The fill must use literal delivered metadata or actual typed source findings and keep other values unknown. No additional model call, inferred scientific ranking, required examination gate or scoring rule fills the gap.
