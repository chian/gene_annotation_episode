not become invented nulls. Full sheets and raw output are excluded from returns.

The boundary checks use real Store, Journal, EpisodeReceipts, BindingContext,
AppServiceCustody and TypedReportContract instances. They check admission before
receipt projection; two recursive scientific forwarding boundaries; exact
original commissioning/form relationships; frozen fields and final forms;
original immediate-child dependencies; actual requirement-source custody;
latest completed publications; type, source, field, function and value
substitution; unrequested/opaque-source exclusion; failed report attempts; and
redelivery without duplicate facts or new completed actions. Repeated reads
leave the database unchanged. A runtime closed-state gate is not added because
typed admission can precede that row's lifecycle update.

boundary tests are deliberately controlled inputs. Their supplied publication
interface is **not** a production download, artifact/hash publication audit or

another native call or current calculator. Root owns the API/execution hooks
and production publication reader. This module performs no acquisition, model
