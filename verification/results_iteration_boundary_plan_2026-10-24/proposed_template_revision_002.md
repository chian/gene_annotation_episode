| Operation or action | Effect | Exact operands | Conditions and limits |
| --- | --- | --- | --- |
{actual_request_scoped_acquisition_status_read_and_wait_contracts}

Select from the actual operations shown. An empty-argument operation uses the
original assignment's fixed selection. A file-read operation must use the exact
assigned path and an allowed byte interval. A path shown here is a real operand;
do not abbreviate or substitute it. Choose no compulsory order or polling
interval. An original job is not resubmitted, replaced, cancelled or moved by
result acquisition. A further page, different metric selection, changed query or
new computation requires the original contract to authorize it explicitly.

Inspect the specific failure before choosing another acquisition. A new selected
same-request read is a new explicit attempt where permitted. Recovery reuses the
original selected action and its saved response; it does not silently repeat an
unknown side effect or repair a mismatched artifact by running the analysis again.
If the required repair has no bound operation, retain the partial result and
specific unavailable information for the original return.

values and actual received basis. Do not invent completion, missing measurements

One completed own acquisition action supplies one local observation. Parsing,
calculation, instruction lookup, result-detail lookup, report construction and
statistical refresh do not add observations. Repeated information earns no new
contribution merely because it was read again. Operational result-acquisition
yield, scientific investigation progress, annotation support, monitoring
information and duration expectations retain separate meanings.

The configured estimator and controller govern continuation. Validated
completion of this original practical assignment sets future expected credit to
exact zero immediately. Preserve the completing action's actual signed gain and
all prior observations; the ordinary controller comparison closes the episode
without another completion statement, model call or zero-gain turn. Yielding with
partial work does not claim that acquisition or annotation is complete.

Return the exact declared structured response. Use `response_type=select_action`
with `selection` and `report_update` to select one actual action, or
