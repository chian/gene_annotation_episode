# Additive selected-transport clarifications

Outside a page/read assignment, each directly read root/concentration/witness/
Km/covariance source needs actual receipt and scientific scope. A separately
received covariance or condition source need not be a descendant of args.source_ref.
Within a page/read assignment, every direct operand must descend from that
assignment's selected page root. Original saved-quantity provenance remains
scoped metadata, not an invented original-source receipt or hidden reacquisition.
The repository and shared LiteratureEpisodes path both enforce page lineage.

Native apparent-Km origin is copied from its authoritative quantity sheet even
when the selected response root has a different declared representation kind.
The source's exact uncertainty kind remains separately visible. Curve contexts
are interpreted source assignments, not a proof from identical quotations.

Parent-visible fact and schema descriptions explicitly define condition_response
as test substrate saturation divided by reference substrate saturation under one
fitted curve. The response may divide an appropriate source effect once; it is
not reliability or target correspondence. No additional typed field or changed
numeric formula was introduced by this clarification.

Canonical curve/quantity hashes remain in host artifacts. Model-facing selected
result metadata and relevant curve-reference records omit those internal
accessions; scientific source labels and requested typed reference meanings stay
visible. Full recurring source-transport TASK survives delta, lookup and provider
restart. The parent keeps its own task after receiving a child form.

The native BtsT controlled example assigns different whole-cell and vesicle
experimental contexts and retains observation_model=unknown. It does not claim
a common fitted Michaelis-Menten curve or use Km±6.4 as covariance. Its cross-
system response and uncertainty remain null while the saved16.5uM Km survives.
No new source paper was interpreted in constructing these selected examples;
they exercise the prior independently reviewed/reset BtsT source relationships.

Transport response is the seventh population family in the existing optional
literature capability profile, not a new axis or episode type. A105 molecular
activity remains separate from A106 perturbation/restoration. Raw transport
trace/isolation/calibration readers and downstream supported effect correction
remain explicit implementation work; no completeness is inferred from h alone.
