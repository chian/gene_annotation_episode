## Existing numerical compilation is real

`LiteratureAssayRepository.populate` already constructs q-g (attributed endpoint rate), u/v (nuisance-condition response), and calls `populate_corrected_activity` for a=(q-g)*v/(k*E*u). The calculator also supplies V=J*C*J^T+distinct_residual_variance, standard uncertainty sqrt(V), precision1/V, and conditional known-normal presence-profile components. Those operations are actual numerical combination, not metadata collection. The optional proposed bounded profile transform is not a function probability or a universal reliability score.

The missing link is source-component composition: this existing writer accepts six raw source point selectors. It does not select already committed optical, calibration, amount or rate cells as its inputs. Its one assay-level organism/construct/preparation/endpoint/input/output context does not establish each operand's scientific relationship to that assay. The existing detailed ASSAY_TASK asks the right questions but literal custody alone cannot establish those answers. A section wrapper around unrelated numeric rows would leave this gap unchanged.

## Compatible operand interfaces

|---|---|---|
| q | optical `net_rate`, in uM/min; assay `net_rate`; native/replicate `reference_rate`, `test_rate` or appropriate `rate_difference` only when physically compatible | Actual net sample-minus-matched-background endpoint rate. The optical endpoint is NADH depletion, not automatically the asserted product. A generic rate difference can compare two proteins or conditions, so it is not automatically a blank correction. Preserve measured and nominal owners behind k. |

## Proposed bounded next workload

Implement one selected within-assay source-activity compilation, consuming explicitly selected *possessed* saved cells and aspect-specific witnessed linkage/stage interpretations. Reuse the existing justified a/V calculation. Start with the six original physical primitive meanings, not a new universal activity/quality model. Its output is a common A105 record with explicit numerical sections and a compiled source-endpoint effect. It is one source-level evaluation, not another evidence axis or episode.

The proposal input shape is in `PROPOSED_INTERFACES_001.json`. Each operand is a closed namespace/sheet/component selector; numerical values are read from authenticated committed outputs, not entered in the operation arguments. The original assay context can come from an actually selected assay sheet and its existing assayed subject, construct, preparation, condition, intended variable, measured entity and asserted input/output bindings. No initial candidate annotation or new universal function identifier is required. Missing asserted input/output remains null; evaluating an endpoint does not establish the functional assertion.

A selected component may be scientifically incompatible while still being a valid source row. Keep it in its original section with its qualification; leave the dependent compiled cell unavailable. Record distinct reasons for absent selected inputs, unknown relationship, known mismatch, unsupported numerical domain and unimplemented conversion. Do not collapse them to source-unreported, zero, one or a numeric quality category.

Stages must distinguish q already blank-corrected, calibration already applied, molecule amount denominator already applied, and nuisance-condition correction already applied. Do not double subtract/divide. Unknown stages remain unknown. A justified mathematical identity after an already applied correction can be represented explicitly as an algebraic identity with its source-stage meaning; it must not be presented as a measured control or an imputed missing value. An already active-normalized rate has different units and should retain its native result; forcing it back through a raw q/E route is invalid.

At population, dependency closure must include source component identity AND actual underlying physical measurement owners. For example k depends on measured and nominal standards; q can depend on optical sample, blank, epsilon and path length; active amount has its own titration/concentration basis. Six new aliases do not make these independent. Unknown cross-component covariance remains unknown. Preserve usable corrected point arithmetic with unknown variance where scientifically supported; do not require a universal covariance producer before preserving that partial result. A supplied covariance source must name the exact canonical ordered owners, compatible units, status and scientific basis. A distinct residual variance must be source-supported and additional, not uncertainty already present in those owners.

## Numerical sections and output

- Measurement: copied requested native q,g,k,E,u,v components, quantities and qualifications.
- Validity: recovery/bias/precision control rows and their genuine applicability; no universal validity grade.
- Comparability: the supported nuisance-condition ratio; the intended change is excluded.
- Attribution/normalization: q-g and the appropriate molecule/site amount basis, retaining unresolved mixed contributors.
- Uncertainty/replication: propagated V, sqrt(V),1/V when supported; actual unit/replicate information retains its existing meanings.
- Compiled source-endpoint effect: a with explicit formula and dependency closure; model-specific profile components only under their actual declared model.
- Functional discrimination: preserve appropriate existing assay-specific comparison rows; no common numerical result is invented for binding, catalysis and transport together.

These are sections within one logical A105 sheet and can contain repeatable assay records. Their shared ownership/dependence is explicit. The copied source rows are needed but are not alone the numerical compilation; the saved a/V cells provide the concrete within-assay compilation.

No scientifically justified cross-assay grand total follows from this code. Units, endpoints and functional resolutions differ; measurements can overlap or complement rather than replicate. Combining likelihoods would require an appropriate common assertion and joint observation/dependence model. Do not add unlike magnitudes, average category weights or multiply normalized aliases. The unfinished whole-A105 scientific design remains visible; this bounded implementation does not declare it complete.
