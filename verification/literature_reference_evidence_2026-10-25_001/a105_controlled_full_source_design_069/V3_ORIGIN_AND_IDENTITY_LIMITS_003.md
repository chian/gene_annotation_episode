# Additive v3 origin/identity limit003

002 is an interface proposal, not evidence that a mixed representation group
already has an accepted origin or source reading identity in068. The original
068 Arm has one origin and one source_observation_id. It has no union-origin
or companion lineage field. A new source-v3 writer may not hide that limitation.

The proposed nonnumeric ambiguity mask is usable only when the writer has a
declared, reviewed origin projection and can reconstruct its reading-group
identity from actual authenticated source outcomes. `graph_derived` in002 is a
proposed conservative group classification preserving graphical participation;
it is NOT permission to relabel a selected reported point, assert successful
graph measurement, erase a synthetic origin or enable a model. The actual
individual origins remain in every retained extraction. If the group contains
incompatible/unrepresentable origins or its identity cannot be authenticated,
the writer must report a specific unsupported origin/group-identity projection;
it must not feed a guessed origin or arbitrary string to068.

The engineering partial fixture uses an explicitly HAND group ID. It establishes
that068's existing numerical algebra preserves unaffected components with an
ambiguous active operand; it does not prove the future writer can produce that
operand with authentic custody or scientifically settled group-origin semantics.
No claim of complete v3 source/native implementation follows.

The v3 extraction declaration now makes the partial projection state explicit:
not_required, ready, unsupported_origin_projection or unavailable_group_identity.
partial_calculation_inputs is nonnull only for ready. It remains null for an
unsupported projection; this does not erase retained primary/companion source
rows. Those rows retain usable native magnitudes, spread/count and original
science. Explicit supported JOINT alternatives can still provide conditional
unaffected cells without a group mask; no unsupported joint combination is
invented. If neither a valid group projection nor a supported joint assignment
exists, the future native partial-source view must preserve and deliver raw
source-native rows and independently established local pairs. That view must
use only each component's actual dependencies, with no invented full-sheet input.

Implementing that last component-local population path and its closed native
partial view is REQUIRED v3 work, not a completed capability of068 or a reason
to drop unaffected results. Its fresh release must declare its exact parsed
input/output and separately populating function before coding. A broad call to
the whole pure sheet on dummy values, unsupported origins or an arbitrary
primary-only joint choice is not a substitute. Tranche S's exact v2 source work
does not depend on settling this unimplemented v3 branch. Root can release S
after reviewing its coherent interface while retaining v3/native completion as
required subsequent work.

The actual active source-authority/reconciliation model remains unadopted.
002's conditional arithmetic and closed shapes supply concrete review material,
not scientific resolution, primary evidence, native integration or typed delivery.
