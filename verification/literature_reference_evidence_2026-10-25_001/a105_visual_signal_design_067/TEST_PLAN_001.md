## Pure extraction and numerical meaning

- A visual-only printed ratio/percent/pair works with no invented JATS paragraph.
  A paired literal0.60/1.00 produces0.60,-0.40,ln(0.60). A printed60% produces
  the same ratio by its separate declared percent transformation.
- Callbacks receive every declared dependency, including unreadable regions
  and semantic witnesses, before helpers. Real authorization/PermissionError,
  malformed callback and unexpected provider/programming failures propagate.
  Explicit availability failure affects only dependent rows and keeps valid
  independent source readings. Same artifact handle/different bytes rejects.
- Exact UTF8 quote boundaries, Unicode characters and JATS Unicode expression
  offsets retain their actual coordinate systems. Clipped tokens, omitted
  inequalities, mismatched quotes and wrong source selectors cannot produce
  an exact point. Unsupported syntax is an explicit capability partial.
- Actual native image metadata must match displayed/source/original artifacts,
  selected frame, dimensions and stored-axis orientation. Cover a selected TIFF
  frame, explicit RGB conversion and original JPEG displayed as PNG; avoid the
  old binding-helper single-frame PNG/JPEG assumption.
- A forged/global view, another episode's unreceived view, inherited source
  reference without own viewed-image custody, changed frame/artifact, invalid
  region or mismatched native action receipt rejects before text interpretation.
  A known earlier own view remains valid after another ordinary action; no
  compulsory immediate-prior-view rule is added.
- Unreadable labels retain real viewed regions with null fragment text. Exact
  plus unreadable preserves known0.64 but withholds a complete scalar. Ambiguous
  candidates0.60/0.80 remain alternatives, not independently measured repeats or
  automatically contradictory experiments. Exact duplicate nominations cannot
  satisfy ambiguous/conflicting cardinality.
- The same reported quantity displayed as1.00 and1.12 yields a source
  representation conflict. Separate experiments yielding0.60 and0.80 instead
  retain different_reported_quantities, no false contradiction or pooling.
  Unknown source linkage does not silently become supported.
- Pair alternatives stay joint; do not form unsupported numerator/denominator
  Cartesian combinations. Known different scales retain both primitive values
  and no normalized ratio; unknown scale stays unknown. Already-normalized
  ratio/percent need no fabricated common raw-scale finding.
- Printed0/1 gives r0,difference-1 and an unavailable log, while ND without a
  supplied numerical threshold gives no inferred zero/limit. A zero or
  unestablished-positive denominator never becomes1.
- `<0.10`/1 keeps ratio[0,0.10), difference[-1,-0.90) and the positive-branch
  log domain. Test strict/non-strict endpoints, outward finite projection,
  unbounded ends and nonfinite/underflow rejection. These are reported-estimate
  domains, not true-amount or confidence bounds. Preserve exact decimal-rational
  originals; do not use rounding tolerance to erase a real source difference.
- A raw negative, unknown abbreviation or compound ± expression outside this
  finite route retains its literal and a capability partial, never clamping or
  an invented SD/SEM/CI. Report the numerical-uncertainty-reader gap explicitly;
  do not claim the paper was unreported merely because no parser is implemented.
- Duplicate exact source-reading locators keep aliases and one arithmetic
  reading. Equal values at distinct locators do not establish physical identity
  or independence. Shared reference identity remains separate from biological
  replication. No count, variance reduction or reliability bonus is generated.

## Saved output, selected native work and typed return

- A new selected native operation in an actual LiteratureEpisode consumes its
  own received source/view custody and commits request/extraction/calculation/
  bindings/sheet/outcome atomically. No human-created numerical JSON dataset is
  necessary. Literal image nominations remain attributed episode interpretations.
- Same key/different arguments or scope fails; repeated same work replays the
  saved outcome. Forbid original paper/image bytes, source parsers, decoders and
  calculators on replay. Recheck receipt/ancestry metadata without new science.
- Saved-read validation checks selected output membership, immutable owner,
  source/provider/version, request/selection, complete output/cell identity,
  extraction associations, source/view rosters and binding relationships. Test
  forged status, value, candidate/domain endpoints, missing reason, source kind,
  construct/reference owner and scalar completeness flags, not only value edits.

  subject/construct/endpoint/reference/arrangement/signal-use qualifications.
  Requested numeric subsets remain exact. Unknown and conflicting identity both
  use null bindings but keep different meaning_statuses. The model cannot
  author recorded numerical cells or gain new fields by report prose.

  old v1 runs keep their original operation/return meanings. All existing
  operations, return views, roles and permitted child relationships remain.
