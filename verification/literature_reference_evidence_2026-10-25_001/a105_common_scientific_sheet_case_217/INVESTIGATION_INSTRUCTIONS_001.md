## Aspect-specific interpretation outputs

An interpretation step selects scientific meanings, not numbers to use as confidence. Each answer uses source/supplied-model witnesses, closed allowed values and `unknown`/`conflicting` where applicable:

1. **Functional resolution:** `identified_product_formation`, `saturation_turnover`, `low_substrate_efficiency`, `binding_occupancy_alternative`; select the actual subject/construct/chemical-event witnesses. Do not silently promote one resolution into another.
2. **Endpoint link:** `direct_product`, `reporter_requires_conversion`, `binding_addresses_occupancy`, `alternative_product`, `incompatible_scope`, `unknown`, `conflicting`. Select relevant quantity/source selectors. A link is not a numerical relevance score.
3. **Arrangement and isolation:** `separate_alternative_P450_arms` versus `coexisting_P450_forms` versus `unknown`/`conflicting`; list actual partner witnesses. Control role `same_scale_other_contribution`, `already_subtracted`, `different_endpoint_or_basis`, `unknown`, `conflicting`; never set background zero from “purified.”
4. **Binding-model applicability:** per relationship `supported`, `stipulated_sensitivity`, `unknown`, `conflicting`. The model's one-site equilibrium, free-substrate, temperature/preparation transfer and equal-other-response assumptions are separately selected; none is collapsed into an overall C.
5. **Uncertainty population:** `raw_reading_SD`, `estimate_covariance`, `fit_parameter_spread_unspecified`, `plotted_triplicate_SD`, `unreported`, `conflicting`; preserve actual scopes and source labels. Calculator decides supported arithmetic, not a model-composed SE.
6. **Evidence relation:** several simultaneous finite meanings permitted: `same_measurement_view`, `shared_primitive`, `shared_sampling_unit`, `independent_units_supported`, `complementary_endpoint`, `same_estimand_disagreement`, `unresolved_scope`. A source row or distinct number is not evidence of independence.
