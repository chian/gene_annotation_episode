# Source-aspect decision/information trace

This additive record applies to the caller-enabled literature experimental
profile. It does not claim the goal or scientific extraction is complete.

1. The assigning parent supplies its actual goal, source/question references,
   scoped material and requested typed form through the original commission.
   No parent history/yield or new construction slot is supplied.
2. LiteratureEpisodes supplies its existing role instructions, actual catalog,
   assignment/source custody and the declared experimental presentation marker.
   Its permitted child relationships remain unchanged.
3. The existing provider presentation state reconstructs an authoritative
   bootstrap/update or continues an explicitly requested same-decision lookup.
   The current state is kept, not a second action history or conversation.
4. The literature-specific pure renderer supplies the full actual source TASK
   every call. It retains scientific distinctions, scope, available decisions,
   actual operation input contracts and parent return meanings. Numerical
   sheet implementations, private histories and tracking metadata are excluded.
5. STEERING selects own category yields/expectations/uncertainty, actual selected
   source results/locators, numerical values with their units/limits and source
   qualifications, actionable failures, admitted requested child cells and
   explicitly requested lookup information. Source material is evidence, not
   instructions. No blanket state or source inventory is serialized as context.
6. The same existing provider sends TEXT input and its unchanged output schema.
   Original structured request/context remains saved for authoritative replay.
   Rendering adds no model call, acquisition, calculation, action or observation.
7. The parent's own task remains its own; the child's typed measurements retain
   their source-specific meanings. No target-transfer or combined credit is
   calculated by this renderer.

The renderer's pure checks and controlled native-turn transport checks cover
complete task repetition after delta, lookup and restart; restored answered
lookups without transcripts; preservation of selected source uncertainty and
censoring; input immutability; exclusion of unrelated inventories and host
bookkeeping; enabled-only rendering; and preserved scientific rendering.
These are controlled transport checks, not an actual model-backed investigation.

Original-paper quantitative extraction is the next separate boundary. The
existing normalized CSV/TSV operation does not establish that source interpretation
or numeric operand nomination is already implemented for primary-paper prose.
