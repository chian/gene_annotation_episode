source.read takes a source_ref and a selected representation. It returns an exact artifact and UTF-8 byte range suitable for a textual scientific anchor. Preserve the actual quote and coordinate frame. Original XML and its paragraph projection are different representations; an offset in one cannot be used for the other.

For a PDF, source.pdf.info exposes physical page information. source.pdf.text extracts one chosen physical page using the selected reading_order, layout or raw mode. Extracted text is a derived source with its own UTF-8 byte coordinates; these are not original PDF byte positions. The current local parser uses Poppler. This entry does not claim PyMuPDF or OCR is installed.

source.pdf.page renders a selected physical page into a retained image. image.view explicitly supplies a selected frame's pixels to the next reasoning call. Rendering alone does not deliver those pixels or interpret a figure. A visual observation uses its actual image view and pixel region; it is not a literal text extraction or a performed experiment.

Different representations can expose different useful information. The episode can inspect outcomes, change approach, or delegate a substantive iterative reading question. A one-off page extraction remains a tool call. No fixed parse strategy, full-document reading requirement or coverage threshold is imposed by these instructions.
