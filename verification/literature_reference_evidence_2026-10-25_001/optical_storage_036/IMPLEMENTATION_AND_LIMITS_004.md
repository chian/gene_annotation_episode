## Ownership, state and communication

Every new source/representation read requires actual episode receipt and the
existing Store scope/assigned-page ancestry check. Exact original/text selection
is preserved, without fallback acquisition. Original selection, complete035
qualified/raw observations, origins, covariance source/data, canonical inputs,
033 output cells, measurement/physical/semantic keys and local reuse aliases
remain saved. Local aliases do not establish global identity or independence.

Request signatures bind run, episode, selected operation key, source selectors,
scope, original assignment and requested subset. Source payload/request/bindings
and the selected outcome publish atomically. Saved reads authenticate the actual
original operation table association, signature, outcome and immutable binding
definitions; a provider label alone cannot manufacture selected work. Exact JSON
comparison rejects bool/number substitutions and malformed/nonfinite cells with
deliberate ContractError results. Authoritative saved cells are not recomputed.

Each required closed optical return field has a declared type/enum/reference
meaning. Unknowns remain explicit. The source endpoint, subject/construct/
preparation/condition, reporting qualification, relationships, covariance status
and origin, and dependency meanings survive the return. Raw numerical operands
and the full covariance matrix are not automatically added to the requested
q/Vq subset. The approved004 measurement_source_ref field preserves only the
source identity needed to keep missing-anchor withholding bounded.

An owning episode may project its own selected sheet. A literature parent
forwarding a child's sheet uses only its actual admitted cells, filtered by the
current requested subset. Global sheet presence or a shared run does not let it
expand an unrequested cell. Actual strategy-grandchild → literature-parent →
annotation-parent checks exercise this path.

Received subsets have an immutable digest association. Actual runtime
run:episode:index:typed_form receipts additionally authenticate the exact cells
against their original runtime_report_attempts contract/form. Forging a receipt
body and its digest still cannot manufacture a different runtime-admitted subset.
Standalone repository receive_cells calls are an explicit trusted caller API,
whose admitted call is bound by its digest; they do not independently prove that
a runtime child commission/form existed. This distinction is intentional and is
not represented as uniform runtime authentication for manual repository calls.

## Observation and replay behavior

Publication, validation, arithmetic, rendering and receipt bookkeeping create
no scientific observations/assessments or synthetic controller observations.
One completed selected action has its ordinary observation; failed attempts
retain feedback without a completed observation. A parent receives its original
commission's contribution once, rather than one observation per child input or
internal calculation. Source q/Vq representations earn no independent progress
or annotation credit by themselves. Configured continuation is unchanged.

Saved-only reopen, idempotent original selection, projection, forwarding,
original closed C4 admission and repeated admission use existing saved facts and
metadata. Tests forbid source artifact reads,035 source population, native numeric
parser calls and033 calculation in those paths. Detached037 checks validate
already saved numerical/identity relationships; they do not reopen source
neighbours or re-establish scientific truth. Repeated C4 admission preserves the
original controller input without repricing, receiving again or calling a model.
Interrupted publication/admission transactions preserve valid prior work and
roll back incomplete authoritative publication/receipt state.

## Factual renderer and limits

Actual controlled provider turns check rate-only and variance-only returns with
distinct raw and canonical operand numeric sentinels and distinct derived q/Vq
values. The full unrequested scalar string must be absent anywhere in actual
receiving TASK/STEERING, not merely absent from a named table row. Tests include
both existing marked literature and source-evidence-parent rendering, actual
nested receiver contexts, broad/partial-overlap anchors and off-page numerical
measurement records mixed with another source's typed scientific reference.

Known-token overlap withholding is bounded by source/artifact custody. Missing
token anchors permit conservative withholding only for their declared optical
source, using actual anchor.source_ref. Unrelated-source scientific information
stays visible. Original records and explicit permitted later source.read access
remain intact. If a broad or off-page source definition cannot safely expand,
the factual view says that its source-bound witness remains available for scoped
access. Original amount subset behavior remains in its existing path.

This is automatic expansion control at the existing marked renderer boundaries.
It does not redact arbitrary caller TASK text, model-authored interpretive prose
or explicitly selected source reads. Other unmarked/generic renderer routes are
not claimed newly corrected or scientifically validated here. Source-kind and
scientific relationships remain supplied meanings; custody validation does not
prove experimental attribution, matching, linearity, covariance truth or the
source's scientific validity.

Store scientific source records are reusable and currently do not carry target
roots. Actual receipt and assigned-page ancestry tests use the ordinary Store.
The separate source-scope rejection test explicitly injects the reference-subset
guard to exercise the repository's scope port. It is not evidence that Store has
target-specific paper-source restrictions that it does not implement.
