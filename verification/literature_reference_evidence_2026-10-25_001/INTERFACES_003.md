# Additive runtime and return contract

The source rate operation is now available through an explicit caller binding:
`LiteratureEpisodes(services, rate_population=True)`. This selects a finite
capability profile; it adds no runtime reviewer, acceptance gate or stop rule.
Default binding catalogs retain their existing choices.

`literature.rate.populate` consumes one selected, received retained CSV/TSV
representation, with exact source subject/experiment and comparison operands.
Its schema is `rate_population_schema()`. It executes one ordinary own action.
There is no acquisition call, private model loop, controller update or parent
report composer inside this operation.

`WorkflowServices.literature_rate_repository()` binds the new adapter to this
application's existing Store and run identity. A source must occur in the
episode's actual receipts, not merely in shared state. Selected operations save
their exact signature and original outcome; replay returns that outcome without
reparsing or refitting. Complete structured sheets are immutable source artifacts.

The recorded top-level form source is `literature_rate_cells`. Parents select a
subset through `requested_rate_components` in the ordinary literature assignment.
Each returned cell has:

- Saved sheet and original evidence source references.
- Typed references identifying assayed subject, experiment, reference and test
  conditions, endpoint and normalization.
- Component identifier, numerical value/null and exact unit code.
- Availability status, unavailable reason, origin and required statistical
  conditions. A populated conditional statistic is not an annotation probability.

Source subject/experiment references denote the source's stated experimental
objects. They do not establish a target match, sequence, construct completeness,
chemical product identity or molecular activity that the input does not measure.
Source tokens and full raw rows remain in the retained extraction.

The ordinary form boundary validates numbers and their experimental references
against saved cells. Syntactically valid altered values are rejected with a
structured ReportBoundaryError. The original child commission context is frozen;
at admission, its later own records are authorized from that same child's durable
receipt selection, with run/episode identity checks. Global records are not an
authorization fallback.

Admission records exactly the requested cell subset for the receiver. Later
forwarding copies those admitted cells; receiving a sheet reference does not
silently deliver its other private cells. Full retained evidence remains
available for separately scoped later access. Exact repeated cell deliveries
do not create new statistical or scientific contributions.

Source facts created by an operation are distinguished from existing facts it
reuses. Neither bookkeeping nor source-sheet construction is automatically
projected as scientific progress. The existing credit projectors and method_loop
controller remain unchanged.

## Still required

The normalized CSV/TSV representation is one finite extraction boundary, not a
general original-paper reader. Source prose/figure interpretation and the
aspect-specific TASK/STEERING presentation still need an installed path and
verification. Primary-source and actual model-backed demonstrations remain open.
Other A105 experimental families, attribution/comparability components and the
other appropriate literature responsibilities remain unfinished.
