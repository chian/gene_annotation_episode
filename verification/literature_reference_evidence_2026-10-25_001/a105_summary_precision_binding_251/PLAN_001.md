## Proposed exact interfaces

The formal declarations alongside this plan are SELECTED_ARGUMENTS_SCHEMA001,
REQUEST_ROSTER_SCHEMA001, RETURN_ROWS_SCHEMA001 and OPERATION_UNION_SCHEMA001.
The four ORIGINAL_*_SCHEMA001 files are exact copies of root-reviewed selection002
and extraction/input/sheet004. They are interface copies, not replacement goal
authority. The plan generator calls only the existing legacy argument-schema
factory; it does not call the new248 modules, a scientific reader or calculator.

Use the EXISTING `literature.kinetic.populate` operation with the explicit new
`version=literature_kinetic_summary_precision_population_v1` wrapper. Its fields
are exactly version, selection, requested_cells, return_context. Selection is
the complete unchanged pure248 selection. requested_cells is an ordered unique
roster of `source_<cell_name>` or `scenario_<cell_name>`, all15 names available
in each population. No unselected scenario is manufactured. A scenario row
request with selection.scenario=null fails specifically rather than creating a
conditional model or copying an ordinary value into a scenario namespace.

The assignment field is `requested_kinetic_summary_precision_components` with
the same closed roster type, optional for legacy assignments and defaulting to
[] in adapter semantics. INITIAL actual requested_cells must equal the actual
assignment roster in order. Empty means no numerical rows. Later nonowners
forward the desired-order intersection of their request and actually admitted
rows; unavailable requested rows remain rows and are not dropped. Knowing a
sheet identity grants no additional cell or source access.

The return is one registered `literature_kinetic_summary_precision_cells`
array. Every row has a unique sheet_ref/component identity; source/scenario
population, cell_name and formula are structurally bound to that component.
The nested `cell` is the exact named reviewed cell schema, with its status,
unit/numeric domain, qualification, reason, origin and declared assumptions.
Each named cell retains its original formula. Source and scenario facts never
merge, even when the numeric value is identical. Counts, proposed confidence,
df and quantile remain dependent calculation information, not experiments.

The row schema keeps the original sheet's $defs verbatim at the standalone row
resource. Every copied cell-local #/$defs pointer has the same referent. The
communication adapter validates the registered row resource separately before
validating the enclosing parent form, and semantic reference walking uses that
same resource. The original full sheet is separately saved/validated as its
own standalone resource; it is never pasted under an enclosing parent path.
No generic report grammar keyword or unrestricted-string permission changes.

## Narrow scientific context and prerequisites

return_context contains explicit UTF8 byte windows for the11 already selected
subject/context roles. All roles are required arrays; [] requests no text.
Each window must lie inside its role's authenticated existing witness. Return
fragments retain exact text and locations, without a generated summary. The
adapter rejects windows overlapping any selected parameter, SD/SEM/CI endpoint,
count, separately selected statistical count or reported confidence selector.
The full meaning witnesses are retained only in private saved extraction. Broad
source witnesses are never automatic context returns. Unselected source facts,
scenarios, statistical counts, interval parameters/endpoints and other section
metadata cannot expand through a sheet/payload/request alias. Public original
source reading remains explicitly available through existing source operations.

Rows carry only the requested numerical cell, explicit narrow context, scientific
sampling basis, component-relevant model condition STATES (no witness quotes),
shared-contribution qualification and actual selected dependency locations.
`withheld_locations` are host suppression operands, never rendered as science.
Dependency locations retain source/artifact/representation/offset identity,
without unrequested operand magnitudes or source-exact rationals. No complete
covariance matrix, full input snapshot or raw measurement roster crosses.
All source/scenario rows share the physical-estimate contribution identity;
unknown independence/systematics remain unknown. A mean variance is estimated
random precision, never known population covariance. No covariance=0 is added.

The exact formula/prerequisite order remains the reviewed pure248 contract:
parameter and SD scales are independent; missing X does not erase S or n;
mean variance S²/n and SE require owned applicable exact n>=2, sample n−1 SD
and IID common-mean finite variance, without normality/central mean identity.
Relative SE additionally needs the supported equal-weight central mean and
nonzero X with matching dimensions. df additionally needs interval selection
and sample convention; proposed.95 only its selected calculation request;
t additionally IID/normal units; halfwidth additionally positive SD/mean SE;
only endpoints additionally require the central mean. Reported SEM/CI stay in
the full authenticated original extraction and are not inverted. Unknown or
conflicting parameter kind retains all original extraction and eligible count
partials with exact004 reasons, and supplies no guessed dimension.

Model condition states returned per cell are selected by a finite dependency
map, never all8 automatically. Counts expose row applicability/count ownership
conditions only where actually used; variance/SE add their sample/IID model;
relative SE/endpoints add mean identity; t/halfwidth/endpoints add normality.
The optional scenario's conditional_on/stipulated_assumptions lists remain
the exact calculator cell lists, not a global scenario dump. Missing/conflicting
conditions preserve valid cells and precise reasons. Invalid custody/unknown
fields/formula-unit mismatches are structured failures through the existing
ExperimentalContractError/ContractError route.
