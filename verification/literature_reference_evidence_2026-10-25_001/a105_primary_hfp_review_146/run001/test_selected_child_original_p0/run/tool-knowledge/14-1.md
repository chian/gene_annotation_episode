public.literature.search sends the episode's literal query to Europe PMC. The query is search syntax, not instructions to a research agent. Distinguish the scientific question being investigated from each query chosen to find relevant sources. Inspect actual result identifiers and returned metadata; snippets and titles do not establish a scientific claim.

Search by the identifiers, source subjects and terminology relevant to the question. Query revision and source selection belong to the episode and can change after earlier outcomes. No particular query decomposition, database hit count or fixed search sequence is required.

An API error is an access outcome. A successful empty search means that query returned no records under the actual service behavior, not that the organism lacks a function or that no relevant publication exists. HTTP 503 reports service unavailability; it does not prove a query is invalid. A retry is an episode choice using the actual diagnostic.

Articles and supplements can repeat one underlying observation. Preserve each representation's provenance and scientific subjects. Shared publication identity or rounded matching values alone do not establish equivalence. Use the existing source-claim equivalence representation when reasoning establishes the same proposition; reading another representation alone does not establish independent evidence.
