public.literature.read requests full text for an actual PMC identifier. Retained source records identify the received representation. The ordered paragraph projection can omit headings, XML tables and other content. source.read with representation original exposes the retained original bytes; text selects the projection when available. An omitted table in a projection is not evidence that the article contains no table.

public.pmc.versions lists actual advertised source versions without selecting one as latest or preferred. public.pmc.files inventories a selected version_ref and its metadata. public.pmc.asset acquires one advertised/listed asset_ref. Use returned identities rather than guessing file names or download URLs. Follow explicit continuation information when more listing pages are useful.

File listings, article versions, supplements and quoted observations keep their separate identities. A metadata acquisition failure can leave usable listed objects. Missing full text is an access limitation, not a judgment about a source or permission to invent its results. Choose a different available access or reading approach when it could answer the question; there is no mandatory fallback chain.
