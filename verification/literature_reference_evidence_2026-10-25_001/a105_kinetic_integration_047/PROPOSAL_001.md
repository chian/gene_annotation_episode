## Detached saved validation and authentication

The new validator has no original-source callback, parser, calculator, model,
Store or controller. It checks closed saved shapes, finite/type-strict fields,
the045 canonical input contract, exact selection-to-enriched-witness binding,
source-token byte locators, per-role canonical projection/qualifications,
uncertainty representation, source rosters and the literal/formula/metadata
relationships that can be checked without re-running the scientific reader or
arithmetic. It returns detached copies and repairable finite error codes.

Repository `read` separately authenticates original selected operation/signature,
request/payload content identities, exact outcome snapshot, provider/version,
immutable meaning-record identities and actual source metadata/ancestry. It
never reads original scientific artifacts. The original content-addressed
selection/extraction/calculation and outcome prove what was saved; the read path
does not recalculate an estimate or reinterpret the paper. Changed True/1,
nonfinite values, reassigned source/construct/physical owner, artifact bytes,
operation owner, request, cell or meaning binding must fail deliberately.

## Closed native typed return

`kinetic_cells_schema()` is an array of closed rows. Proposed common fields:

    sheet_ref, evidence_source_ref: source references
    component: one of the five native components
    value, threshold: finite number|null
    unit: uM|per_min|uM^-1min^-1|dimensionless|null
    status: populated|unavailable
    relation: eq|lt|le|gt|ge|none
    approximate: boolean
    origin: reported|calculated|synthetic|derived
    unavailable_reason: frozen045 finite reason|null
    formula_code: finite native formula identifier
    conditional_on: frozen045 finite prerequisite codes
    evaluation_scope: source_kinetic_parameter_contrast
    contrast_meaning: numerator_parameter_exceeds_denominator
    model_input_status: not_supplied_by_native_operation
    model_reader_capability: unimplemented
    comparison: five closed finite meanings + witness_refs
    numerator, denominator: closed role metadata below

Each role retains parameter kind (including unknown/conflicting), canonical
dimension, source/canonical status, qualification, approximation, source origin,
converted origin, specific unavailable inputs and references for its token,
source unit, physical observation, subject fields, context fields and source
uncertainty. Missing references/meanings are explicitly null with finite reasons.
Token metadata includes its actual source_ref for safe off-page withholding;
host hashes/source offsets do not become model-facing text.

Uncertainty means statistic, repetition basis and estimate basis remain visible.
Its magnitude/CI/count/level witnesses remain source refs. Numerical uncertainty
is included only for the corresponding explicitly requested raw parameter
component; all other role-number fields use a finite `not_requested` status,
not `unreported`. For example a ratio-only return does not silently deliver
both raw parameters, their spreads or counts as metadata. Requesting the
numerator parameter returns its own normalized uncertainty and actual statistic
without turning SD into SEM, a CI into halfwidth or a count into independence.
Derived uncertainty remains outside this native-only route. This conditional
typed shape must be validated against its exact saved component projection.

Only public native cells are projectable. The final044 `fact_cells` allows own
selected saved cells and exact child-admitted subsets; `validate_fact_values`
also rejects a hand-authored outgoing superset. Runtime receive authenticates
the original form/contract (or actual revised selected delivery) separately from
outgoing possession. The new route inherits that machinery, including view
identity, idempotence, old-state limitations and read-only reconstruction.
