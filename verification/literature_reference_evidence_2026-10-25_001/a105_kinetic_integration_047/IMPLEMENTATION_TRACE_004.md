# Selected native kinetic operation: implementation and information trace

This adds one selected component operation inside the existing A105 work. It is
not an additional scoring axis, a complete experimental grader, or the deferred
paper-to-grader router. A literature episode still decides which experiment and
source meanings matter. No scientific TASK constant was added or changed.

## Selected operation and durable state

1. Existing opt-in LiteratureEpisodes exposes literature.kinetic.populate as its
   eighteenth population operation. All first seventeen descriptions and schemas
   are exact. The source/scoped child assignment supplies optional
   requested_kinetic_components using only the first five frozen045 components.
   This is ordinary selected work in shared method_loop, not a new episode kind.
2. Existing execute dispatch calls the lazy kinetic repository service. The
   repository authenticates run/episode/operation identity and retains the exact
   original scope, assignment, requested components and046 source selection.
   Its callback authorizes each actual received source and assigned page ancestry
   before046 reads original/text bytes. The selection contains witnesses and
   interpretations, not supplied scientific numbers or covariance.
3. Frozen046 reads the source once; frozen045 populates the native contrast with
   no model. The new detached validator authenticates selection/extraction/input
   associations. It does not parse a paper or independently reinterpret it.
4. One Store transaction publishes source-bound references, exact request and
   saved payload artifacts, the kinetic source record and original operation
   outcome. Deterministic role/comparison order keeps record rosters stable after
   sorted JSON reopening. Physical observation identity and preparation identity
   remain different fields; missing physical owners stay unknown.

## Typed output and parent possession

The native return vocabulary is numerator_parameter, denominator_parameter,
parameter_difference, parameter_ratio and log_parameter_contrast. The complete
nine-cell045 result remains private saved state, with model=None and its four
model-dependent values unavailable. Public fixed fields explicitly say
model_input_status=not_supplied_by_native_operation and
model_reader_capability=unimplemented. This states an implementation limit,
not a finding that a paper omitted covariance. The scientific model/covariance
source reader remains required future work.

Public rows preserve exact source and physical ownership references, actual
subject/construct/context, per-role parameter kinds, units, point/limit relations,
thresholds, approximation, source and converted origin, supported finite
comparison meanings, source uncertainty meanings and unavailable reasons.
Numeric spread, interval, confidence level and count are supplied only with the
matching requested raw parameter row. Derived-only rows keep these values null
and explicitly mark delivery_status=not_requested. Units containing a caret
cross the closed-string contract as uM_inverse_min_inverse; frozen scientific
inputs/calculation units remain uM^-1min^-1. The renderer displays the physical
unit spelling for the admitted numerical component.

The unchanged final044 base supplies owner/admitted-subset fact_cells,
validate_fact_values, receive_cells and received_cells. An actual selected owner
may project its selected components. Another episode holding the sheet can use
only the exact admitted typed rows. Existing C7 outgoing validation checks the
reporting episode, and incoming receive belongs to the distinct parent.
Original successful runtime forms/contracts authenticate receipt subsets; a
receipt plus forged matching digest is insufficient. Original selected report
repair authentication and old read-only compatibility remain unchanged.

## Saved reconstruction and rendering

Saved reads verify immutable request/payload/source identities, original
operation linkage, selected witness and canonical input associations, finite
closed field types, measurement/physical-owner hashes, source metadata and page
ancestry, exact published reference bindings, and actual frozen implementation
hashes. They do not read original scientific source artifacts, call046/045,
infer covariance, compute new scientific contrasts/profiles, call a model,
admit another receipt, or reprice completed work.

C7 fingerprints exactly four kinetic modules: frozen045 calculations, frozen046
inputs, new detached validation and new storage. Storage additionally verifies
actual bytes for all frozen reused reader dependencies. Existing pins and saved
runs were not rewritten.

Automatic factual rendering uses the admitted rows. Numeric token anchors also
suppress overlapping broad source labels, including numeric spread/count/CI and
confidence-level witnesses. If a numeric anchor is off-page, fallback suppression
is restricted to its actual source. Safe scientific labels from known anchors
and unrelated sources survive. The dedicated renderer shows selected finite
scientific meanings and requested numbers. Full original source access remains
available for an episode's later explicit selection.

## Verification meanings and limits

The two new test modules use synthetic source bytes and the real Store,
LiteratureEpisodes/shared loop, provider serialization, C4 admission and SQLite
read-only reconstruction. They exercise all three native parameter dimensions,
qualifiers and useful partials; actual source receipt and page ancestry;
owner versus receiving subsets; snapshot/type/identity tampering; replay;
source uncertainty delivery and numeric leakage through broad/off-page labels;
physical observation versus shared preparation; Unicode source identity;
transaction rollback, original admission authentication and saved-only reopen.

The nested loop fixture has one selected population and two parent subset
admissions, with five actual own-action observations and zero target credit.
The separate C4 reopen fixture has no controller observations and whole SQL
unchanged. They do not establish live-model choices, paper extraction quality,
scientific normality/covariance interpretation, or completeness of A105.
VERIFY_004_RECEIPT.json and its exact terminal log record the final bounded
verification outcome; overlapping exploratory runs are not additive totals.
