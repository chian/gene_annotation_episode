# Additive precision before ratio runtime integration

Retained visual rows preserve both printed_label and reference_printed_label,
and both image_region and reference_image_region. Runtime validates actual source
image custody/dimensions/lineage and parses the two printed numerical tokens.
It calculates numerator/reference, rather than assuming reference1. A retained
visual transcription remains labeled as such; pixel-reading truth is not proved
by parsing its retained JSON. The primary example is manually source-inspected,
not OCR or fresh densitometry.

The final cells carry candidate values and whether the received raw ratio roster
is complete (no missing observations). Candidate sets describe received source
representations, not sampling intervals or an exhaustive scientific uncertainty
set. Amount-adjusted-effect unit stays null when its response model is unknown.

Runtime selection also supplies constrained signal_kind (protein_band,
transcript_signal,other_reported_signal,unknown), reference_role
(tagged_wt_complementation,endogenous_wt,other_reported_reference,unknown,
conflicting) and arrangement (existing closed codes), supported by actual
source interpretation_witnesses. These preserve the actual denominator/arrangement
questions; validation proves exact source words/custody, not semantic correctness.
All interpreted fields survive typed delivery. Unknown relationships stay unknown.

Source JSON comparison labels must match selected subject/variant/reference.
The retained source must name its actual received parent image sources and
artifacts. Complete sheets retain primary/projection/visual locators, all source
parents, numerical candidates and unavailable calibrated-effect cells. No new
independent preparation count is manufactured from representations.
