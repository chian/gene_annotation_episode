# A108 requirement and alternative-route meanings

Implemented the scoped engineering defect repair. A108's existing fifteen
numerical components now have a versioned typed return that retains the actual
requirements' and routes' source-supported scientific meanings. The original
calculator, capability-versus-sample-coverage distinction, v1 schemas, saved
outcomes and receipt families remain separate and unchanged in meaning.

This is not A108 completion, native-paper extraction validation, or completion
of the fixed literature goal.

## Concrete behavior

Retained `a108_source_context_measurements_v2` adds closed `meanings` alongside
the unchanged numerical `inputs`. Each actual requirement and route must have
one meaning entry, matched by its private key rather than list position.
Private keys are host alignment information and never scientific labels.

Requirements carry nullable, exact source witnesses for definition, entity,
property, biological setting and function relationship. Routes carry nullable
definition/setting/function witnesses and separate membership and joint-scope
source witnesses. Meaning-list order can differ from numerical roster order.
Extra, missing, duplicate or unknown roster entries fail explicitly. Absent
meanings remain unknown; this creates no new numerical scoring gate.

The selected operation authorizes every newly discovered witness source for
actual receipt, scope and assigned-page ancestry before reading its bytes.
Durable anchored terms, contexts and definition/evidence references retain
those selected meanings. Distinct scoped references identify requirements and
routes even when their scientific definitions are unknown. Unknown handles
assert no substance, biological support or independence.

`literature_context_record_v2` stores the same existing numerical sheet. Its
closed `literature_context_semantic_cells` view binds each native unit/domain
to requirement identity and meaning references. Each route retains exact
requirement membership, completeness, existing joint-support status and the
separate source evidence. It has independent receipt custody. Existing v1
forms cannot acquire the new view or its meanings by knowing a sheet ID.

The view performs no DDL during construction/discovery on an old read-only
database. Its receipt state is created only during actual receipt. Saved replay
uses the saved sheet/request; it does not reread original sources, re-extract,
recalculate, migrate, backfill or upgrade old forms/receipts. Read-only semantic
record reconstruction also works without any artifact/source reads.

The recurring A108 TASK now explains operand/route meanings and missingness.
The narrow STEERING renderer resolves only actual received scientific records,
using local requirement/route handles to preserve membership. Missing possession
does not silently recover a label from global storage.

## Remaining work and limits

This path still consumes prepared retained structured JSON. It is not automatic
extraction of requirements, operating domains or alternative routes from an
arbitrary experimental report. Native report/table/figure readers remain a
separate required workload. No primary paper, live database, external service
or live model was used for this implementation validation.

Exact source witnesses validate custody and selected literal identity, not the
scientific truth of a role assignment, joint biological scope, supplied domain,
mapping, independent sample design or declared relation. Legitimate
source-supported interpretation remains the episode's responsibility; source
phrases need not use our ontology. Metadata absence does not change the
existing conditional numerical formulas. Fresh source-grounded scientific
validation, and any needed native input path, remain outstanding. The own
authority reset must precede the next primary-paper interpretation.
