# Caller-bound source-evidence parent presentation

Current GOAL_VERBATIM.txt and TASK_AND_STEERING apply. The installed owned-model
path runs annotation/root through ordinary method_loop; it has no alternative
root role or initial literature assignment. Source-specific child presentation
alone does not satisfy the parent side. No new root loop/episode is introduced.

Root will add optional LiteratureEpisodes(...,reference_parent_sources=[refs])
configuration, allowed only with rate_population=True. Default None preserves
existing bindings. This is an explicit caller source assignment, not inferred
from generic fact-source presence or child history. On annotation/root only,
initial_decision_context returns reference_evidence_parent={version:
reference_evidence_parent_v1,source_refs,source_custody} and the existing
literature_experimental_work marker with aspect=reference_evidence_parent.
Validate all assigned refs against actual same-root receipts/scope; preserve the
fixed caller source roster in every iteration and saved descriptor/reconstruction.
Do not read source contents or add new observations in this context hook.

Fresh presentation worker owns ONLY new literature_reference_parent_prompt.py
and tests/test_literature_reference_parent_prompt.py. Export REFERENCE_PARENT_TASK
and render_reference_evidence_parent_prompt(state,instructions,*,lookup_results=()).
Root routes the existing renderer lazily on the explicit aspect. The new renderer
may reuse pure mechanical _values,_schema,_section,_steering,_pick/text_instructions
from literature_experimental_prompt/scientific_process_prompt. It must not call
that child renderer's _task or append child ASSAY_TASK/EXPERIMENTAL_TASK wholesale.
No source papers/packets, provider, runtime, binding or other files changed by worker.

The parent's actual job is to evaluate what the assigned experimental sources
establish about a reference molecule/function, decide which uncertainties to
resolve, choose permitted source/literature work, request meaningful typed
information and integrate actual returned measurements/qualifications. Preserve
actual caller goal, selected source roster/custody, scientific scope/constraints,
available own operations and allowed child choices. Distinguish molecular activity
from perturbation/restoration phenotypes; actual band signal from calibrated
protein amount; source assay results from target correspondence. Evidence can
qualify or contradict proposed functions; no initial annotation is required.
Do not fabricate reliability numbers or target-transfer weights. The parent owns
integration; a child return does not become a new parent task or another model
report call. Describe requested forms/available numerical fact meanings without
pasting full scoring sheets/calculators into TASK.

Render full recurring TEXT TASK on every call. STEERING uses current own-yield /
expectation tables, actual selected outcomes and requested admitted child forms,
qualifications and actionable repair only. No whole source inventory/history,
configuration/pin/host tracking, or copied child/private instructions. Shared
source facts are not parent knowledge merely because an ID exists globally.
Controller owns continuation; no completion gate/fixed action count. Tests use
synthetic states and controlled transport data, not live inference.
