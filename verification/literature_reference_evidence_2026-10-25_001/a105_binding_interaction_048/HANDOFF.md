# Bounded four-cell binding interaction component

Implemented only the new pure calculator and its synthetic test module. The earlier proposal and additive 002 refinements record the review sequence; the production module docstring is the final exact closed input contract. No existing source module, source reader, storage operation, catalog, prompt, runtime or W05 credit function was edited.

The 12 numerical cells preserve four actual source parameter points/printed thresholds, two within-subject ligand-parameter ratios, D and log(D), optional c'Cc and its standard uncertainty, and the known-normal signed S and bounded B representations. These are dependent numerical meanings within A105, not 12 sheets, independent evidence contributions, or a whole-A105 grader. IC50 and reported Hill Kd remain separate input kinds; no conversion into intrinsic affinity or protein-input-ratio correction is made.

Canonical subject, construct, state, parameter-definition, readout and normalization IDs must be known and agree within a subject pair. Ligand IDs must be distinct within a pair and agree by reference/test role across pairs; parameter definitions must agree across all four. At least one source-assigned subject/construct/state identity differs across subjects. Source-supported relationships remain separately required. Unknown preparations establish no sameness or independence. Different readouts/normalizations between subjects retain actual protocol qualifications. A common-condition comparison additionally needs an explicit matched relationship and cannot override known different canonical condition IDs. Actual reported-protocol arithmetic survives qualified conditions.

Each numerical operand retains exact source labels, source-assigned canonical IDs, physical-fit identity, source expression and closed byte/image/table witness. Methods/footnote witnesses directly support relationships. Model estimate owners hash the complete normalized record plus parameter kind and unit; physical owners remain separate. Exact same-token and known physical-fit reuse within the four roles cannot create a contrast. Shared control identities survive across calls; this module does not count them or aggregate multiple interactions.

Printed-limit arithmetic accepts multiple censored operands only when the coefficient-adjusted directions agree, preserves strictness and keeps the threshold separate from a point value. Opposed directions are explicitly uninformative; individual source values and valid partial ratios survive. Printed arithmetic is not a confidence interval or a true-parameter bound. Censored joint likelihood is unimplemented, separately from whether the source reporting event is unknown or source-defined.

Covariance is a complete actual source-bound symmetric PSD 4-by-4 matrix on natural-log-nM estimates. Exact rational Schur complements and c'Cc avoid tolerance/jitter or default independence. Known/estimated status requires physical owners and the full matrix; unknown status can retain a validated matrix without using it. Estimated status permits variance but not known-normal S/B. S/B require uncensored points, known covariance, a normal log observation model and positive V. Raw fit spreads, confidence intervals and exact/minimum counts never become covariance. Source CI endpoints are retained even if outside the positive parameter domain; no CI-to-log or SD-to-SEM conversion is attempted.

Numerical range failures are local: log contrast can survive D overflow/underflow; standard uncertainty and S can survive V overflow; bounded B can survive S overflow as a qualified rounded endpoint, never a claim of certainty. Valid earlier causes remain attached to dependent unavailable cells. Returned input/model records are detached, finite JSON compatible copies.

## Limits and work outside this release

This is a pure numerical component, not an installed or scientifically source-bound operation. It validates supplied witness shapes, declared mappings and numerical relationships; it does not verify retained bytes/image extents, paper interpretation, source receipt, episode scope or actual reader bindings. Future source/storage integration must prove those facts. Unrecognized aliases across different locators/representations cannot be resolved here when the physical identity is unknown. No runtime operation, catalog selection, model call, prompt, cross-interaction joint covariance/likelihood, observation deduplication policy or annotation-credit aggregation was implemented or verified. Whole-A105 coverage and the final number of component graders remain open.
