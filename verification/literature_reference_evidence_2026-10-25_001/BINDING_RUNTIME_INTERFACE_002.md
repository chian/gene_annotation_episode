# Typed formula identifiers and comparison context

An assembled ordinary-form check found that mathematical formula strings are
outside the common closed-string code language. Preserve each full formula in
the host scoring sheet. Project formula_code=binding_<component>_v1 through the
typed boundary instead of formula. These finite identifiers resolve to that
saved component's existing formula. Do not weaken the common form validator or
add a free-text report field. Validate both JSON and common closed-form semantics.

The standalone calculator preserves raw parameters/spreads but leaves ratio/log
unavailable with comparison_context_mismatch if selected arms differ in subject,
state or experiment. The present reader selects one common context; a deliberate
across-protein/state contrast would need its separately defined experimental
relationship, rather than bypassing this finite comparison contract.
