# Additive refinement of the increment003 assay boundary

The initial interface001 remains the pre-delegation record. The implemented
boundary also retains source_kind (primary_source,retained_extraction,
graph_extraction,synthetic_fixture) as a provenance declaration. It does not
verify experimental validity from that declaration. Retained-extraction operands
are labeled derived, graph operands graph_derived, fixtures synthetic; actual
raw witnesses remain alongside the declared source basis.

The assay literals additionally include experimental_system,expression_host,
measured_entity,asserted_input,asserted_output. This prevents returning only an
abstract endpoint label while losing the actual chemical/entity question. A
measured oxygen endpoint is distinct from asserted reaction input/output names;
those names do not prove products were quantified in the same assay.

Numeric returns use literature_assay_cells and requested_assay_components.
Every cell retains the assay/source identities, literal-subject/context references,
endpoint/arrangement kinds, evaluated_scope=interpreted_source_endpoint,
operand_source_kind and covariance_origin. Exact numerical primitive references
accompany dependent cells, enabling the receiver to recognize shared measurements
across roles and repeated selected representations. Covariance source identity
is explicit. Full source graph, model witnesses and original source bytes remain
in durable artifacts. Receiving an unrequested private cell is not implicit.

The calculator still performs its declared arithmetic on meaningful supplied
operands. If assayed molecule or measured endpoint is unresolved/conflicting,
partial arithmetic survives and the source profile/index remains unavailable
with a specific reason. This is numerical observation-scope missingness, not
an episode continuation rule or acceptance gate. No score is zero-filled.

Original/text labels resolving to the same source artifact and numeric byte span
share measurement identity. Source units cannot be hidden to turn a printed rate
into a dimensionless recovery. Exact quotations validate custody, not biological
interpretation. The episode remains responsible for assigning roles and scientific
meaning; the prompt states those concrete questions on every iteration.

A saved sheet is admitted only when its source reference is the committed result
of its original selected operation, in addition to run/version/custody checks.
Copying the provider label and constructing a source artifact does not manufacture
an authoritative population outcome. Reopening/replay does not reparse/refit.
