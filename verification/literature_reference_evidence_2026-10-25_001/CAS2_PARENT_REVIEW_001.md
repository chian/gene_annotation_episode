## Source definition and inference limits

Donor genes are E.coli K12 MG1655 cas1/cas2; assay recipient BL21-AI is described
as lacking cas genes. Reference WT denotes the plasmid Cas1+Cas2 pair in that
recipient. Cas1 and Cas2 coexist as required partners. The tested Cas2 variants
replace plasmid WT Cas2; a WT/mutant Cas2 mixture is not established. Figure1b
contains empty vector,Cas1 only,Cas2 only,and Cas1+Cas2. The empty vector
comparison removes both components, so it does not isolate Cas2 alone.

Figure3's Δβ6–β7 is a Cas2 domain truncation, not a native gene deletion and
matched rescue. Its precise residue boundaries remain unknown. Figure4's E9
variants retain visible acquisition products; neither quantitative equivalence
nor measured catalytic-null capacity of these E.coli variants follows. Catalytic
defects cited from other homologs are not a measurement in this source case.

The endpoint is an OD-normalized PCR pattern after20–24h induction. It lacks
calibrated expanded-locus fraction/events-per-cell, eligible clone denominator,
amplification/detection model and numerical detection limit. Visible bands
cannot become exact frequencies; nondetection cannot become zero. OD matching
does not quantify active Cas2 dose. Figure3f explicitly calls E65R expression
low, but supplies no quantitative expression ratio.

Assembly IP and DNA pull-downs address specific alternatives but do not measure
the same endpoint as PCR acquisition. The same lysates in4g/h retain dependence.
Purified proteins versus lysate DNA recognition are distinct systems, with
possible host factors/wash effects. Uncropped images are representations, not
independent experiments. Repeated>=3 is a lower bound, not three identified
independent cultures or a sampling variance.
