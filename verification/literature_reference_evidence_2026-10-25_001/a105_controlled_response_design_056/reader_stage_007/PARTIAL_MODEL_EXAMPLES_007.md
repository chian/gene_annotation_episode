# Proposed partial-model examples and boundaries

These are specification examples, not executions of a reader that does not yet
exist. COMPATIBILITY_RECEIPT_007.json contains the actual existing-helper and
separate calculator calls. Every source/data/model fixture is invented.

| Source/selection case | Required retained fact | Proposed effective parsed model | Distinction |
| --- | --- | --- | --- |
| Valid four-variable matrix, actual known status, selected known/none | Full source matrix, human labels and witnessed four-owner map | C available; known; model none | Actual compatibility proof: e=.006, V=1.7e-6. |
| Actual three-variable matrix [P1,E,P0], one E explicitly shared | Actual source C remains 3x3; four-role indices [0,1,2,1]; one actual physical E owner | Full projected4x4 with actual repeated rows; known; model none | Actual compatibility proof: e=.007, V=1.36e-6. No new E observation. |
| Same source index bound to different declared actual owners | Original source/index/owner witnesses and conflict | C=null; unknown; model none | Projection never establishes ownership; do not unify owners to fit C. |
| One owner mapping unknown, despite an actual complete source C | Whole source C and unresolved binding | C=null; unknown; model none | Missing scientific correspondence, not an omitted matrix or independence. |
| Exact raw source C is asymmetric/non-PSD | Actual complete source lexemes/model fields and finite source-invalid code | C=null; unknown; model none | Keep all independent rate/uncertainty records; no jitter/diagonal fallback. |
| Duplicate JSON key/nonfinite JSON constant | Raw authentic acquired artifact and finite representation error | C=null; unknown; model none | Malformed source representation, not malformed selected arguments. |
| Lexical1e-500 in otherwise exact PSD source matrix | Nonzero exact source rational and unsupported finite projection | C=null if no supported finite representation; unknown; model none | Finite source mathematics; missing numeric interface capability, never zero or source-invalid PSD. Existing JSON helper probe rejects numerical range. |
| Exact source PSD, float projection loses PSD/shared-row identity | Exact source model plus finite projection failure | C=null; unknown; model none | Reader representation limitation, not a bad experiment. No repair. |
| Source and selected variance status both estimated | Actual estimated C/status and normal-family qualifier if separately supported | C available; estimated; selected supported family | V available; frozen calculator refuses known-V profile. No SD/count conversion. |
| Source estimated, selected known | Both unchanged actual and nominated statuses | C=null; unknown; model none; explicit mismatch | Do not promote source estimate or silently select a different model. |
| Source known C; selected model none | Source model family retained even if normal is offered | C available; known; model none | No automatic statistical-model selection. |
| Source normal family unsupported but C otherwise valid | Actual C plus missing/unsupported family support | C available with actual status; model none | Magnitude/variance useful; no normal-profile claim. |
| One canonical display overflows under a registered rate unit | Native literal and actual registered scale still valid | Native parsed operand survives | Calculator may retain exact joint cancellation or finite dependent quantity. |
| Arbitrary defined-unit scale cannot fit frozen numeric interface | Exact source definition/native literal and limitation | Native reading retained; no invented converted zero/unit | This is an unimplemented numeric representation, not missing paper evidence. |
| Unknown normalized denominator on condition0 | Actual raw quantities and unresolved denominator | Scalar inputs retained; corresponding ID null | Calculator keeps valid condition1 pair; e unavailable. |
| Complete authentic95% followed by sentence period | Exact selected95% bytes and actual '.' in source | Confidence piece null with parser-capability code; count/SD/CI retained | Actual released helper failed. No source punctuation rewriting or assertion confidence was absent. |
| Graph nominee in first text/JSON stage | Actual authenticated image/crop/tick/recipe nominees | No graph number; graph_rate_reader_unimplemented | Required graph capability remains unfinished; no fake ordinate or C from reading bounds. |
| Unauthorized source, forged quote or known clipped numeral | Repairable actual selection failure | Reject selected request | Do not reclassify scope/custody violations as missing scientific evidence. |

The source-label format is the first supported acquired structured format. Other
real source model formats, source-defined covariance unit scales and the eventual
graph pixel wrapper still require exact bounded interfaces. The proposed source
reader does not solve every literature model, and these capability limits must
be visible in results rather than attributed to a paper.
