# Scoped calibration-return integration

This is implementation evidence. The immutable full goal is unchanged; whole-A105 adequacy and the common complete sheet remain open.

Initial child: the actual parent assignment names source scope and the requested calibration-recovery component list. The complete existing experimental TASK remains. The full previously printed CALIBRATION_RECOVERY_TASK is added for a nonempty actual request, a marker derived deterministically from that request, or the child's actually received own selected recovery result. A source name or keyword does not route work. The marker is a view, not another persistent authority or workflow.

Later decisions, on-demand lookups and reconstruction: each decision rebuilds the same substantive TASK from the original assignment and actual receipts. New lookup information belongs in concise factual STEERING. Lookup, parsing, arithmetic, fact projection and report construction do not create synthetic completed-action observations.

Selected operation: the child selects literature.calibration.recovery.populate in the existing LiteratureEpisodes catalog. Each witness source must actually be received, in scope and, for a page assignment, descended from the assigned source. The source reader obtains values from original bytes. The deterministic calculator populates numerical components once; the selected operation saves the exact request, selection, extraction and sheet atomically.

Typed child return: requested components are literal saved projections. The new registered closed fact schema preserves scientific control meanings, analyte, matrix, endpoint, expected basis and spread interpretation alongside numbers and original measurement reuse. A genuinely unavailable pre-output return can be empty. Once requested results are known, omission of the available requested subset is invalid. Merely knowing a saved sheet's reference does not grant its unadmitted components.

Parent: its original full REFERENCE_PARENT_TASK remains authoritative. Requested admitted rows render as numerical tables and necessary scientific qualifications in STEERING. The child TASK, raw scientific source witnesses, host byte offsets, hashes and measurement IDs do not become parent instructions. Human-readable local measurement labels make dependent algebraic views visible without treating them as independent experiments.

Cold reconstruction: the fresh composed factory validates the original implementation descriptor and saved records. No source reacquisition, scientific parser, calculator or interpretation reruns. The completed writer is checkpointed and closed before the fixture opens immutable SQLite in mode=ro with query_only enabled. Exact original admitted rows are restored without database changes or state-byte changes.

The source-control analyte is the actual control subject. A NADPH standard does not silently become the G6PD enzyme or an established function claim. A serum enzyme-activity spike is not an isolated reporter gain. The new operation has no target measurement to which it can apply a correction, and it cannot fill recovery uncertainty from numerator SD alone. Source-reported within-run/between-run CV, Z-prime and linear-calibration conversion are separate implementation gaps; this route's absence of those fields is not a finding that the paper lacks them.
