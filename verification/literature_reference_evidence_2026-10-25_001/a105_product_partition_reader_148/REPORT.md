# A105 reported product partition: bounded implementation

The numerical sheet retains the original reported fractions separately and
calculates their dependent sum, signed deviation from one and ratio. In the
retained PMC12051542 case, R5P is 60.3% and Ru5P is 39.7% of the selected
equilibrium mixture. Components are 0.603, 0.397, 1, 0 and 0.603/0.397 =
1.5188916876574308. Source reporting as a point does not establish exact
physical values. Sum 1 is arithmetic closure of these selected reported
fractions, not independently measured mass balance or absence of side products.
The ratio describes relative partition, not rate or substrate specificity.

The reader pairs exact original number/unit spans with the actual species,
subject, organism, construct, preparation, endpoint, stage, time, denominator,
measurement basis and species-contribution identity. Scientific interpretation
is separate from byte verification. Unknown or conflicting source relationships
preserve individual fractions while leaving affected pair components unknown.
Amount fractions, signal fractions and unknown bases are separate meanings;
percent syntax alone does not establish a molar calibration. Bounds retain
thresholds, and source-qualified approximation remains explicit. Out-of-range
reports are retained with a flag, without clamping.

The isomerizing HFP preparation is not evidence of isolated HFP isomerase
activity: the article reports contaminating RpiA detected by mass spectrometry
and activity in four of five selected other preparations. Cleanup also changes
the construct/purification and timing, so comparability and attribution remain
different questions. Complementary carbon NMR supports chemical identity, not
an additional independent repetition. NMR scans are not independent n. The
reader retains finite source-evidence roles and exact witnesses; it does not
convert any of these relationships into an overall quality number.

No covariance or standard-uncertainty calculator is implemented in this narrow
five-cell route. `uncertainty_calculation=not_implemented` is explicit. This is
an implementation limit, not evidence that a publication omitted uncertainty.
No default covariance, zero variance, independent-preparation count, probability,
HFP-attribution fraction or annotation credit is manufactured. Final annotation
aggregation and W05 remain separate.

The original reaction native producer was inspected completely. It supports a
single published ratio point or a literal author `a:b` expression and native
resource quantities. It cannot preserve these two percent fractions, their
shared composition denominator and closure. Its arithmetic was therefore not
substituted for this narrow composition reader.

The implementation uses existing Store custody and LiteratureRateRepository
scope, assigned-page and authenticated subset receipt mechanics. Saved reading
validates associations and arithmetic deterministically without reacquiring
source text, invoking a model or changing history. The root subsequently granted
serialized ownership of the three shared integration files after the
completion-time workload released them. The reader is now an optional selected
operation in LiteratureEpisodes, disabled by default and using an empty default
requested component subset. It follows ordinary source custody, exact typed
admission and shared method_loop paths. No new episode or private loop is introduced.

Primary-source scope read for this workload: complete XML article body text,
61,166 Unicode characters, in sequential ranges [0,30000) and [30000,61166).
Front matter, reference list, external supplements and other papers were not
claimed as read. Initial oversized output attempts were truncated and were
superseded by the complete sequential reads. After that read, the complete
immutable user goal and required authority set were reread before the concrete
field/component proposal. The authority manifest records paths and hashes;
these are provenance, not a replacement goal or runtime approval condition.

Tests use actual original numeric spans for the primary example and explicitly
synthetic contrasts for lexical, partial-information, custody and subset cases.
They do not run a configured model or supply new scientific credit.

The final selected operation returns only the original assignment's requested
typed component rows. A complete sheet remains private. Meaning references
distinguish selected, not selected and withheld because of unrequested numerical
overlap. Exact byte overlap masks are used; numerical characters inside a gene
or compound name do not by themselves cause withholding. Dedicated text tables
show all selected scientific meanings and qualifications without generated host
accessions. Own outcomes, current reports, child returns, history and lookup
paths preserve mixed return siblings and omit unrequested native operands.

Focused checks establish actual primary-source selected population through
LiteratureEpisodes, exact subset return validation and receipt, cold query-only
lookup, source-free saved reconstruction, and a controlled shared child-to-parent
run with one child population action and two parent actions. All three observed
scores are zero. The parent reasoning action commits only a synthetic source
subject. This is engineering execution with controlled choices, not configured
model-backed science, annotation credit or completion of A105/W04/W05.
