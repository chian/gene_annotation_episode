# Additive integration instructions for the shared-file owner

This bounded implementation has no shared-file edits. The root owns assembly.
The original user-supplied goal remains authoritative and unchanged.

Use the current opt-in completion-time integration as the mechanical analogue,
while retaining product partition's own scientific TASK and return meanings.

1. In `literature_episodes.py`, add `product_partition_population=False` to
   `_population_catalog` and `LiteratureEpisodes.__init__`. Validate a literal
   boolean and require `rate_population` when enabled. Add no descriptor key,
   operation, assignment property or TASK marker when false.
2. When true, catalog operation `literature.product_partition.populate` uses
   `literature_product_partition_inputs.product_partition_arguments_schema()`.
   Description: "Populate selected A105 reported product-composition fractions
   and their dependent sum, signed numerical closure and relative partition.
   Read exact original number/unit spans; retain basis, preparation, endpoint,
   stage, denominator, source qualification and competing-contribution evidence.
   These quantities are not rate, specificity, mass balance or molecule-specific
   attribution. Numerical uncertainty propagation is not implemented."
3. Include the five `literature_product_partition_{inputs,calculations,storage,
   prompt,render}.py` files in the enabled descriptor's source snapshot only.
   Freeze the actual inherited custody dependencies already present in the
   rate-population descriptor, without transplanting an older release's hashes.
4. Add optional assignment array `requested_product_partition_components`
   with unique items from `literature_product_partition_calculations.COMPONENTS`.
   Missing selection means `[]`, never all. Preserve the original parent's
   exact requested subset at return validation.
5. Add lazy `_product_partition_repository()` matching the current
   `_completion_time_repository()` factory, instantiating
   `LiteratureProductPartitionRepository(self.services.store,
   self.services.run_id)`. No EpisodeServices change is necessary.
6. Add the new operation name to the existing population validation/dispatch
   branches and map it to that lazy factory. Populate uses the ordinary existing
   selected-action completion, with no private loop or extra observations.
7. Register `literature_product_partition_cells` under the flag using
   `product_partition_cells_schema()`. The provider is
   `literature.a105.product_partition_population`. Add the existing cell-source
   tuple `(NAMESPACE, "requested_product_partition_components", PROVIDER, (),
   self._product_partition_repository)`. The empty tuple preserves opt-in exact
   selection; the repository itself also defaults to an empty projection.
8. Add the namespace to the existing exact-schema validation in
   `communication.py`, with no unrestricted fields. Retain existing receipt and
   requested-component checks. At receipt include only
   `repository.cell_record_refs(cells)` for the exact returned rows; do not
   expand to all bindings or read original source bytes.
9. In ordinary task preparation, add marker
   `literature_product_partition_work: {version:
   "literature_product_partition_task_v1"}` only under the flag. Render
   `PRODUCT_PARTITION_TASK` in every TASK, independently of STEERING and prior
   outcomes. Include it in child assignment and reconstructed task paths using
   the normal preserved descriptor flag.
10. In text presentation, recognize closed partition rows with
    `literature_product_partition_render.is_row`; use `rows_from_values` and
    `rows_from_reports` on exact received rows and `render_received` with the
    corresponding received records. Source-meaning records must be limited to
    the returned rows' `cell_record_refs`. Suppress generic raw outcome/sheet
    dumps in own-history, child return and lookup presentation. The renderer
    must never read a full private child sheet to complete missing operands.

The repository masks complete scientific-meaning witnesses when they overlap
an unrequested scalar operand; it never rewrites a quote. Qualification
witnesses use the same exact overlap check. A numeral inside a compound or gene
name is not itself a reason for withholding. Availability is explicit.
An episode can select a smaller source-backed phrase in a later
action. The typed result contains species/endpoint/basis/stage relationships,
but never native operands merely because a derived component was requested.

Required joined checks: default descriptor/catalog unchanged; enabled flag
reconstructs; real primary-source selected populate within LiteratureEpisodes;
unknown or conflicting relationships retain individual fractions; exact typed
subset through child-to-parent receipt; unrequested numbers absent from every
prompt/lookup/history representation; source-free query-only reconstruction;
one completed selected own action creates one controller observation, with no
additional observation for parsing, arithmetic, rendering or receipt. Fixtures
and controlled choices carry zero scientific credit.
