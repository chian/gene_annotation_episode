## Reader input and responsibility

Keep literature.context.populate and its exact existing selected arguments. The received data_source_ref may contain a new closed retained recipe version a108_source_context_selection_v1. Unlike the existing retained measurement JSON, its numerical measurement leaves are source selectors, not supplied numerical values. Its three top-level fields are version, selection and meanings. meanings retains the complete existing v2 requirement/route witness contract.

selection retains the existing question/scope/frame/pairing/sampling interpretations and the actual requirement, route and context roster. Native report numbers are selected through {witness,number_start,number_end}; byte-exact witness custody and whole-token lexical/censoring checks use the existing source-number reader. Unit selectors retain the exact unit witness and a declared physical basis from current NATIVE_UNITS. Recognized mM/uM units can be parsed directly; ambiguous gas/dissolved bases remain explicit interpretations with their source context. Source scalars, spread magnitudes, counts and measured non-equal weights cannot be introduced as numerical arguments. Alpha and an equal-unit weight of one are declared method parameters, distinct from source measurements.

First scope: exact numeric points plus separately selected SD/SEM/untyped spread and exact integer counts. Unsupported approximate, bound or range syntax is rejected as unsupported rather than converted to an exact point. Missing inputs remain null. Existing basic arithmetic/conversions are reused where dimensions support them. Broader censoring/range grammar is not claimed by this first source case. Requirement supported/incompatible domains can be discrete source-supported tested-point unions; the reader does not interpolate between points. State relations remain source-supported narrow interpretations, not fabricated numeric measurements.

Each context retains a source identity witness, actual biological setting, source basis, sample-unit/cluster witnesses where known, scope match and pairing. Per-observation physical identity derives from retained source/measurement selections, with explicit shared identity retained where supported. Equal numbers do not establish identity or independence. Technical count or repeated representation does not create more context states or biological opportunities. The native trace records nominal reported settings separately from source-reported measurements and conditional/inferred values.

The helper returns normalized current-v2 inputs/meanings plus exact original recipe and enriched native evidence. It invokes no model, acquisition, Store write or calculator. The existing repository invokes the unchanged numerical calculator once for the selected population operation. Newly discovered numeric witness sources are authorized for actual receipt/scope/page ancestry before reading.

## Explicitly requested native observations

The existing literature_context_semantic_cells view continues returning the requested numerical components and meanings exactly. It does not automatically reveal the child's native operands. A new independent fact source literature_context_native_observations returns actual native observation rows only when the original parent form requests it. This is reader output tied to the same committed sheet, not another scoring sheet.

Closed row fields proposed: sheet_ref, evidence_source_ref, data_source_ref; context_ref, requirement_ref and measurement_ref; observation_position; unit; lower/upper and inclusivity (equal for an exact point); reported_sd, reported_sem, reported_plusminus; reported_count, count_relation, replicate_kind; value_basis (source_reported_measurement/source_reported_setting/source_supported_inference/conditional_assumption/unresolved), basis_ref; sample_unit_ref, cluster_ref; scope_match and pairing. References are durable scientific records; source quotes are rendered through actually received records and local scientific handles, never copied as unrestricted report prose. Context definitions identify the culture/habitat/cellular scope, so a culture concentration is not relabeled as a habitat measurement.

Proposed optional assignment selector requested_context_native_positions uses a unique list of nonnegative canonical observation positions, or the sole value all. Omitted means all only for an actually requested native fact field; [] means none. Positions select actual retained unique contexts/requirements in fixed order and are tracking operands, not scientific labels. Native facts outside the requested positions cannot be delivered or forwarded by knowing the sheet reference. New receipt custody is independent of existing semantic-cell custody.

Saved reconstruction reads the exact immutable population payload/outcome/request and native trace, not original paper bytes or a parser/calculator/model. An old prepared-input v1/v2 sheet without native evidence cannot be upgraded into native facts. Lazy receipt-table creation occurs only during actual native fact receipt, never discovery or read-only reconstruction.
