## Closed scalar return and scientific scope

`rate_grid_cells_schema()` is an exact registered whole-field array schema. Each row contains sheet_ref/evidence_source_ref (source reference types), record_version, scientific_sheet_version, evaluation_scope, component key, and **the complete selected pure scalar cell**: selector, cell_key, ordinary/conditional value and exact forms, unit, formula_id, meaning_id, numeric_basis, status, separate source/relationship/implementation reasons, input measurement/origin keys, estimator/model/contribution identities, variance_status, count_basis and selected-roster/available-point scope. The registered fact exception does not permit model-authored unrestricted findings.

Additional required closed scientific context is bounded to the requested scalar's meaning:

- Source subject, source panel and native endpoint labels have original locations and a scoped display value/status. Full original label strings stay in the private saved extraction. Unclassified numerical claims embedded in labels are withheld from the projection/display with an explicit numerical-context limitation; chemical/construct identifiers and unit notation are not arbitrarily treated as measurement values. This is a bounded display capability, not a claim of universal prose redaction.
- Endpoint relationship status and sampling status/assumption/source_claim remain separate. No raw Methods/caption quotes are included in projected rows. Authenticated original witness locations remain host custody and can support explicit later source access.
- Preserve exact estimator kind, selected fit model and weighting meaning; reported curve labels are report labels, not physical preparation identities. Necessary denominator/count metadata is explicitly reporting-level, never biological n. Include only counts needed to interpret the selected statistic, not another independent contribution.
- For point/sensitivity/cross-concentration scalar selectors, return only the selected concentration coordinate(s) needed to name that result, with their actual unit, point/bound/status and original location. Those coordinates are the result's named context; they grant no rate entries, parameter values or matrix. Global/curve/estimator rows do not expand the full concentration roster. Root should confirm this explicit coordinate-context choice before coding.
- Qualifications explicitly state fixed reported concentration coordinates, conditional IID reporting-vector covariance where applicable, unknown physical preparation count and published-estimate covariance, and unresolved product attribution/blank/recovery/active amount. Precision does not resolve the endpoint-header/Methods conflict. Neither supported nor stipulated IID scenarios become ordinary physical covariance.

Host custody contains original locations/identities needed to validate rows and to prevent generic record expansion; it includes no unrequested raw numeric matrix or rate roster. Only the selected scalar's value, and its explicitly named coordinate context, are numerical delivery. A CV-only recipient cannot obtain source rate means, fitted parameters, other covariance entries or full scientific snapshots from the sheet reference or a generic alias.
