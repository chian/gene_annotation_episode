## Exact candidate and classifier interfaces

The shared pure `_between_numeric_scope(prefix, suffix)` returns exactly
`numeric_interval`, `non_numeric_coordination` or `unresolved`. It performs no
numeric conversion. Candidate absence returns unresolved but is not rejected by
itself: both consumers first test the same imported candidate patterns.

Candidate matching uses the nearest applicable `between` within one sentence:

1. Upper-endpoint candidate: `between ... and` ends the prefix, with only
   whitespace between `and` and the selected literal.
2. First-endpoint candidate: the prefix contains `between` without a subsequent
   sentence delimiter, and the suffix contains `and` before such a delimiter.
   This also rejects an unfamiliar first-endpoint modifier, rather than admitting
   the first endpoint while rejecting only the second.

Delimiters are semicolon, newline, question/exclamation mark, and a period except
within an ordinary decimal, a decimal scientific notation such as `3.e2`, or the
recognized abbreviation `approx.`. This finite punctuation grammar is not a
general sentence parser. An earlier completed sentence cannot veto a later
55 °C/4.5 h quantity or its conjunction. Existing direct between/from/range/CI,
dash/to, qualifier, arithmetic, lexical sign/exponent, uncertainty, role/unit and
finite-number guards remain independent.

For a candidate, positive allocation recognition precedes generic numeric first
endpoint recognition, so `between 17 wells` can be recognized as allocation.
Only the following complete grammar escapes the broad guard:

- Immediately before `between`: `was|were|is|are`, optional `equally|evenly`, then
  `divided|distributed|split|allocated|dispensed`.
- Object: positive digit cardinal or spelled cardinal one through ninety-nine;
  `flasks|wells|vessels|tubes|cuvettes|containers`; optional `of <unsigned literal>
  <ul|µl|μl|ml|mL|L> each`; optional comma; then `and`.
- Independent addition clause: one or more `<qualifier>* <literal> <unit>
  <entity-label>` items separated by `and`, commas or Oxford commas; then
  `was|were added to each respective|the respective|their respective` plus the
  same vessel noun (singular or plural), ending at punctuation or field end.
- Units are a finite molar/mass-concentration syntax, not a new unit converter.
  Labels contain ordinary letter-led alphanumeric/underscore/hyphen tokens.
  Interval, conjunction, qualifier, uncertainty and addition keywords cannot be
  label tokens. The selected placeholder must occupy a scalar position in this
  matched list. A reserved-placeholder source collision is unresolved.

Inline markup is ignored only by this syntactic test; it does not rewrite raw
contexts, selectors or sources. The actual field/context readers are unchanged.
No molecule name, particular amount or vessel/list count is special-cased.
Unsupported allocation verbs, labels, units, modifiers or relationships retain
rejection. Embedded real intervals cannot satisfy the positive list grammar.
