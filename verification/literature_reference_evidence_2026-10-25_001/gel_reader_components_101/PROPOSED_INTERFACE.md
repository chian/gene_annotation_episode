Selected arguments declare one ORIGINAL image/source/artifact/hash/dimensions/source-kind, nullable scientific context, explicit lane identities/conditions/control roles and source witnesses, and complete named ROI assignments (background, whole-lane and shifted/free/other bands). All ROI coordinates are half-open original stored pixel coordinates. No crops/resizes/conversions/classifier/OCR/axes or assumed intensity calibration. Initial reader capability is native8bitL, PNG/JPEG, one frame with stored orientation. Unsupported decoding/mode returns a capability partial, not an unavailable scientific measurement.

Read and authenticate the nominated full source closure before decoding pixels; source callback authorization failures propagate. Each ROI retains immutable image association, geometry, pixel bytes and SHA256, integer sums/count/min/max/zero-gray count, background-corrected exact rational signal including negative values. Invalid/outside regions are independent partials; unrelated regions survive. Repeated ROI representations retain their original physical identity. Explicit assignments are coherent entire-lane maps, never Cartesian products.

The calculator preserves B=sum shifted bands,T=sum shifted+free bands,f=B/T(display darkness fraction), protein-minus-baseline delta, residual competitor response, displaced fraction C and competitor-sensitive delta*C=fprotein-fcompetitor; whole-lane off-band display fraction, total-display-signal ratio and black-pixel occupancy are diagnostics, not calibrated recovery or saturation. Actual nonpositive denominators are unavailable; no intensity/fraction clipping. Overlapping selected bands cannot be counted twice. All sampling uncertainty and independent-preparation counts stay unknown absent actual supporting inputs. ROI-assignment ranges are analysis-choice ranges, never confidence intervals or repeated experiments. Missing scientific values and unimplemented statistical observation models remain separate.

Detached validation recomputes stored ROI summary/arithmetic from retained pixel bytes using base64/integer arithmetic, no source callback/Pillow decoding/reader/populator call. It binds exact selected identities and type-sensitive serialized payloads. Optional expected_digest is HOST-owned original immutable-record integrity, not a model-authored proof argument. Without such trusted custody, a pure JSON consistency check cannot prove original image-to-pixel mapping; native integration must bind the ordinary recorded original outcome before scientific admission.

No existing production modules, schema contracts, prompts, runtime, goals, instruction documents or controller histories are owned by101. Native LiteratureEpisodes integration remains unfinished and outside this component workload.
