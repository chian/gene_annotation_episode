# Gel reader and descriptive display component contract101

The source and comparison JSON schemas in this directory are generated directly from the new public constructors, not replacement instructions. Fields with scientific meanings use explicit known/unknown/conflicting interpretations and source witness spans. Known labels require supporting source witnesses; the label/enum interpretation need not occur verbatim. Byte-span authentication does not prove the scientific interpretation. Lane subject/construct/endpoint meanings can differ; those differences qualify the descriptive calculation rather than erasing valid pixel values.

One original native8bitL PNG/JPEG is measured. No decoder conversion, crop input substitution, image transform, OCR, graph-axis calibration or classification. Half-open ROI coordinates apply to original stored axes. Invalid/outside/unselected regions remain local unavailable results; independently measurable raw values survive. A complete source-witness closure is authorized before any image decoding. Callback authorization/failures propagate. Original selected source/artifact/byte hash/dimensions bind acquired bytes. Each measured ROI stores exact pixel bytes/base64, hash, integer sums/count/min/max/zero-gray count and exact rational background-corrected signal. Negative corrected values and fractions outside0..1 remain with qualifications.

Public read and validate functions: read_gel_inputs(arguments,*,read_source), validate_gel_selection(arguments), validate_gel_extraction(arguments,extraction,*,expected_digest=None). Detached validation uses retained ROI bytes with integer/base64 arithmetic, no source reader or Pillow image decoding. Optional expected_digest binds actual host-owned immutable original outcome only when supplied by that host. Recomputable JSON digests alone do not establish historical image-to-pixel custody. No native persistence/admission route is delivered by101.

Comparison fields are version, nullable baseline_lane_id, required protein_lane_id and nullable competitor_lane_id. They refer to declared exact lane IDs; no favorable automatic choice. populate_gel_components(extraction,comparison) returns coherent per-ROI-assignment raw band/total/fraction components plus delta, competitor residual fraction, displaced fraction, factorized competitor-sensitive shift and DIRECT protein-minus-competitor fraction. The direct form uses only protein and competitor pixels: it survives missing baseline or zero delta when factorization is unavailable. Reused measurements and cancellation remain explicit; no independent-evidence claim follows. Unknown/conflicting meanings or subject/endpoint/construct mismatches remain alongside available descriptive numbers, not protein-specific evidence. Display-black occupancy depends on selected raw band pixels, never a background measurement. Off-band and total-ratio diagnostics do not establish calibrated recovery or detector saturation.

validate_gel_sheet(extraction,comparison,sheet,*,expected_extraction_digest=None) recomputes consistency through private arithmetic without public reader/populator calls. Cells carry exact rationals and separately projected finite floats. No sampling covariance/calibrated-detector input route exists in this initial interface; data absence is reported separately from unimplemented calibrated molecular occupancy and binding likelihood. Independent preparation count and annotation credit remain unknown.

Sensitivity ranges use only explicitly supplied coherent ROI assignments. Each range says complete/partial/no_available_values, lists included and unavailable assignment IDs, and explicitly does NOT bound unavailable assignments. These are available-assignment analysis-choice ranges, not sampling confidence intervals. Per-assignment relationships remain intact; no Cartesian product of independent cell extremes is generated.
