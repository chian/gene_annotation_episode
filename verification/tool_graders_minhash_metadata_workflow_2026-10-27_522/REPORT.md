artifact and an exact JSON integer pointer under the original stage and metadata

had been received.

decisions and a scientific-role engineering continuation fixture choose the
test's work; production resource practical estimators remain in use. Scientific
credit is explicitly zero, with no scientific scorer. Only the transport
response is substituted at the urllib boundary; custody, common numerical
calculation, publication, report validation and durable observation paths remain
production paths. The native response and metadata are explicitly synthetic and
never presented as measured remote sketch parameters.

Assertions cover the complete eight-operand RPC and its bytes for genome and
FASTA modes; original selected tool information; genuine metadata action and
admitted form; precommission results input; original native bytes and reported
tokens; exact per-field frozen bindings; V2 publication with the common V1 sheet
and components; requested calculation/diagnostic families through the actual
results return and onward scientific/annotation return; calculation-only genome
resolution; and no expansion for counts-only or source-only forms.

Every completed own action must have exactly one local observation. Redelivery
adds no observation. Selected result recalculation has its own action but gains
zero additional acquired-record credit for the unchanged original native
response. Closed launch/API/results endpoints immediately have exact-zero future
expected credit while their actual final gains remain intact. Scientific
annotation/observation records are not fabricated.
