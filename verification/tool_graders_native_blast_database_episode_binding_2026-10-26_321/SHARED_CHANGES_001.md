# E321 shared implementation changes

This is the complete shared production-file change list for E321. Exact final
byte hashes and sizes are in `HANDOFF_EVIDENCE_001.json.shared_integration`.
The four new E production modules are listed separately in that evidence file.
The behavior trace is in `WIRING_001.md`; test results are separate receipts.

| Shared file | Added behavior |
|---|---|
| `execution_episodes.py` | Construct the explicitly configured native database results/returns adapters; expose N's resource-specific request contracts; validate original inputs and selected metadata authority; route native database selectors, catalog and execution; transfer explicit references; integrate exact native fact sources, recorded forms, receipt admission and resolvers; exclude bundle sources from generic fallback authority; delegate result credit and endpoint proof. Additive010 uses qualified returnable handoffs for delivery and retains usable-only launch completion and baseline/new handoff-credit identities. |
| `execution_progress.py` | Describe the separate six-mode database target and numerical selection contract; authenticate original N plan fields and the original PBS attempt witness; expose bounded original-attempt reads. Add `returnable_handoff` only for an existing usable target or an authenticated original failed native database HPC target; retain `usable_handoff` unchanged. |
| `practical_execution_records.py` | Add N's separate requested-job schema and validation to the practical assignment; require its HPC resource kind and explicit resource identity. Preserve the original logical request. |
| `practical_execution_operations.py` | Reject a native database assignment in the local executor with the specific HPC-resource-required failure. |
| `practical_pbs_operations.py` | Validate explicit database software/producer/database bindings and project workspace/account constraints; compile the exact original attempt's N plan and driver invocation; pin plan identity in ledger/receipt; authenticate original run/episode/action/attempt/token/PBS identity before file capture; restrict reads to original selected files and reject path/symlink substitution. |
| `domain.py` | Add the exact host-only native database observation marker and the necessary literal native HSP metric names. Remove that marker from model-authored observation schemas. |
| `state.py` | Enforce the marker's tool-origin bundle source, exact program/mode, unmixed marker and query-only biological operand relationships. Frozen scientific authority is additionally enforced by E's publication validator. |
| `evidence_geometry.py` | Qualify native database records against their frozen publication before existing single/multiple extent calculations. Existing extent formulas are unchanged. |
| `evidence_axis_contracts.py` | In `native_metric_facts` only, qualify an actually received native database observation before copying its existing measurements. No axis entry, sheet, binding, rubric or formula is changed. |
| `infernal_result_presentation.py` | Recognize the host marker when omitting automatically hydrated native observations from receiver presentation. Explicit typed child returns remain intact. This pure presentation function does not resolve records or assert authority. |
| `blast_result_views.py` | Qualify the native database observation first, then return the specific biological-reference-unavailable failure for the paired/reference view. |
| `alignment_site_native.py` | Apply the same frozen-authority check and specific biological-reference-unavailable outcome in source and grading consumers. Never fabricate a paired biological reference. |

`practical_resource_episodes.py` was read and required no edit. E did not edit
`communication.py`, `form_reference_validation.py`, `episode_return_records.py`,
N/M/R modules, collection/iteration/PSSM graders, evidence-axis entries or
formulas, W05, literature, prompts, the knowledge index or accounting. Root and
the named owners made the separately accepted dependency changes documented in
their own packets. No source or test file outside the E-approved ownership list
was modified by E.
