## Behavior traced

The received bundle includes the exact sheet and ordered table identities.
Repeated table bytes preserve every population role; deduplication of receipt
handles does not shorten that scientific bundle. Control metadata is preserved
for historical proof; current physical availability is checked on new use.
Private child artifacts require an actual requested return. Mere presence in the
Store is not a substitute for receiving them.

A failed projection can retain a valid complete numerical sheet and components.
The corrected initial witness validates their joins without requiring the failed
projection to succeed. A later explicit saved selection can repair the requested
projection without reacquiring native data or earning acquisition credit again.

Acquisition uses one original native-job identity and the existing caller unit,
not the number of populations, cells or retained files. Missing native tables do
not become zeros. Practical completion requires original acquisition plus the
requested delivery, with no positive numerical-value requirement. Existing
zero-denominator values remain null. Closed receipt reads do not re-open native
inputs or reprice original credit after later byte loss.
