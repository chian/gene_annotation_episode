# RNA custody/calculation/return interfaces

This additive implementation record preserves the immutable goal, 349 plan and
addenda, frozen355 contract and root's additive007. It changes no earlier
direction, scientific formula, completion tally or provider implementation.

The six owned production modules are:

| Module | Production exports used by the shared host |
| --- | --- |
| native_rna_structure_acquisition | is_native_rna_structure_target; capture_local_rna_structure_bundle; rna_structure_source_payload; publish_rna_structure_source; ORIGIN |
| native_rna_structure_result_worker | run_rna_structure_grading_worker; run_saved_rna_structure_grading_worker |
| native_rna_structure_result_publication | prepare_rna_structure_grading; prepare_saved_rna_structure_grading; validate_rna_structure_job_inputs; validate_rna_structure_selected_inputs; validate_rna_structure_publication_inputs; publish_selected_rna_structure_rows |

NativeRNAStructureResults has the agreed applies, async execute, read_result,
read_receipt_key, facts, credit_view, result_identity, completion, resolve and
retained_reference_access methods. It binds an existing ExecutionEpisodes owner.
NativeRNAStructureReturns binds that owner's native_rna_structure_results. It
subclasses EpisodeReturnRecords and supplies received_context, received_facts,
validate_received_report, record_admission, resolve_received and
resolve_saved_rna_input. No alternative owner registry or state layer is added.

Both validate_rna_structure_selected_inputs and
prepare_saved_rna_structure_grading require the explicit keyword
`returns: NativeRNAStructureReturns`, as root specified in addendum007. The
binding passes its existing returns instance. Original input and saved operand
qualification permit the existing allow_unsaved=True construction boundary:
Workflow initializes references before saving the child's runtime_episodes row.
Saved results still require the actual original parent commission and exact
context/request plus the frozen inherited receipt prefix. Publication requires
the saved context.

Root clarified that355's "original inherited/supplied operand set" defines no
additional descriptor container. This implementation uses exactly
SavedSelector.saved_input, proved by an actual earlier descriptor-bearing typed
return in the eligible frozen lineage, together with received operand handles.
Correct source/sheet handles without that typed descriptor are insufficient.
The ancestor child commission index excludes later sibling forms, and inherited
EpisodeReceipts exclude handles outside the saved prefix. The new result
assignment handoff must equal the original descriptor handoff.

Publication directly calls PracticalReceiptInformation.read on the received
handoff. That shared reader authenticates original selected practical action,
saved outcome, source and assignment snapshot. The RNA publisher additionally
compares the snapshot's complete requested job and resource, original run and
episode, request digest, workspace/attempt path, execution identity, mode,
record key, argv/environment and actual monitor/results operations. A later
status/collect receipt may identify the same original launch; the status
receipt operation key is deliberately not confused with the bundle's original
launch operation key. The adapter independently uses owner.targets.read_target.

Original capture uses the fixed357 locator and shared materials helpers. Only
the first capture opens producer paths. It pins every path component without
following symlinks, retains whole files, preserves actual invalid bytes and
expected manifest metadata separately, and saves capture intent/plan/receipt.
Replay uses the retained manifest, original saved plan and retained artifacts.

Workers write one canonical JSON value plus newline for each full sheet,
complete component array, requested prepublication projection, diagnostics and
worker result. Host preparation executes the data worker through run_local_job
with20GiB RAM,4GiB scratch and wall_seconds=None. It retains actual stdout,
stderr, worker result and lifecycle metadata. The worker imports no RNA library.
Model/parameter-file associations are checked against the selected job and
original manifest; invalid model associations preserve independent supplied
topology with specific issues.

Native success, complete capture and qualified requested delivery are separate
receipt booleans. Failure row ordinals are frozen before the receipt, including
specific missing-selection supplements. An untrusted bundle has no scientific
source, but its original nullable-source failures remain valid typed facts.
No observation is written for parsing, calculation, binding, projection or
form construction.

Saved-sheet actions authenticate the original descriptor before opening its
sheet bytes. Receipt authority is therefore distinct from current sheet-byte
availability. Missing/corrupt saved bytes are explicit qualifications, without
capture or native execution. Saved status retains the historical observation
and emits no scientific rows/source. Saved collect keeps original source,
capture, observation and stable grading envelope while creating new complete
component and selected-view artifacts. calculation_key identifies the selected
complete component bytes. Changed parameters never rewrite the original sheet
or receipt and never introduce an acquisition identity. Root's addendum008 names
the saved completion proof's second validation key
`retained_original_sheet_custody`; original acquisition retains
`complete_sealed_bundle_acquisition`. This changes no endpoint predicate or
credit and allows saved-sheet delivery after an originally partial capture.

Only explicitly requested fact groups are forwarded. Source-only forms carry
no auxiliary files or unrequested rows. The retained-reference guard checks
source/prepared metadata and authenticated explicit permissions before generic
Store fallback; it does not open another child's sheet to decide access.
Independent original operands, actual scope sequence operands, completed/partial
own-action references and explicitly requested original child-form artifacts
remain eligible. Old recursively expanded receipt rows alone are denied.

This lane's tests use real Store, Journal, BindingContext, saved actions,
PracticalReceiptInformation, EpisodeReceipts and typed-form records. The
original producer reservation is real; its terminal scientific bundle and
observation are explicitly synthetic supplied data. Tests never start the
native producer driver or import ViennaRNA. The fixture uses the actual
ExecutionEpisodes `_target`, `_selected_result_action` and `_result_directory`
methods but supplies a synthetic target-observation port. These are component
tests, not the root-owned selected-tool→launch→local→results→parent integration.

Shared dependencies discovered during verification are owned elsewhere: root's
exact RNA registered-fact exception in communication, and360's RNA practical
schema registration plus resource/target/results dispatch. Shared receipt
nonexpansion, general resolver ordering, credit/completion consumers and final
prompt presentation require root's assembled verification. This packet does
not change the108/308 completion tally.
