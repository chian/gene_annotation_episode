# Additive construction and runtime-boundary clarification

This supplements INTERFACES_001 without changing the original receipt,
scientific row, saved-input, custody or credit contracts. Root approved the
narrow construction exception after inspecting the actual runtime ordering.

Workflow.selected calls build before saving the parent's selected child action.
Within build, initial references and the initial empty report are validated
before the child's runtime_episodes row is saved. The RNA entrypoints use the
existing EpisodeReturnRecords allow_unsaved authentication at those construction
boundaries. They still compare any existing saved context exactly.

authenticate_rna_results_commission permits an absent parent commission only
when allow_unsaved=True, the child has no runtime_episodes row, and the child has
no own runtime_actions or runtime_forms row. Its parent must be an authenticated
saved context; its role/path/canonical child_N slot and scope are validated. Its
existing EpisodeReceipts manifest must point to that actual parent and exactly
equal request.message.knowledge_inheritance, including the frozen prefix.
An existing commission must match the exact assignment, scope, role, decision
and requested schema. A persisted child, execution or publication cannot use
the exception. No additional durable record or runtime ordering is introduced.

The execute entry authenticates the strict saved original commission and the
received original handoff before reading the target, observing its status or
capturing its files. It does not use allow_unsaved. Publication independently
repeats original handoff and commission authentication at its own boundary.

Saved-input validation still requires the exact earlier typed descriptor in
the eligible frozen lineage, all four actually received descriptor operands,
the matching handoff and the authentic original result receipt. Construction
does not convert Store presence or matching artifact handles into authority.

The shared runtime appends pending_work_after_action to committed tool outcomes.
RNA receipt validation compares all five adapter-owned outcome fields exactly
and accepts only that one existing envelope extension, validated by the shared
waiting.validate_pending function. The adapter's original receipt is unchanged.

The retained-reference guard runs before generic Store fallback. A results
child whose original form explicitly requests the saved descriptor can resolve
that descriptor's exact listed operands after its own completed collect. This
does not grant its components, stdout, stderr or other unrequested auxiliary
artifacts. Root contexts legitimately have report_contract=None; requested
source extraction treats that as an absent contract. Independently returned
artifact bytes remain eligible through an actual authenticated non-RNA child
form, with original commission, frozen facts/form and report-attempt checks.
