# Pre-curation historical record

These files preserve the rejected prior catalog, including its fixed tool bundles and fixed assemblies, solely as permanent history. They are not current slot options or executable episode definitions and are excluded from active discovery. Do not run this historical generator against current content.

RECOVERY_MANIFEST.json distinguishes exact original copies from reconstructions produced by the original generator whose complete bytes match a separately saved pre-curation SHA-256. It also lists baseline files that were not recovered here. No current tool, episode, scientific support slot, numerical policy or historical run is changed by this archive.
