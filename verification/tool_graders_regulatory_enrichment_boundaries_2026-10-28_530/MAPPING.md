## `identify_transcription_factor_binding_sites`

**Exact wrapper:** `identify_transcription_factor_binding_sites(sequence, tf_name, threshold=0.8, output_file=None)`; G:851–972, descriptor genetics:228–259. Returns prose; optional TSV columns are `Position,Strand,Sequence,Score,Relative Score`, rounded to two decimals.

The wrapper GETs `https://jaspar.genereg.net/api/v1/matrix/?name={tf_name}`, selects only `results[0].matrix_id`, GETs `matrix/{matrix_id}.pfm`, parses with `Bio.motifs.read(..., 'jaspar')`, forms `motif.pssm`, then calls `pssm.search(Seq(sequence), threshold=threshold)` on both strands by default. It does not retain the search response, candidate population, selected matrix bytes/metadata, HTTP status, exact motif release/taxon, PSSM, original sequence identity or unrounded hit list. The URL/name search is not a unique TF-to-matrix association and cannot justify an arbitrary first-match choice in infrastructure. A selected exact matrix is required in the eventual invocation; supplied sequence is the scientific input, not a candidate annotation.

**Native arithmetic inspected:** Bio `motifs/__init__.py` initializes zero pseudocounts and normalized uniform background; `pwm` normalizes counts and `pssm` takes base-2 log odds. `matrix.py`:318–510 normalizes each column, computes `log2(P(base,column)/B(base))`, sums column extrema, uppercases the search sequence, scans forward/reverse-complement matrices and tests native score `>= threshold`. `_pwm.c`:15–57 sums doubles then stores float32; non-ACGT windows become NaN. Thus threshold 0.8 is a **raw log2 score cutoff**, despite the descriptor's 0–1-relative description. Native scores have no calibrated binding/function probability meaning. Zero matrix counts can yield negative infinity and make `(score-min)/(max-min)` undefined; uniform columns can give zero range. A parser must preserve native nonfinite states, not invent pseudocounts or force a finite confidence score.

**Coordinate defect:** Bio returns forward start `x>=0`; a reverse-strand start is encoded `p=x-L`. The original-forward interval is `[L+p,L+p+m)`, where L is sequence length and m motif length; the motif-oriented matched string is its reverse complement. The wrapper instead publishes `abs(p)` and extracts `sequence[L+p-m:L+p]`, the preceding window. For a hypothetical L=20,m=4,p=−14, the correct interval is `[6,10)`; the wrapper publishes 14 and extracts `[2,6)`. This follows inspected source, not a new native run. Retain legacy reported tokens as conflicting observations when importing old logs; corrected geometry must derive from retained raw positions, not from guessed recovery of the rounded TSV.

**Missing ports:** exact motif selection/acquisition identity; lossless matrix/sequence/native-result retention; common scan parameters including threshold scale, background and pseudocounts; ordered occurrence/strand/native-position joins; shared score/geometry components; typed completed-empty versus failed/incomplete scan; actual local child/result/return binding. A fetched matrix may be a separate selected input acquisition without prescribing a fixed child itinerary. No FIMO service or HOMER scanner exists in this wrapper.

**Failure behavior:** requests have no explicit status check, bounded response or timeout; missing result returns prose; imports before the `try` may fail. Other exceptions append an error and then “Analysis complete.” No structured partial list survives a later output error. Sequence shorter than motif, invalid symbols and equal/extreme matrices need explicit supported input behavior; do not reinterpret all of them as completed zero sites.
