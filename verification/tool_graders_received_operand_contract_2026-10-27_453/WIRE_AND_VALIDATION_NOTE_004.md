# Exact provider wire examples 453/004

This additive note makes the transport consequence of 453/003 explicit. It is
part of the same unapproved design packet; no prompt or runtime code was added.

Adding a marker alternative inside `sequence.align.arguments` creates a composed
argument schema. The existing `_json_tool_arguments` therefore selects JSON
string transport for that argument object. Existing episode assignments already
use JSON string transport. The readable objects in 001 and
`RETAINED_SELECTION_EXAMPLES_001.json` are the **decoded semantic selections**.
The following are their actual `decision_exchange_v1` wire representations under
the proposed schema adapter. The model-facing context remains scientific text;
the response remains the existing structured action protocol.

update is `{}`:

The surrounding `kind="episode_child"`, `role="results"`, `goal`, `scope`,
`purpose`, `schema_json`, `initial_report_json` and report update retain the
original actual contracts. No common field is generated by the operand adapter.
Its internal exact fixture assignment/form and expanded selector are copied in
the examples packet. Omitting those common fields here is a scoped fragment,
not a valid complete child action.

If an implementation chooses a different generation encoding later, it must
show a separate explicit schema/decoder contract and preserve original
semantics; that alternative is not part of this recommendation.

## Predicate order for a selected marker

1. The dispatch belongs to the exact saved receiver and decision; its generation
   schema and frozen binding association match the saved request.
2. Decode existing argument/assignment JSON using the adapted semantic schema,
   not the generation schema. Validate that adapted response, including strict
   marker keys, exact allowed positions and unchanged report-update contract.
3. Every marker names an entry actually exposed in this pending decision; the
   entry's kind and granted use match the declared slot. For saved results the
   handoff and descriptor markers are both present and select the same entry.
4. The entry exactly matches its saved requested-field/witness occurrence and
   frozen receipt prefix. Copy its ordinary values and persist resolution proof.
5. Validate the expanded response under the original exact schema. Use existing
   `Workflow.selected`/scientific execute/selected-use authority. Record ordinary
   exact actions and actual outcomes through the existing path.

None of these checks declares scientific success, chooses work, broadens scope,
changes continuation or requires a model restatement. They are deterministic
admission of the model's actual selected operands.
