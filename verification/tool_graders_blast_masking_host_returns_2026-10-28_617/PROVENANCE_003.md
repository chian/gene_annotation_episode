# Original statistics provenance audit

Generated provenance is an authenticated original producer relationship, not a
claim that a counts file is useful or native execution was successful. Admission
checks the actual retained Bundle.statistics_binding against615's full-Identity
helper, the received original source, the explicitly received statistics artifact,
and the captured original reference occurrence IDs. It never constructs a new
generated binding merely because a caller supplied one.

610/HANDOFF_001 and615's producer seal generated binding only after successful
counts creation. A failed attempt can retain useful statistics with a null original
binding. Such bytes remain valid supplied operands with unknown provenance; the
host must not promote them to authenticated_generation. This preserves partial
data without changing the original producer's qualification. No mask quality or
native-success gate is added to selected result completion.

Check072 verified the initial eight host/return checks. A subsequent audit briefly
removed the native-success condition without requiring the original saved binding.
Check076 passed that overpermissive intermediate behavior; its test expectation
encoded an implementation mistake and is not correctness evidence. Both original
runner receipts and snapshots remain unchanged. The correction requires the actual
recorded binding and captured reference custody. Revised focused check078 verifies
rejection of fabricated generated provenance while allowing the same retained
partial statistics as supplied/unknown. Public signatures and record shapes stay
unchanged.
