# Additive host input and saved-data ports

Root approved616/RETURN_GRANTS_002 and FULFILLMENT_003. There are now seven
array fact sources, including `execution.masking_saved_data`. Native Occurrences
remain native files; selected derived sheet/calculations/statistics rows have
their own exact616 schema. Source-only delivery grants none of those bytes.

The full current host surface is001 plus these changes:

- `retained_target(context, *, assignment=None, scope=None)` supports an owning
  results episode and a parent's prospective results assignment. Explicit saved
  sheet possession and its original handoff/source relationship are authenticated
  through existing frozen receipt inheritance. No native paths are consulted.
- `validate_job_inputs(context, assignment) -> list[str]` is a no-op for other
  request families. Nonnull artifact operands require actual supplied/received/own
  receipt authority and matching retained hash/size. Source-record bindings require
  actual receipt membership. Raw supplied file operands with null artifact refs
  remain valid; native capture owns their eventual byte retention. This calls
  `validate_statistics_binding(context, job)` for generated original provenance.
- `validate_selected_inputs(context, assignment) -> list[str]` is a no-op for
  other selector versions. Native selections return their actual admitted handoff.
  Saved recalculation additionally requires and returns its exact explicitly
  received original sheet, without granting a full source-grading envelope.

All calls use the existing owner ports from001. Receipt metadata is read through
EpisodeReceipts without creating another receipt writer or transaction. Existing
scientific parents/children own selections. Authenticated failed native diagnostic
delivery can complete the selected request; quality checks or native success do
not act as an additional endpoint gate.616's exact status semantics are preserved.

The new host modules export the same classes/constants/functions as001, with
`FACT_SOURCES` now imported from616's exact seven-source authority. No new prompt
template has been written. Full shared Workflow verification remains root-owned.
