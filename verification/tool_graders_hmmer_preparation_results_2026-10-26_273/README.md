## Publication correction

The initial host validator incorrectly required the artifact list to contain
only explicitly requested files. V1's agreed contract also includes actual file
dependencies of requested quantities, rows and checks. Publication now validates
the ordered explicit prefix, exact original occurrence custody, uniqueness,
population counts and required row/check references. V1 validates scientific
dependency joins against saved data in its bounded worker. No arbitrary source
auxiliary artifacts are added; no host full-sheet reparse is introduced.

An injected grade-worker startup failure leaves prepared.graded false and no
numerical artifacts. A real projection worker can still return the requested
captured file and the recorded failure. A request for unavailable numbers fails
specifically and its saved failure replays without another worker. Captured
files do not depend on unrelated numerical calculations succeeding.
