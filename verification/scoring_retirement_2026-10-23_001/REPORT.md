# Categorical scoring removal — implemented correction

The user requested: “fix all those violations.” This records the correction of
the audited categorical-score paths. It does not adopt a replacement scoring
sheet or change the permanent scientific design. **Zero of ten numerical
evidence-axis scoring sheets are complete.**

## Active code

- Removed the five default axes, applicability/relation lookup weights,
  unresolved multiplier, and maximum-based categorical evidence projection from
  `credit.py`. Retired public constructors/calls give a specific error rather
  than computing an old score. Their former constants are not defaults in a
  second hidden implementation.
- Preserved the original hypervolume product arithmetic as a pure calculation
  requiring explicit numerical components and parameters. Missing values cannot
  become zero. This is not a new biological component or aggregation policy.
- Moved the twelve unchanged extent/coordinate definitions needed by state
  ownership into `evidence_geometry.py`. State ownership does not depend on the
  retired annotation scorer. The definitions were independently compared with
  an earlier saved implementation and are identical.
- `default_scientific_binding` now records v2. Default runs retain received
  investigation progress and leave annotation scoring unbound. The explicit
  numerical annotation-score channel remains supported. The fixed-case policy
  factory also uses received findings without a categorical scientific-policy
  section. Old categorical configurations are rejected, not silently ignored.
- Export with `include_credit=True` returns an explicit unavailable result with
  `annotation_score: null`. Runtime summaries identify an unbound scorer. An
  absent scorer creates no numerical report fact, zero score or observation.
- Removed observation-kind dispatch to the five rejected axes from instruction
  metadata. A caller's arbitrary numerical function is not sufficient to infer
  its scientific field mapping.
- Old default v1 resumes require their original code. Tests verify that rejected
  root, latest-run, fixed-case and detached reconstruction attempts preserve the
  recorded bytes. Closed runs with an explicit numerical scorer return their
  original result without recomputation.
