Root supplied B2_B3_CONSTRUCTION_005 and B2_B3_OWNERSHIP_006. Both were read in
full. A well-formed wrong link must remain a raw request with local failure,
while other usable input and native measurements survive. Initial shared
validation incorrectly applied cross-object digest consensus to SourceFields
inside raw link assertions. That could reject the entire saved sheet merely
because a rejected claim carried the wrong digest.

The common validation pass now distinguishes raw execution/native/metadata
requests and representation links from admitted source evidence. It checks
their closed shapes and source-pointer syntax, but excludes those raw assertions
from global digest consensus. Actual source ContentBindings, native selectors,
copied cells, and diagnostic/requirement SourceFields remain strict. A rejected
locator stays verbatim in the raw link; a diagnostic path can identify it.
Diagnostic SourceFields must cite actual retained sources, not repeat a rejected
digest as though it were an actual source binding. Admitted links still undergo
the full contextual checks against retained native/input/metadata values.

Worker169 identified an analogous representation case: a well-formed explicit
mapping to row 999 or to the wrong comparison track should be locally unbound.
Root settled the mixed-outcome precedence explicitly:

1. An observed disagreement in any valid mapped pair yields conflicting.
2. Otherwise any unusable target or mapping yields unbound.
3. Otherwise the existing incomplete/equal checks apply.

Only actual conflicting cells from valid pairs appear in conflict_source_fields.
Bad targets retain representation_correspondence_missing diagnostics, even when
another valid pair establishes a conflict. Duplicate mappings, self-links and
malformed shapes remain invalid. Primary values are never selected, replaced
or merged by this validator. Both unavailable cells may compare equally while
their distinct native presence states remain retained; missing is not zero.

New tests cover rejected native, metadata and execution claims with wrong
digests, malformed pointers within those raw claims, strict diagnostic sources,
missing source/row/association targets, mismatched track mapping, duplicated
maps with unavailable sources, and a valid observed conflict beside an invalid
mapping. The existing rejection tests for forged admitted links still pass.

verification process was stopped or restarted. No live GenomeComparison,
