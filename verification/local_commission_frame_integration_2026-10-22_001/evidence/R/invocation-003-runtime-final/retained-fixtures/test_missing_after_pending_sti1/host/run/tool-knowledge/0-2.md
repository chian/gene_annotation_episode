Use the parent-supplied admitted handoff for this exact registered job. homology.sample returns a durable observation of its execution state, outcome, elapsed service-wall seconds and output availability/byte counts. Prior samples passed in the assignment are inherited information, not newly earned contributions.

Elapsed service-wall time is not a separately measured queue wait or native-program-only runtime. Native state and output bytes do not reveal the fraction of the search completed. An unchanged output file does not establish a stall, and a live process does not establish productive computation.

The job survives a monitoring episode yielding. The parent chooses whether and when to commission further monitoring using the returned form and duration expectations. There is no prescribed number of samples, polling interval, timeout or stop action. Timing information, monitoring credit and scientific progress retain their separately configured meanings.
