source.archive.members inventories a retained ZIP/TAR source with member identities, preserving ordinal distinctions even for duplicate names. source.archive.extract acquires one inventoried regular member. A member's archive name does not authorize a host filesystem path or identify its biological subject.

source.xlsx.sheets exposes actual sheet keys and names. source.xlsx.rows selects a sheet_key, matching-row offset/limit, optional literal where condition and explicit header_row or null. Original row numbers and cell addresses preserve native identity. Numeric/date lexical values, styles, formulas and cached values remain distinct; the tool does not recalculate formulas.

Row meaning can depend on headers, units, footnotes, sample identities and experimental conditions. Choose the additional context needed to interpret the actual question; a cell alone does not establish a measurement on the input gene. A source's annotation column remains a source assertion with its own provenance.

Article XML tables can be read through original source byte windows even when absent from the paragraph projection. The current tool registry has no dedicated XML-table reader or source-local passage-ranking tool. Choose among actual available capabilities rather than assuming those interfaces exist. Reading coverage and table size do not award scientific progress by themselves.
