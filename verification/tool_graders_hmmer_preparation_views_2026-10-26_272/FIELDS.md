# Closed HMMER preparation projection fields — 272/V1

This is the exact static path catalogue consumed by `preparation_projection_catalog(program, mode)`. It documents copied saved values; it is not an executable scoring language. Each operation below uses only its listed collections, row kinds, quantity paths and check names.

## Selection and missing values

A selector names one existing collection, an explicit row window or ordered record-key list, and the desired paths/check names. There is no default or fixed maximum result count. `calculations` means `calculations.rows`; the other collections are their exact `sheet` fields. A path declared for one row kind may be requested for another kind in the same collection; that inapplicable cell returns `value=null,state=missing,unit=null`. A declared but absent field uses its row-kind unit only when that mapping has one unit. A present saved component copies its exact value, state and unit, including nonzero incomplete/failed values. Explicit native scalar states are copied. No background, fit parameter, denominator, unit conversion or missing measurement is supplied by projection.

Catalogue `unit` is one string or a sorted unique list of the actual declared units. The row-kind table below is the exact kind-to-unit mapping; alternatives within one row kind remain alternatives. Returned quantity `unit` is nullable and copies the saved cell when it exists. For F1 native `index_parameters.payload.value`, `bin_length` has `index_symbol_count` and `suffix array sample rate` has `suffix_array_sampling_interval`; `alphabet` and `input is asserted to be` are categorical rows and return null/missing/null for this numeric path.

## Retained data and provenance

Full saved D1 sheets remain retained. Native sequences, alignments, probability arrays, per-position/column tables, score vectors, tracebacks, XY series, calibration tables, FM packed arrays, interval/mismatch tables, dynamic E1 symbol-count tables, original tokens, inputs and arbitrary diagnostics do not cross this scalar projection. Their aggregate scalar components remain selectable below. The unit is the native or calculator's actual unit; generated scores and samples are never described as biological measurements or annotation confidence.

Checks are copied by the exact saved row relationship. Every matching instance remains separate, including contradictory outcomes. A requested absent check is `unknown` with no occurrences. The check-name lists are closed family vocabularies; they do not assert that each name exists for every row. See [IDENTITY_HANDOFF_001.md](IDENTITY_HANDOFF_001.md) for E1 model/consensus, S1 scope and F1 null-key exceptions. Artifact references disclose only explicit selections or operands required by the selected row/cell/check. Aggregate rows have no fabricated single artifact. Original occurrence IDs, roles and ordinals distinguish identical bytes in different roles.
