# GenomeAlignment D/E/F contract package

Ready for root review; no production implementation or shared integration changes.

1. `D_CONTRACT_001.md`: closed v2 numerical sheet/components, explicit CalculationPlan and stable per-request outcomes, exact calculator/builder signatures and saved-validation boundary.
2. `D_TARGET_ERRORS_002.md`: exact per-native-function ValueError allowlist for local incompatible requests; every unlisted error propagates.
3. `NUMERICAL_CATALOG_001.md`: every existing numeric field, exact locator, formula/source, units/denominator/state and real native numerical examples.
4. `E_CONTRACT_001.md`: actual pure facade, C retained_records forwarding, closed parameters/requested facts, saved projections and exact completion dependencies.
5. `F_CONTRACT_001.md`: finite typed fact families, immutable publication validation, EpisodeReturnRecords original-task/parent/child custody and named root-only consumers.
6. `OWNERSHIP_AND_VERIFICATION_001.md`: disjoint new files/tests, exact producer outputs/consumers, required verification cases and honest unverified gaps.
7. `SOURCE_HASHES_001.json`, `PIN_DEPENDENCIES_001.json`, `VERIFICATION_001.json`: source identities, actual observed dependency closure and execution evidence.
8. `offline_probe_001.py`, `OFFLINE_EXAMPLES_001.json`: small executed neutral-output probes and full numerical results. They do not implement D/E/F.

The critical additive fix is a complete ordered plan and one recorded outcome per stable request ID, including missing/invalid-target requests. Later successful numbers cannot move into another request's slot. Original native documents and C values remain saved so new explicit parameters can produce a new sheet without parsing/acquisition; saved result reading validates relationships without rerunning scientific calculations.

Root may hand D/E/F to independent coding contexts after reviewing the corresponding contracts. Root alone owns registry/host/API/execution/tool-library/progress integration. Frozen002 and existing A/B/C/XMFA value shapes are untouched. Native-only counts remain useful with explicit missing source/census/join qualifications. The current service's missing same-run witnesses and legacy v4/XMFA visualization issue remain unverified/unfinished; this package does not declare the fixed row complete.
