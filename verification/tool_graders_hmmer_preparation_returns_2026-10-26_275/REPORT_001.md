## Ownership and data path

An already selected `execution.results.status` or `.collect` action is matched to
its exact runtime action and frozen results assignment. Collection observes the
original target, captures C1 once, prepares G2 retained numerical artifacts,
publishes only the requested V1 facts, and saves a HMMER-specific immutable
acquired-result receipt and reference index. The body has exactly the261/R1
fields. Validation checks the saved episode, scope, target, intent, observation,
source payload, capture, prepared custody, selected publication, failures and
completion flag. Existing receipt validation cannot initiate a first capture or
worker execution.

Complete numerical arrays and sheets remain retained files. G2 authenticates
compact custody and selected projection receipts; these R1 modules never hydrate
complete numerical artifacts for form validation or reference membership.
`occurrence_id` is used throughout. Binary native stdout remains an artifact;
C1 source `text_ref` stays null.

Received facts are matched to the original immediate-child commission, original
scope/role/form/assignment, successful report delivery, frozen facts and exact
frozen form. Scientific forwarding carries only requested information actually
received from that immediate child. Redelivery does not revise an earlier frozen
form after later descendant deliveries. Exact repeated facts are deduplicated;
distinct producer source identities remain distinct. Generic execution-result
references remain available to other providers. Source custody alone does not
grant access to unrequested auxiliary artifacts, private child history or scores.

## Failures, partial results, credit and completion

Valid native partial output remains returnable with its native failures. A
missing manifest returns a completed acquisition action with no result source and
specific capture failure. If grading raises, its operational exception diagnostic
is retained separately, its typed code is sanitized, and original native failures
still appear. Failure rows validate native locator/code/stage agreement and exact
capture-file locators. Native preflight remains `preflight`. A failed query line7
identifies the unique selected queries operand at its actual artifact ordinal0;
ambiguous multiple source operands remain affected:null.

Only the caller's existing acquired_record_unit and handoff_unit are used. One
original bundle earns at most one acquisition unit within the results episode;
files, cells, checks and workers create no extra credit or observations. A
successful original native attempt, completed observation, complete capture and
all requested selections establish practical completion. Numerical selections
require graded=true. Artifact-only selections may complete when unrequested
grading failed but the requested artifact publication succeeded. Unknown cells
and failed diagnostic checks are not scientific acceptance gates. The completion
proof feeds the existing PracticalYieldEstimator exact-zero path, preserving the
final actual gain without an extra zero action.
