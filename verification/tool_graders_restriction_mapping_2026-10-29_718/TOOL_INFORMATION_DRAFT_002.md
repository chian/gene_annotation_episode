# Proposed restriction tool-information instructions

Draft only,2026-10-29. Not implemented, approved or a scope/goal amendment.
The original user attachment remains authoritative. These are the selected
tool-instruction contributions to the recurring TASK, not a replacement for
the scientific mother's parent assignment, scope, A/P process guidance or
typed return. The common native producer/reader is separate from this text.

The feedback boundary is docs/TASK_AND_STEERING.md: "The user requires seeing
each proposed template and providing running feedback before it is treated
as settled or implemented." No new STEERING renderer is proposed here.

## Decision/information trace

The recipient is the constructed scientific process using these selected
local supporting operations. It decides whether a restriction search or a
comparison of retained results helps its assigned molecular question, which
allowed enzyme/topology operands to select, and how to repair specific input
failures. It retains its own iteration/controller; the text prescribes no
itinerary, count, timer, retry or resource substitution. The source investigation
can begin from supplied DNA/file/snippet. Instructions are not target evidence.
Native positions, match counts, unknown geometry and exact queried populations
have different meanings; requested typed facts come from the retained result.
Machine identities, hashes, receipt controls and raw dictionary JSON stay in
host records. Previous work belongs in separately selected factual STEERING.

Both proposed entries have resources="local". Their names/descriptions must
be exposed only when the actual bounded operation and requested-return path
are installed and verified; this draft does not establish that capability.

## find_restriction_sites

Description: Find native recognition matches and reported restriction positions
for an explicitly selected enzyme set on supplied DNA.

Complete proposed instructions:

Find recognition matches and reported restriction positions for the selected
enzymes on the supplied DNA. Start from the supplied sequence, selected file
contents or snippet; no searchable name or candidate annotation is required.
Use exact enzyme names and explicit linear or circular topology. This
operation's compatibility default is circular; retain topology as a processing
assumption when source metadata does not establish it.

Use the retained input and selected native catalogue. Examine requested enzyme
results, compare explicitly selected searches, or repair a specific invalid
input or selector when that addresses the assigned question. A completed empty
list applies to that searched enzyme, input and topology. Keep missing, failed,
omitted and empty results distinct.

Keep the recognition motif separate from native diagram text or an unavailable
diagram. Known-cut positions are one-based first bases after cleavage. NoCut
entries report recognition starts with unknown cleavage geometry. Derived
zero-based boundaries and canonical circular coordinates are separate from
raw positions. Two cuts can come from one recognition event; duplicate
positions do not establish event identity.

Return only the parent's requested typed facts from retained records, including
relevant qualifications and unknowns. These are conditional sequence predictions,
not measured cleavage or gene-function confidence. Use recorded facts for saved
readings and returns; a read or replay is not a new native search.
