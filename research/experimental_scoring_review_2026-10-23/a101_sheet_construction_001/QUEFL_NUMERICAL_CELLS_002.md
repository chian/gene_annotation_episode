## Exact comparison

The reported domain-level range compares eight archaeal QueF-like proteins with
the C-terminal half of bacterial Vibrio cholerae QueF. A different reference,
Bacillus subtilis QueF, supplies four named pocket positions. These references
and scopes cannot be exchanged when filling a denominator.

For the explicit source-data calculation, the selected Pyrobaculum calidifontis
record contains 109 amino acids. Its introduced expression in an E. coli

The bacterial reduction reaction, reported through earlier cited work, is not
automatically the archaeal protein's reaction. No future target-to-reference

## How these observations must affect the calculation

These components answer different questions about an annotation. The 4/4 value
can describe retention of the selected substrate pocket. It cannot by itself
support transferring the bacterial reduction mechanism, because the associated
cofactor signature is absent in the supplied full record. Equally, multiplying
4/4 by the zero signature count would erase the shared pocket information and
wrongly make the entire A101 contribution zero for every possible function.

The sheet therefore needs component scope tied to the particular inferred
function: shared substrate-recognition features and exact reaction/mechanism
features are separate numerical inputs. They may contribute with explicitly
defined coefficients to that function's score, but no coefficient or overall
function probability is identified by these observations alone. A list of site
counts is not a completed scoring sheet. Native-score and whole-axis combination
work remains required and is tracked as unfinished.

For an actual consistent alignment, the already defined count product remains
usable: paired identity times paired-query fraction equals identical residue
count divided by supplied query length. Here it cannot be filled: the group
identity range does not define the exact identity count or alignment extent.
The reported 89–107 superposed C-alpha atoms are not substituted for a sequence
alignment denominator. The 1.5–3.1 Angstrom RMSD belongs to structural comparison;
the structure-guided sequence mapping and that structure are linked evidence.

## Coordinate, domain and missing-data handling

The main paper's B. subtilis site numbers 55/62/70/97 correspond to sequence-byte
positions 56/63/71/98 in the supplied record. The query positions are
21/28/36/63. Both coordinate systems are retained; the cause of the offset is
unknown. A reader must populate mapped positions and actual residues rather
than trusting a printed integer alone.

In bimodular bacterial QueF, the signature belongs to the N-terminal domain;
Figure 2C displays the substrate-pocket-bearing C-terminal region. Absence from
that displayed fragment cannot be counted as absence from the full reference
protein. The query's absence calculation instead uses its supplied full record.
For an arbitrary snippet, an unevaluated region remains unknown.

The exact targeted reader fields must include compared sequence/region, native
score type and value, actual match/coverage denominators, the predefined site
set and mapped symbols, scope/completeness of a motif scan, and reference-function
grounding. Provenance supports those numerical cells but is not itself a score.
Unknown score, denominator, function specificity and coordinate convention are
different missing inputs; none is replaced by an intuitive relevance grade.
