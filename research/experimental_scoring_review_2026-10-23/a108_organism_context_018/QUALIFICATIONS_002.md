# Additive qualifications to the organism-context proposal

1. The published examples' “1/1” notation displays one resolved contextual
   event for one specified organism, not a statistical estimate from a random
   sample of organisms. Its interpretation is a logical compatibility component.
   It must not become a prevalence, confidence or universal applicability weight.

2. The porphyran route component is a narrow literature interpretation, clearly
   conditional on the named gut-resident organism and a dietary route. It is
   not direct measurement of local porphyran exposure. The complete sample score
   remains unknown when exposure is relevant and missing. The 35/40 expression
   coverage and harvest-density ratio are retained boundary checks, not A108
   scoring terms.

3. The Cdv paper establishes a native constriction-site context but does not
   supply an endosome census. Its [0,1] endosomal-context result is deliberate.
   A zero based only on the word “archaeon” is not supported by this inspected
   source. The paper's earliest bands also prevent treating already separated
   nucleoids as a necessary precondition for every Cdv assembly observation.

4. O and C answer different biological questions. The proposed question-kind
   handoff is an explicit design extension requiring the user's judgment before
   adoption. It does not silently rename O as the old exposure fraction, and
   it does not claim that one scalar expresses every aspect of organism biology.
   Concrete organism traits and narrow contextual relations are now calculable;
   unstructured “typical for this clade” prose remains unscored until its
   biological referent is defined.

5. The fixed fixture's first whole-scope exclusion entry merely stipulated the
   Boolean result. `arithmetic_additional_receipt_002.json` separately applies
   the necessary zero predicate to every observed state and the unresolved
   remainder, then performs the OR. This is a meaningful propagation check,
   still entirely synthetic and not a reader implementation.

6. The workspace is not a Git repository: the attempted scoped `git status`
   returned that error. No Git preservation audit is claimed. Every successful
   write in this task targeted this new owned folder. No existing research file
   or authority was edited; primary text elsewhere was read only.
