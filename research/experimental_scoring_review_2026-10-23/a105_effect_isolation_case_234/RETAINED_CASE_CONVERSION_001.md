# Conversion boundary after retained-case reset

The retained case identifies an activity-attribution question for the actual Aquifex HFP preparation. It supplies qualitative control relationships and a primary reference, not a measured same-scale contaminating rate suitable for the existing g cell. The primary paper must establish the actual subjects, preparations, endpoints, observation times, source controls and any numerical separation before a subtraction or multiplier is proposed.

The existing assay/compiler can subtract a separately measured, matched-scale contaminating contribution and propagate supplied joint covariance. The product/coupling section separately preserves product identity, reporter activity and dependence. Neither code path makes a contaminant identification into a measured contaminant rate, and a reported product is not molecular attribution. Useful new extraction therefore needs contributor identity/control provenance and the actual measurement relationship, while preserving native signal and unknown quantitative attribution. No overall category weight, false zero, assay count or new scoring policy is proposed by this boundary. Primary verification and its own full reset come next.
