# Tool implementation inventory

- [SCOPE.json](SCOPE.json): 308 fixed tool, mode, collection, provider and resource qualification rows, with 288 intended resource bindings.
- [WORK_STATUS.json](WORK_STATUS.json): component status and retained verification history for the fixed rows.
- [CHECKLIST.md](CHECKLIST.md): readable tool and resource rows.
- [SOURCE_ALIASES.json](SOURCE_ALIASES.json) and [SOURCE_MAPPING.md](SOURCE_MAPPING.md): source observations and wrapper mappings.
- [COVERAGE.json](COVERAGE.json): inventory coverage counts and unresolved source mappings.

The execution receipt directories retain historical requests, receipts and logs. Source mappings distinguish acquisition, analysis and transport; a mapped source does not establish deployment or an integrated result.
