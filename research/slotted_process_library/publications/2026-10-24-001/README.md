## What is in each evidence-axis entry

`investigation_instructions` is the detailed recurring investigation text.
`name` and `description` support discovery. `entry_version`, `id` and `slot`
identify the host-side record. `evidence` preserves the source-to-instruction
provenance. These are the record's only fields.

The child instruction projection contains the selected name and complete
investigation text. It contains no scoring sheet, grading formula, qualitative
point scale, reader implementation or instruction-provenance observations.
Source rows can be inspected through the existing explicit provenance lookup;
they are not acquired evidence about a future target and create no biological
observation or annotation credit.

All 268 A-entry provenance rows retain their original JSON values and order
from publication 2026-10-23-002. All nineteen P files retain their original
bytes from the existing research entries, including their 76 provenance rows.
`option_sources.json` therefore contains 344 rows. `SOURCE_PROVENANCE.json`
records the exact retained source files and their hashes.

selected STEERING block. TASK contains the mother instructions, parent job,
scope and constraints, supplied material, selected evidence-axis instructions,
