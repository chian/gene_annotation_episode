## Notes on the proposed fixes

- **E1.** `_load_snapshot` has to build the snapshot class of the service it calls, or the shared root needs its own
  minhash service. All ten tests use an empty selector for the failing step; their later steps were not exercised, so
  they may stop next at r2f C06 (`source_admission_before`).
- **E3.** The test builds the top-level class and uses the top-level `MolecularSequenceInputBindings`, which is what
  the top-level tool requires for the receiver. So the mismatch is inside product code, not in the test.
  `tests/test_reference_edit_outcome_tools.py::test_generic_own_facts_authenticate_producer_and_redisplay_then_freeze_literal_group`
  (not in this work list, `assert None == {...}`) fails the same way in run 005.
- **E5.** A plain tree copy is not an option: the package directory is 4.7 GB. The copy needs top-level `*.py`, the
  `episodic_workflow/root/a101` modules, `a101/library` and the package `__init__.py` files. The exact set the
  isolated subprocess imports was not established, so this fix is not a one-line change.
- **E4.** Restoring the gate is excluded by `AGENTS.md`. A memory version would use two jobs that each request more
  than half of `limits.memory_bytes`.
