## One product change that is not a removal (say if you want it reverted)
`_materialize_text_arguments` in the 14 `published_evidence_assessment/**/source_operations.py` copies called
`repository._native_source(context, ref)`, a method `LiteraturePartnerRepository` never had (only the rate
repository has it). At HEAD this was hidden because every caller that reached it supplied the legacy quoted
witnesses, which need no source read. With quote inputs removed, `literature.partner.populate` and
`literature.partner.source.populate` raised AttributeError for every call. I changed the call to
`repository._source(context, ref)` (same received/scope/assigned-page checks). Without this change 21 test cases
that passed at baseline fail.
