## Product changes that are not plain removals (say if any should be reverted)
1. `_materialize_text_arguments` in the 14 `published_evidence_assessment/**/source_operations.py` copies called
   `repository._native_source(context, ref)`, a method `LiteraturePartnerRepository` never had. At HEAD this was hidden
   because callers supplied the legacy quoted witnesses, which need no source read. With quote inputs removed, both
   partner-populate tools raised AttributeError on every call. Changed to `repository._source(context, ref)` (same
   received/scope/assigned-page checks). Without it, 9 cases that passed at baseline fail.
2. `runtime._recorded_assignment_transport` (coordinator ruling 2): pa107c had made it require the transport proof on
   every saved decision, which would refuse every exchange-protocol replay (those requests are saved with
   `decision_protocol` and no proof, `runtime.py:758`). It now refuses a proof on an exchange-protocol request
   and requires a valid one on a direct request, the same body as a103.
3. Nine model-facing strings in five `*_tool_info.py` files and three `knowledge/*.md` files said "20 GiB RAM/memory";
   they now say 5 GiB (pa107c had already changed six others).
4. Late sub-slot handoffs applied by me: `runtime.py` controller keys no longer list `window_size`/`subsample_size`;
   the dead `restore_saved_process` lookup in `Workflow.build` is removed; `execution_prompt.py:40` no longer lists
   `rfam_batch_result_selector_v1`.
