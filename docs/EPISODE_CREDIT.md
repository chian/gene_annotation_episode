# Inspecting the current credit operands

For a new run with a separately bound annotation-support projector, scientific
episodes also have `episode.annotation_score` when that projector exposes
`read_details`. It accepts the same explicit `limit` and `offset`. Its result
names the scalar `annotation_score` and includes the actual
`annotation_score_binding`, policy and operand pages. This is the detailed view
of the annotation score already supplied in decision context; `episode.credit`
continues to describe the independent local credit binding. Neither read
chooses a new scorer or awards progress for inspecting its operands. A selected
successful read has one ordinary-action observation of the actual progress
change, usually zero. Job roles do not acquire these scientific detail tools.

Eight checks passed in 26.09 seconds across annotation-score separation and
existing credit-detail reads. They exercise the real Store/hypervolume, a
synthetic positive progress flag during annotation decline, explicit annotation
operand reading with no additional semantic records, exact ordinary-action
accounting, parent-defined frozen form facts, policy recovery and existing
credit-reader failures. The progress flag remains a fixture; no production
investigation-progress contribution rule is established by these checks.

`episode.credit` is an ordinary read available to an Episode when its actual
run-bound projector declares detail support. The native binding uses the same
projection function, frozen policy and assigned scope for this read as for its
current scalar and evidence-vector inputs. It does not select another policy,
expand the assignment, change scientific state or make a scientific assessment.

The selected arguments are exactly:

```json
{"limit": 10, "offset": 0}
```

Both are required nonnegative integers. There is no hidden maximum page size or
default detail budget. A zero limit returns summary/page metadata only. The
supplied offset applies independently to `source_contributions` and
`inactive_dependencies`; their separate `total`, `returned` and `next_offset`
describe their actual pages. An offset requires an explicit limit at the
projection API too, rather than silently selecting a default detail page.

The returned record includes the current scalar, evidence axes, actual policy,
scope and fixed target denominator. Source rows retain their current annotation,
hypothesis, assessment, observation, source and contributing original intervals.
Read-library intervals retain the original `member_ref` and member-local bounds;
equal coordinates on two different reads are different positions. Native operand
bounds and inferred attribution retain their existing distinct meanings. These
operands explain the progress proxy; they do not establish biological accuracy.

`detail_pages.state_basis_sha256` identifies the projected current-state basis.
It permits comparison of pages against that basis; it does not freeze later
calls into an old snapshot. If relevant state changes between calls, a later
page may have another basis and should be interpreted accordingly. The native
projection uses disk-backed intermediate tables and streams current records;
requesting a large page or projecting a single large scientific record can still
produce a large result. No global memory or throughput bound is claimed.

Native Episode scalar/axes reads explicitly request a summary for both scalar
targets and read libraries, avoiding materialization of unrequested operand
archives. An explicitly selected `episode.credit` page uses that same sparse
projection with the requested detail size. The public projection API retains
its historical unpaged scalar-detail behavior when called without detail paging
(`details_limit=None`). No
new evidence axes, weights, quality thresholds, hypervolume formula or numerical
continuation rule are introduced by this read.

A successful selected read passes through the existing ordinary action journal
and receives one own-action controller observation with its actual signed gain,
normally zero. The read helper itself creates no observation. A shared score
refresh, page row or nested scientific contribution creates no additional turn.
Failure returns `credit_details_read_failed` with the actual exception type and
operational detail; it creates no completed-action observation. Scientific rows
and current revisions remain unchanged.

A caller-injected projector must explicitly expose its callable `read_details`
capability. Without one, the catalog does not advertise this read. The runtime
never substitutes its default policy for a custom projector. A declared reader
failure is reported to the owning Episode so it can choose its next work; it
does not trigger a fallback scorer or an extra model/composer call.

Focused checks use actual local sequence/profile observations with explicitly
scripted interpretations and synthetic continuation controllers. They exercise
nondefault policy fidelity, fixed scope, member identity, page provenance,
failure feedback and ordinary accounting. They do not demonstrate model
scientific judgment or child-to-parent improvement.


Material-context allocations use projection v7. Each current assessment and
annotation retains an immutable nonempty `context_account_scope` and an actual
revisable `context_scope`. These masks identify original targets, frozen selection
unions and optional exact member-local intervals; they never identify a joined
sequence. Explicit empty allocation withdraws the current contribution in the
same CAS lineage. Missing allocation is unlocalized, distinct from withdrawal.
Equivalent selection syntax has one semantic identity and causes no duplicate
account or no-op revision. Historical revisions remain immutable and exact old
assessment links become inactive after correction as they already do elsewhere.

Actual observation kind continues to choose its evidence axis, including direct
growth/chemistry assays on their actual sample subject. `whole_input_context`
no longer suppresses empirical, mechanistic or discrimination components. No
axes, weights, applicability/source semantics, hypervolume or controller rule
change. Compact context cells and local molecular intervals compete under the
same explicitly declared whole coherent-account envelope on actual eligible
positions. Partial masks do not receive independent additive credit. The fixed
scope denominator remains unchanged. Summary and operand pages share one frozen
projection basis; requesting details does not synthesize completed actions.

Context operand rows name `attribution_space=material_context` and
`contributing_context_segments` separately from physical `footprint` and native
measured operand/source coordinates. Full context summaries use an implicit
baseline without creating scientific subjects for untouched reads; exceptional
wholemember groups and actual interval sweeps use temporary disk tables. Empty
current allocations remain part of the state basis and visible through their
account domain, so parents can receive actual withdrawal facts. JSON export
retains masks, exact selection handles/indexes and provenance; GFF emits no sample
context chromosome. No new scientific restriction or result-approval process is
introduced by this representation.
