# A104 evolutionary history and phylogenetic placement

A104 investigates placement among characterized relatives and agreement between
family and organismal histories. It preserves paralogs, mixed activities,
sampling, uncertain branches and unresolved historical causes. An unrooted tree
does not establish ancestry or horizontal transfer. An acquired protein name is
a search lead, not experimental characterization.

`A104Subtree` commissions the recursive scientific tasks in
`a104_investigation.py`. Scientific descendants remain A104. Shared-parent
information records carry both facts and exact unmet needs; A101, A102, A103 and
the existing A105 remain independent scientific siblings. The shared execution
parent owns HPC work and returns original results to A104.

| Operation | Actual operands and measurement | Automatic scoring attachment |
|---|---|---|
| `phylogeny.prepare_analysis` | Received exact protein parts, original regions, taxon/copy identities and explicit model/seed choices | New frozen native operands; zero scientific credit |
| `phylogeny.request_analysis` | Host-frozen sequences, regions, program and parameter hashes | Shared HPC need; zero scientific credit |
| `phylogeny.import_hpc` | Original submitted plan, PBS receipt, compact result bytes and completed collection action | Exact request/worker/input/MSA/tree custody; zero placement credit |
| `phylogeny.inspect` | Received native tips, splits, taxon/region bindings and cross-analysis relationship identities | Read only; branch ordinals stay local to each analysis |
| `phylogeny.measure_placement` | Selected original split and its actual bootstrap population | Original target-to-region-to-MSA-to-tip identity; native support and matched extent |
| `phylogeny.compare_histories` | Original family and independently inferred reference trees, explicit unique taxon/copy join | Actual restricted split comparison, RF distance, support, omitted taxa and reference assumptions |
| `phylogeny.clade_functions` | Particular measured native clade plus received existing A105 worksheet and assayed-subject links | Per-reference native MSA identity/extent and actual experimental characterization; unknowns and mixed activities retained |
| `phylogeny.compare_placements` | Genuinely different original analyses on the same target region and member scope | Measured common/union membership and minimum support; competing analyses are retained |

Robustness compares the same physical reference-group question across models,
or genuinely incompatible splits. Distinct compatible edges can coexist in one
unrooted tree and cannot establish instability. Inspection's
`corresponding_relationships` groups exact members and regions across analyses;
it provides the correct local split index for each occurrence. In real MJ0044
data the same six-member relationship is LG split 9 and MFP split 8, whereas
MFP split 9 is a different compatible edge. New comparisons reject that ordinal
mix-up instead of interpreting its zero group overlap as model disagreement.

The native leaf runs MUSCLE and IQ-TREE sequentially on a PBS compute node.
Independent markers are aligned separately, then concatenated with explicit
NEXUS model partitions. Original commands, software byte hashes, MSA files,
Newick trees, reports and all bootstrap trees remain on the allocation storage.
The compact result preserves original sequence mappings and split counts. The
reader accepts equivalent implicit and explicit full-target scope geometry,
while requiring exact agreement between the original HPC ledger and receipt.
Partial scopes, different runs, changed operands and substituted native bytes
remain separate failures.
The shared HPC service owns submission, calendar monitoring, recovery and result
acceptance. Operational forecasting/acceptance credit is separate from A104.
The shared `hpc_prediction` and `hpc_execution` sisters keep one owning ledger.
A104 supplies actual sequence/residue/analysis counts, worker threads, marker
partitions and model-selection workload, plus an implementation/parameter
profile for compatible history. Broad CPU/RAM priors are explicitly priors;
PBS accounting supplies measured demand and prospective forecast validation.
Unknown allocation capacity stays unknown. Frozen examples use the configured
repository-level shared execution memory, not a snapshot-private default.
A104 commissions attach the existing durable monitor controller at handoff,
with observation intervals of 60–120 seconds. These intervals schedule status
checks; they do not stop research or expire a job. A legacy commission without
that attachment receives recorded recovery feedback directing its parent to
monitor and collect the original job, without replacing it.
Closed-child replay keeps the original typed form separate from the receiver's
automatic attribution records. Additional receiver records must match that
action's frozen completion evidence, original receipts, scope and unit identity;
replay does not rerun a producer or grader or grant new receipts.
The implemented organismal proxy requires the original matching L2/L3/S3
metadata and taxon identities, with inputs distinct from the family panel.
Relabeling the family analysis cannot create independent history evidence.
New work definitions travel as immutable host-issued commission Sources to the
same HPC parent. Source, scope and configured-resource grants are checked before
commissioning, and execution sisters retain that original commission identity.
Completed native subanalyses from a confirmed failed work unit may be admitted
with their original failed receipt; missing analyses remain explicit and the
failed portfolio does not receive operational acceptance credit.

Publication runs the native grader. Actual receipt runs the per-use attribution
grader before numerical projection. `episode.credit` only reads existing host
grants. A newly received A105 link may qualify its corresponding already measured
clade use; it cannot create a placement or history measurement. Whole-protein
assays cannot characterize an arbitrarily selected proper subregion.
An assayed construct with a different record identity can qualify a panel
reference only when received complete amino-acid sequences are identical and
unambiguous. That per-use comparison retains the original assayed subject,
sequence hashes, observation and conditions; repeated uses remain one assay.
Other construct/reference mappings remain explicit information needs.

For each assigned original-region cell, `p`, `h` and `c` are respectively
placement, actual history comparison and experimentally qualified native-clade
progress. Compatible contributions within a coordinate use max pooling;
competing analyses and incomparable qualification sets remain explicit.

`A104 = ((1+p)*(1+h)*(1+c)-1)/7`

The assigned length weights cells. Root composition remains
`product(1+C_axis)-1`, so a missing axis does not erase another axis's progress.
Neither score is a function probability. A measured conflict can earn
investigation progress while its biological cause remains unresolved.

Run the examples through `tools/one_workflow.sh`, one workflow per Codex window.
Local limits include Python, model-provider processes and descendants: one CPU,
5 GiB RAM and zero swap. No elapsed-time, action, token or
cumulative-usage stopping budget is installed. PBS walltime is an explicit
scheduler resource request, not a local research deadline.
The A104 model view lists available fact names and meanings and carries full
schemas for the actual requested facts. Other exact types remain available
through the existing return-contract lookup. Model workers retire between
decisions, with durable history restoration, to release local process and
prompt memory. This changes process ownership, not scientific stopping.

`examples/a104_evolutionary_investigation.py --integrated` exercises the typed
A104 need, shared-parent HPC commission, original result admission and scientific
followup. Without that flag it labels original authenticated native evidence as
retained and runs fresh scientific decisions. Reusable molecular inputs live in
`tests/fixtures/a104/`; disposable execution output belongs under `runs/`.
The validation example declares a scientific continuation cost of 0.05 in the
normalized progress units, using the ordinary numerical marginal-yield
controller. This is separate from machine bounds and is not a deadline or
usage budget. A104 scientific episodes do not idle on calendar waits for their
own suspended annotation parent. Operational HPC children retain the existing
real-job monitoring and durable calendar wake machinery. Other biological axes
still belong to separate investigations commissioned by the shared parent.
