# A105 (experimental_activity_evidence): graders, subscoring sheets and scoring sheets, old against new

Scope, as the owner narrowed it on 19 November 2026: only graders, subscoring sheets and scoring sheets. That
covers grader definitions and prompts, sheet schemas, cell components, sheet columns, how a grader fills a sheet,
and which sheet an episode writes. Goals, instructions, credit, yield, thresholds, tools and messages are out of
scope. Only the owner's decisions are tracked; old machinery (repositories' ledgers, receipts, validators) is not.
Nothing here was changed in code and no Python was run.

**Best version.** From `6a02e91ba` to `97308b94c`, every grader and sheet text below is the same (checked by
constant-by-constant comparison; only import paths and `from __future__` lines differ). The import `b5d7c94e2`
has an earlier, shorter assay-grading prompt (9389 bytes against 15815). It lacks the paragraphs on
`investigation_finding`, the `source_number` / shared-header-unit route and database selectors. For every
item, the best version is therefore `60889621e` (the same as `97308b94c`). Paths below are given at `97308b94c`,
where SEE stands for
`root/a105/experimental_activity_evidence/published_evidence_assessment/evidence_search_strategy_improvement/source_relevance_assessment/source_evidence_examination`.

**Which version is more articulate.** For the grader and reader prompts, the old version is. For example, the old
`ASSAY_GRADING_TASK` says "Select the grader by the experiment's protocol and question, not the reader's format".
The only text the model is shown now is the tool description, which says just "Select scientific
applicability by protocol, quantity and design". The schemas, criteria and formulas are word-for-word the same in
old and new.

**Main finding.** The grader definitions, sheet schemas, criteria, formulas and combination rules are all preserved
in the library. The owner's prompts were different. They say what each grader grades, how a sheet is filled and
what is kept apart, and none of them reaches the model of any A105 episode now. In the old code they were shown
through the per-family table in `tools/literature_task_families.py` (`_ROWS`, plus `A105_ASSAY_SELECTION_TASK`) and
the decision prompt in `prompts/literature_task_selection.py` and `prompts/literature_experimental_prompt.py`.
Today they survive only as copies inside
`SEE/messages/internal_summary.py` (289 KB), in a decision-prompt renderer that its own docstring says "is not wired
into `decide`" and that is built on `_NotCarried` names that raise.
