## Sheet decisions the owner wrote that no commit ever implemented (design only, not lost)

These are in convention 015 (`research/.../a101_complete_sheet_015/CURRENT_PROPOSED_SHEET.md`, unchanged at HEAD).
No compared commit's code implements them; `a101_scoring.py` from 1019717c3 to now emits only the native channel and
marks the rest not assessed (`'function_specific_index': {'value': None, 'status': 'not_assessed', ...}`). They are
listed so they are not mistaken for lost code. Home when implemented: `episode_support/grading/sequence_homology_evidence/scoring.py`.

| Decision | Exact text (convention 015) |
|---|---|
| A competing incompatible function lowers the index by an explicit penalty, printed apart from support | "H_d is observed correspondence support; X_d is the explicitly defined penalty for overlapping observed alternative-function correspondence; C_d is the remaining index. Native evidence and its contradiction stay printable separately." |
| Feature panels qualify a function; a necessary feature is separate and cannot be compensated | "An independently established **necessary** sequence feature is stronger than a merely associated motif. Necessary predicates form a separate, deduplicated set and are not also included in A_F." / "A contradicted indispensable feature cannot be compensated by a large bit score." |
| Two named outputs, fixed in the calculation record | "homology_only_index(F) = C_native,F" / "feature_qualified_index(F) = C_native,F * A_F * V_F." / "An unfavorable site cannot trigger a silent switch to the homology-only form." |
| Every cell carries value, unit, origin, bounds and status | "Every numerical cell has value (finite number or null), unit, origin (reported/derived/synthetic), native printed token when present, lower/upper bounds when available, and status." |
| Unavailable included analysis gives bounds and a null point | "Its unknown contribution needs an explicit availability envelope ... The selected calculation point is null." |
