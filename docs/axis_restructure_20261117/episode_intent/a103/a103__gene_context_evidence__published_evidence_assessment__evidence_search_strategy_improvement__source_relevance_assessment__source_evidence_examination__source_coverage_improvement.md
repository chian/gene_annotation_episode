## What this episode is for

Its goal, in its own words (`goal.py` with `source_contracts.py`):

> For A103, identify the actual locus and genome before using a source claim. Keep neighboring-gene identity, order, orientation, spacing, fusion, cooccurrence, and alternative explanations tied to their source and scope.
>
> Investigate the source in document order as useful for the assigned question. Use returned UTF-8 byte continuations and retain representation identity. Decide whether to continue, reread, change the examined window or interpret obtained evidence from actual outcomes.

In short: It is handed one source and a starting window and reads the source in document order for the question, following the returned UTF-8 byte continuations and deciding whether to continue, reread, move the window or interpret what it has.

## Task and instructions

One unit is one model-selected action: a tool call. There is no reasoning-commit action (`source_interpretation.py`) and no waiting (`waiting.py`).

The instructions (`task_instructions.py`, this folder's own copy) are composed in this order:

1. The literature investigation text `INSTRUCTIONS` ("You own an iterative scientific annotation improvement, not a tool itinerary. ..."), held in the file itself.
2. This episode's goal text above, appended (the binding's `instructions`).
3. The tool-knowledge text, when tool knowledge is in the context; the launch-instruction text, when the launch-instruction library is.
4. The paragraph on a pending child delivery (`redeliver_report`); it cannot arise in a leaf.
5. `REASONING_COMMIT_REQUIREMENT` and the two wait paragraphs are only added when `reason` / `wait` are permitted; they are not here.
6. Under the exchange protocol the old history guidance is replaced by: use `request_context` exchanges for own attempt metadata (no completed action or observation), and read earlier outcomes with `episode.history` (view=records).

## How its credit is counted

- Credit kind `scientific` (`credit.py`): the axis's scientific credit view for this episode (`services.scientific_credit(context, receiver_selection)`). No projector and no score judgments of its own (`scientific_records.py`).
- After each own action whose outcome counts as observed, the credit view is read again; its `credit` is saved with the action and handed to the controller as that unit's input (`task.py`). A unit that fails while executing is recorded `failed` and still enters the iterator with the credit measured after it (`task_state.py`). A response that fails admission is recorded as a `rejected` decision effect and creates no unit. Request_context exchanges create no unit.
- Nothing in these files bounds, clamps or rescales credit.

## Old-runner machinery to replace

- **Every hook takes an old role name** (`self._role(context.role)`), and children are looked up by old role (`literature_page`, `literature_table`, `literature_ordered`, `literature_targeted`). The new contract names bindings by path and children by slot.
- **`self.workflow.*`** in `call.py`, `decision_exchange.py`, `saved_decision_exchange.py`, `decision_contracts.py`, `decision_provider.py`, `decision_inputs.py`, `decision_state.py`, `report_delivery.py`, `task.py`, `task_state.py`, `task_instructions.py` (as `source.workflow`), `task_suspension.py`.
- **`BindingContext`** (`context.role`, `.assignment`, `.scope`, `.episode_id`, `.received_record_refs`; `parent.role`, `.assignment`, `.scope`) is the argument of every binding hook.
- **Per-axis services provider** (`self.services`): `scientific_credit`, `own_outcomes`, `tool_catalog`, `execute_tool`, `reference_in_scope`, `read_record`.
- **Journal tables read or written directly:** `runtime_model_calls`, `runtime_actions`, `runtime_episodes`, `runtime_forms`.
- **Old runtime module:** every task file ends with `from ...root.a103 import runtime as _live_original_runtime` and calls its helpers through that alias (and imports a long list of names from it, most unused).
- **Old shared prompt pieces:** `task_presentation.py` / `task_presentation_policy.py` import from `root.a103.gene_context_evidence_prompt`, `root.a103.decision_context`, `root.a103.execution_prompt`, `root.a103.native_profile_presentation`, `root.a103.library.hpc_prompt`, `root.a103.library.monitor_prompt`.
- **Other old shared root modules:** `root.a103.communication`, `root.a103.domain`, `root.a103.episode_bindings`, `root.a103.composition_information` (via `source_contracts.py`), `root.a103.library.action_contracts`, `root.a103.library.private_policy_call`, `root.a103.library.report_fact_assembly`, `root.a103.episode_work_report`, `root.a103.episode_source_failure`, `root.a103.providers`.
