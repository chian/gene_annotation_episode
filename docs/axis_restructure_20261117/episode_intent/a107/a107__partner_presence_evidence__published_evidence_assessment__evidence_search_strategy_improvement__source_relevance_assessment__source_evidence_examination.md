# a107 / source_evidence_examination (old role `literature_page`)

Path: `gene_annotation_episode/episodic_workflow/root/a107/partner_presence_evidence/published_evidence_assessment/evidence_search_strategy_improvement/source_relevance_assessment/source_evidence_examination`

Source of this note: the episode's own files at `97308b94c` (36 files directly in the folder; no grading/ or scoring/ subfolder). Child folders were not read.

## What it is for

Goal (goal.py, own words): `_ROLE_INSTRUCTIONS['literature_page']` = "Investigate where and how this exact source should be examined. Choose ordinary source operations or selected table, ordered-reading or targeted-passage investigations as useful. Paragraph projections omit some XML headings, tables and footnotes; retained original bytes remain addressable." followed by the A107 partner text: "Investigate reported partner removal, addback and coexpression evidence. Preserve the original molecule and partner roles, normalization, nonpartner conditions, physical measurement identity, source units and uncertainty. Condition-specific dependence does not establish universal necessity, genomic presence, target correspondence or annotation credit. A search or read earns no scientific credit by itself."

In short: examine one assigned source (one representation of it) for partner evidence, directly or through table / ordered-reading / targeted-passage children.

## Task and instructions

Same task loop, instruction composition and TASK/STEERING prompt as its siblings (files byte-identical): snapshot -> model call -> apply; model-call error -> `source_failed`. No `reason` / `wait` texts (not permitted); redelivery text always present.

## What it reads from the parent's assignment

`page_assignment_v1` (`_PAGE`, from_parent.py): `{version, source_ref, representation (text|original|stdout|stderr), artifact_ref, question_context_refs, prior_delivery_refs}` plus partner fields from `library.partner_source_contracts.assignment_schema_fields()`. Validation (`_validate_page`): source in scope, `artifact_ref` must be exactly the artifact of that representation (original -> artifact_ref, text -> text_ref or artifact_ref, else <repr>_ref), artifact in scope, question/prior refs in scope. The whole assignment is the page: custody is that one source, and every tool call is confined to it.

## Decision state and what the model sees

Own fields: `literature_assignment` (the page), `literature_source_custody` for the page source, `own_literature_outcomes` (own acquisition+read outcomes, limit 8), `literature_history_meaning`, `literature_experimental_work` marker, owned population sources, latest failed population attempt, component-axis source origin/access. Old-runner fields as in the parent's note (goal, scope, working_state, credit, evidence vector, time_accounting display, pending work, outcome/feedback, tools, child_options, requested form, current report update, action_yields, ...).

## Tools it offers

Access tools only: `state.query, source.read, source.locate, source.sequence.scan, source.sequence.references, source.experimental.records, image.view, source.archive.members, source.archive.extract, source.xlsx.sheets, source.xlsx.rows, source.pdf.info, source.pdf.text, source.pdf.page, execution.estimate` (xlsx branches only) + partner population operations. **No acquisition tools** (no search, no public read, no PMC/NCBI). Every source_ref (including archive member sources and refs inside population arguments) must lie within the assigned page source; otherwise `literature_reading_outside_assigned_source` with a rejection detail.

Common actions: `tool`, `child`, `redeliver_report`.

## Credit

Same as siblings: `scientific` kind, services.scientific_credit view, no projector, credit after each observed outcome, failed executions recorded with credit. Unbounded.

## Continuation

No own continuation (`continuation_task`/`yield_controller` None); old default controller with yield table. Nearest new estimator: **accumulation**, default settings (inference).

## What it reports to its parent

Typed form via `form_with_facts` with partner fact cells of committed refs (requested components only); validated by `validate_report` (assignment, form refs, received partner cells: sheet_ref permitted, components requested, empty family validated).

## Differences from similar episodes

- vs parent `source_relevance_assessment`: no acquisition tools; one-page assignment; three children instead of one; tool calls always confined to the page.
- vs leaves: commissions children; its own assignment is the page itself (leaves hold `page` + a reading selection and check the page lies within the parent's page).
