Source of this note: the episode's own files at `97308b94c` (30 files; no subfolders, no grading/ or scoring/).

## What it is for

Goal (goal.py, own words): `_ROLE_INSTRUCTIONS['literature_ordered']` = "Investigate the source in document order as useful for the assigned question. Use returned UTF-8 byte continuations and retain representation identity. Decide whether to continue, reread, change the examined window or interpret obtained evidence from actual outcomes." followed by the A107 partner text ("Investigate reported partner removal, addback and coexpression evidence. Preserve the original molecule and partner roles, normalization, nonpartner conditions, physical measurement identity, source units and uncertainty. Condition-specific dependence does not establish universal necessity, genomic presence, target correspondence or annotation credit. A search or read earns no scientific credit by itself.").

In short: read one source in document order from a starting window, extending coverage by byte continuations, and interpret partner evidence.

## Task and instructions

Same task loop, instruction composition and TASK/STEERING prompt as its siblings (byte-identical files).

## What it reads from the parent's assignment

`reading_assignment_v1` (from_parent.py): `{version, page: _PAGE, selection: _WINDOW {source_ref, representation, offset, limit}}` plus partner fields. Validation: page validated; the window must have the page's source_ref and representation; offset must not exceed the page artifact size. When prepared by a `literature_page` parent, the page source must lie within the parent's page source (own copy of the parent page schema/validation).

## Children it may commission

None (`child_roles` = ()), `child` still listed in permitted common actions. No to_child/from_child files.

## Decision state and what the model sees

Own fields: `literature_assignment`, `literature_source_custody` for the page source, `own_literature_outcomes` (limit 8), history meaning, experimental-work marker, owned population sources, latest failed population attempt, component-axis source origin/access. Old-runner fields as in the siblings' notes.

## Tools it offers

Access tools only + partner population operations; no acquisition tools; all reads confined to the assigned page source. Common actions: `tool`, `child`, `redeliver_report`.

## Credit

`scientific` kind via services.scientific_credit; no projector; unbounded.

## Continuation

No own continuation; old default controller. Nearest new estimator: **accumulation**, default settings (inference).

## What it reports to its parent

Typed form via `form_with_facts` with partner fact cells of committed refs, requested components only; validated by `validate_report`.

## Differences from similar episodes

- vs `passage_evidence_extraction`: single window instead of a list of spans; otherwise identical apart from role/path strings.
- Note: the folder name says "coverage improvement" while the old role is ordered reading (episode.py maps `literature_ordered` to this folder).
