## Purpose (its own words)
"Acquire the original selected execution results through the original handoff. Choose bounded status or requested file/page reads using actual preceding outcomes. Preserve partial bytes and native scores. Native paths expose the current resource filesystem: the exact attempt observation does not establish that current file bytes were produced by that attempt. Separate read windows are not an atomic file snapshot. The scientific parent interprets the returned records. Original work, resource and selector stay fixed. Only actual complete acquisition establishes this endpoint." (`goal.py`)

## Task and instructions
- Role `results`. No entry roles. Commissioning parent `evolutionary_history_evidence/hpc_work_planning/hpc_allocation_execution`. `replaces_default_instructions = True`.

## Tools
- Generic native targets (`result_operations.py`, `native_file_acquisition.py`):
  - `execution.results.status`: observe the exact handed-off attempt once;
  - `execution.results.collect`: observe and read the first window of every requested path, each window min(log_window_bytes, 1 MiB, length);
  - `execution.results.read`: one window inside a requested path/interval.
  - Immutable intent/observation/window/receipt files, published as `episode.execution_result` sources (`execution_result_information_v2`). A result action after a verified completion is refused (`execution_results_assignment_already_completed`).
- Typed native targets use their own catalogs (masking, utility, BLAST database, standard database, HMMER preparation, HMMER, pairwise BLAST), each with capture, grading preparation and selected-row publication.
- API targets: the API acquisition catalog (`api_acquisition.py`, `hmmer_acquisition.py`, `appservice_*`).
- Common actions: `tool`, plus `wait` for an `api_service_assignment_v1` API target. Errors become `invalid` outcomes (retained-artifact capture errors re-raise).

## Credit
- Kind `operational`.
- Generic native selector: `acquired_record_unit × mean over requested paths of the newly covered byte fraction` (`execution_received_selector_coverage_credit_v2`). Bytes in initial known refs are excluded; each byte position is credited once whatever the read boundaries. `handoff_unit × handoff_count` with handoff_count fixed at 0.
- Mixed local-file sources: `acquired_record_unit × acquisition count` (`execution_received_records_credit_v1`).
- API (BLAST/BV-BRC/UniProt) and EBI HMMER: `handoff_unit × new handoff identities + acquired_record_unit × new result identities` beyond inherited ones.
- Typed native results delegate to their own credit views.
- At closure the projected view is pinned (`execution_closed_operational_credit_v1`) and later returned verbatim (`closed_credit.py`).
- No bound or clamp is applied anywhere in these files.

## Continuation
- Private yield required (`execution_private_yield_binding_not_enabled` otherwise).
- Finite native selector: profile `results:native_finite_<kind>`; bounded-credit estimate with `maximum_credit = acquired_record_unit × (1 − already received fraction)`; exact zero once all requested bytes are credited; practical endpoint estimate once completion is verified. New estimator: **bounded quality** (maximum = remaining selector credit), with the verified endpoint ending it.
- Unbounded native selector (a path without a length): `results_yield_profiles['native_unbounded_<local|hpc>']` with a plain YieldController. New estimator: **accumulation**.
- API and typed selectors: task profile `results:api_<service>[_<selector version>]` or `results:typed_<kind>_<selector version>` with the practical endpoint estimator. New estimator: **completion with a target** (the verified completion proof).
- Settings: `cutoff` and `parameters` per profile from configuration (`results_yield_profiles`, `task_yield_profiles`).
