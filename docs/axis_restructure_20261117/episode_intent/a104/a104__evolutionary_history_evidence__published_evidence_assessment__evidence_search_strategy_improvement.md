## Purpose (its own words)
"Investigate which search approach is productive. Keep the information objective and evidence context separate from a literal provider query. Revise terms or source choices in light of actual search/read outcomes; a search child can investigate which returned sources deserve examination.
This is an iterative scientific investigation in the shared Episode loop. Earlier outcomes and admitted child forms inform later choices; no child order, reading quota or complete-document requirement is prescribed. A one-off search/read is an ordinary tool. A supplied reading selector is context, not an automatically executed action. Preserve the source's actual subject, experimental conditions, representation, version and UTF-8 byte anchors. Distinguish source claims from their applicability to the fixed target. Negative findings and qualifications can advance the investigation. Commit interpretations with the common reasoning action and update only the parent's declared typed form in that same work call. Navigation, byte coverage and repeated reading earn no scientific credit by themselves. The commissioned task's own yield settings guide continuation." (`goal.py`)

## Task and instructions
- Role `literature_strategy`. No entry roles. Commissioning parent `evolutionary_history_evidence/published_evidence_assessment`. It does not set `replaces_default_instructions`.
- Instructions (`task_instructions.py`): the default scientific-investigation INSTRUCTIONS text ("You own an iterative scientific annotation improvement, not a tool itinerary...") + `\n` + own goal + REASONING_COMMIT_REQUIREMENT (a reason action needs at least one commit row; the `no_applicable_evidence` exception) + tool knowledge + launch library + pending-child redelivery text + wait text (only if wait is permitted, which it is not) + native event text + exchange-history swap.

## Continuation (`yield_estimator.py`)
- Without a private yield binding: none (`yield_controller` returns `None`).
- With one: `continuation_task(context)` gives the task key, and the declared binding (`kind`, `cutoff`, `uncertainty_alpha`, `credit_unit`) is given to `literature_task_credit._private_yield_controller`. The binding's `kind` picks the estimator. Map it to **accumulation**, **bounded quality** or **completion with a target**, as the binding declares, with its cutoff and uncertainty_alpha as settings.

## What it reports to its parent
- Fact sources (`report_fields.py`): `SCREENING` (screening answers), `LEADS` (verified source-lead dispositions) and, with rate population, every population cell family (`report_field_contracts.py`).

- `validate_report` re-validates the assignment and the form references. It also checks that task answers equal the saved work and that population cell subsets equal the requested/saved subsets (`received_report_admission.py`).
