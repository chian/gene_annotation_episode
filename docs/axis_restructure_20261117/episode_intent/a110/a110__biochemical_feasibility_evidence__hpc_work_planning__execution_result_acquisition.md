## What this episode is for

It acquires the results of one already handed-off execution attempt, within the original selector, for the scientific parent to interpret. In its own words (`instructions.py`):

> Acquire the original selected execution results through the original handoff. Choose bounded status or requested file/page reads using actual preceding outcomes. Preserve partial bytes and native scores. Native paths expose the current resource filesystem: the exact attempt observation does not establish that current file bytes were produced by that attempt. Separate read windows are not an atomic file snapshot. The scientific parent interprets the returned records. Original work, resource and selector stay fixed. Only actual complete acquisition establishes this endpoint.

## Task and instructions

- Role `results`; commissioned by `biochemical_feasibility_evidence/hpc_work_planning`; no entry roles.
- `replaces_default_instructions=True`: the text above replaces the default; `task_instructions.py` appends tool knowledge, launch library text, the redelivery repair paragraph and exchange-protocol guidance.
- Only common action: `tool`.

## What it reads from its parent's assignment

`RESULTS_SCHEMA` (`execution_results_assignment_v1`): `handoff_ref` (a practical receipt handoff, or a retained FBA target) and `selector`. Selector kinds: native path windows (`paths`/`path`, `offset`, `limit`), `local_file_source_selector_v1` (files to capture), and `flux_balance_result_selector_v1` (when FBA is configured; modes including `saved_sheet_recalculation`). On preparation it first restores a previously returned identical Results commission (`saved_commission.py`); otherwise reads the target, validates the selector against it and admits local file sources. Initial references: the handoff_ref and, for saved-sheet recalculation, the authenticated saved sheet artifact.

Decision inputs as in the job-execution episodes with execution expectations for `results`. Rendered by `present_results_context`.

## Tools

- Native: `execution.results.status` (observe the exact handed-off attempt once), `execution.results.collect` (observe and read first windows of every requested path, each min(log_window_bytes, 1 MiB, requested length)), `execution.results.read` (one window inside a requested path and interval, ≤ 1 MiB). Intent, observation, windows and receipt are immutable files keyed by the operation key; failed windows are kept as failures; refuses new acquisition once the assignment already completed. Each body is published as a `source` record (`episode.execution_result`).
- FBA: the native flux-balance result catalog.
- Local file sources: their own execute.
Errors become invalid outcomes (except retained-artifact failures of file capture, which raise).

## Credit

Kind `operational`. Live: `handoff_unit × new_handoff_count` (always 0 here) `+ acquired_record_unit × new_acquired_selector_fraction`, where the fraction is the mean over requested paths of newly covered byte positions (union of windows, minus bytes already in initial records) over the requested interval — "Credit saved byte positions once, regardless of read boundaries". For local file sources: `acquired_record_unit × new file acquisitions`. FBA results use their own credit view. After closure: only the authenticated closed view. Not bounded or rescaled.

## Continuation

Requires the private yield binding; chosen by selector:
- unbounded native selector (a path without length): `results_yield_profiles['native_unbounded_<resource_kind>']` = `{cutoff, parameters}`, plain controller (new: **accumulation**);
- finite native selector: `task_yield_profiles['results:native_finite_<resource_kind>']`, bounded credit yield with maximum remaining = acquired_record_unit × (1 − fraction already covered by initial records); exact zero when nothing remains; endpoint estimate once completion is proven (new: **bounded quality**, with completion);
- typed selector (file source / FBA): `task_yield_profiles['results:typed_<resource_kind>_<selector version>']` with the endpoint estimator (new: **completion with a target**).
The file also carries copies of launch, launch_local and launch_hpc controllers that this results-only episode never calls.

## Report to parent

FBA facts when FBA applies; otherwise execution_handoff_refs, execution_result_refs (bodies with windows), execution_file_source_refs, execution_file_capture_outcomes, execution_result_origin (current filesystem, version unverified, no atomic snapshot, completion basis), execution_completed; plus the closed credit snapshot at closure. `required_return_sources` is `('execution_result_refs',)` when the parent is `biochemical_feasibility_evidence` and an annotation task is required. Report fields with `x-source` must equal recorded facts.
