# a110 / biochemical_feasibility_evidence / published_evidence_assessment

Source: `git show 97308b94c:gene_annotation_episode/episodic_workflow/root/a110/biochemical_feasibility_evidence/published_evidence_assessment/<file>`. Only the files directly in this folder were read; `evidence_search_strategy_improvement/` is the child episode and was not read. Old binding class `LiteratureEpisode`, decision source `SourceInvestigationTask`. Old role name: `literature`.

## What it is for (its own words)

`goal.py` (role text from `contracts._ROLE_INSTRUCTIONS['literature']` plus its own): "Investigate which published evidence bears on the assigned scientific question. You can pursue ordinary searches and source reads directly, or assign a strategy investigation when that narrower question warrants iteration." + "Investigate the reported reaction and resource evidence for this source. Preserve source identity, exact conditions, units, uncertainty and byte anchors. Keep reported product ratios, resource budgets and named predictions distinct. Unknown replication, calibration, alternative reactions and resource completeness remain unresolved. A search or read earns no scientific credit by itself."

## Task and instructions

`task_instructions.py`: the default scientific INSTRUCTIONS text with this binding's text appended (not replacing it), then tool-knowledge and launch text, the delivery-repair paragraph, and the exchange-history replacement. Prompt renderer `task_presentation.present_source_context` renders the literature experimental prompt when the context is a literature experimental task, else JSON.

## What it reads from its parent's assignment

`literature_assignment_v1` (`from_parent.py`): `question_context_refs`, `source_refs`, plus literature component fields from `library.literature_component_binding.assignment_schema_fields()` (requested reaction components, native observation positions). Every `*_refs` entry must be in scope (source namespace except question context). With a root annotation parent and configured `reference_parent_sources`, `parent_context.initial_decision_context` adds the reference-evidence parent context.

## Children it may commission

One slot `literature_strategy` -> `evidence_search_strategy_improvement`.
- Sends (`to_child_evidence_search_strategy_improvement.assemble_request`): a child goal refining this goal with the contract's schema as result contract; message with scope and initial report, optional report contract declaration (validated saved fact form), job/episode assignment (launch instructions), `biochemical_feasibility_evidence` message, and `knowledge_inheritance` receipts binding the child's episode identity to this one.
- Takes back (`from_child_evidence_search_strategy_improvement.receive_report`): the admitted form; references from recorded admission, progress receipt, references in the form, binding-received form references (reaction cells and native observations received into the reaction repository), recorded as child_form (or report_redelivery) receipts, plus tool attributions.
- `create_binding_tree` constructs this binding and its six descendants (strategy, source relevance, source examination, table, coverage, passage) from one configuration.

## Decision state shown to the model

`internal_summary.SourceDecisionSummary._decision_snapshot`: the shared state fields, plus annotation context for scientific sources. Decision inputs inline in `task_decision.py` (execution expectations keyed by the episode's own grain name).
Its own part (`internal_summary.decision_context`): `literature_assignment`, `literature_source_custody` (version, artifact/text/stdout/stderr refs, parent sources), `own_literature_outcomes` (own outcome metadata, page size 8), `literature_history_meaning`, `literature_experimental_work` (aspect source_experimental_evidence), owned population sources and the latest failed population attempt, `component_axis_source_origin`, `component_axis_source_access`.

## Tools

`source_operations.py`: from the service tool catalog, only access tools (state.query, source.read, source.locate, source.sequence.scan/references, source.experimental.records, image.view, source.archive.members/extract, source.xlsx.sheets/rows, source.pdf.info/text/page, execution.estimate restricted to xlsx) and acquisition tools (public.literature.search/read/sequence_identity, public.ncbi.search restricted to pubmed, public.pmc.versions/files/asset, experimental database operations), plus the reaction population operations (`literature.reaction.populate`, `literature.reaction.source.populate`). Locate/scan/experimental tools receive `permitted_record_refs` = received refs. With a page assignment, every read must stay within the assigned source. Actions: tool, child, redeliver_report (no wait; `supports_wait` False; no reason action).

## Credit

Kind `scientific`; credit view from `services.scientific_credit(context, selection)`; no own projector. Per AGENTS.md the A110 evidence is counted through the parent's scientific credit; this episode has no grading sheet of its own in these files.

## Continuation

None of its own: `continuation_task` and `yield_controller` return None; the caller's controller continues it. A new binding must choose one of the three estimators explicitly (no default exists in the new runner); nearest by intent is accumulation of scientific credit.

## What it reports to its parent

`to_parent.py`/`numerical_report_facts.py`: fact sources are the reaction rate fact sources: reaction cells per population route (`literature_reaction_cells`, `literature_reaction_semantic_cells`) for requested components from received reaction records (v2/v3), and native observation rows for requested positions. `validate_report` validates the assignment, the form and the received reaction returns (permitted sheets, requested components and positions, empty-family checks).

## Differences from similar episodes

- Its child `evidence_search_strategy_improvement/` at HEAD has the same file names and the same line counts for most files as this folder (copies), differing in episode.py and the from_child/to_child pair.
- Appends its text to the default instructions, while the HPC and results episodes replace the default.
- Only episode of the four with scientific credit and no private continuation.
