## What it is for (its own words)

`instructions.py`: "Acquire the original selected execution results through the original handoff. Choose bounded status or requested file/page reads using actual preceding outcomes. Preserve partial bytes and native scores. Native paths expose the current resource filesystem: the exact attempt observation does not establish that current file bytes were produced by that attempt. Separate read windows are not an atomic file snapshot. The scientific parent interprets the returned records. Original work, resource and selector stay fixed. Only actual complete acquisition establishes this endpoint."

## Task and instructions

`replaces_default_instructions = True`: the model instructions are this episode's own text (above), plus tool-knowledge and launch-instruction text when present, the delivery-repair paragraph, and (exchange protocol) the exchange-history replacement (`task_instructions.py`).

## What it reads from its parent's assignment

`RESULTS_SCHEMA` (library `execution_result_contract`) extended with the `local_file_source_selector_v1` selector and, when FBA results are configured, `flux_balance_result_selector_v1` (`from_parent.py`). Key fields used: `handoff_ref` (the practical receipt of the launched attempt, read as the execution target), `selector` (paths/path, offset, limit, or a typed selector version), constraints. `prepare_assignment` first restores an already admitted original Results commission (`saved_commission.py`: same assignment and scope as the parent's recorded child and the child yielded), otherwise reads the handoff target and validates the selector (and admits local file sources). Initial references are the handoff ref (plus a saved sheet artifact for FBA saved-sheet recalculation).

## Decision state shown to the model

`internal_summary.results_decision_snapshot`: the shared state fields (goal, scope, working state, visible refs, current credit/evidence vector, credit binding, time accounting, pending work, last outcome/feedback, visual evidence, report deliveries, controller, tools, tool knowledge, job episode options, report facts, requested purpose/form, current report and basis); no investigation_progress. Its own part (`internal_summary.decision_context`): `execution_assignment`, `execution_progress` (= its facts), `execution_target` and `execution_target_description` (status and acquisition operations, provenance or FBA operation/mode), and for FBA work `selected_execution_task` (scientific question, selected tool info, requests with resource information, constraints, selector, result description). Compact FBA assignments show `practical_assignment`, `practical_progress`, `practical_completed`.
Prompt renderer (`presentation.py`): renders HPC, published-scientific, selected-execution, monitor or receiver text from the reconstructed frame, else JSON.

## Tools

`result_records.native_result_operation_catalog`: `execution.results.status` (observe the exact handed-off attempt once), `execution.results.collect` (observe and acquire first windows of every requested path, each at most min(log_window_bytes, 1 MiB)), `execution.results.read` (one window inside the requested path/interval, limit at most 1 MiB). For FBA targets the FBA result catalog; for local file sources the local file-source operations. Acquisition (`native_file_acquisition.py`) writes immutable intent, observation and per-window files, keeps read failures as failures, refuses new acquisition after completion, and publishes an `execution_result_information_v2` receipt as a Source (provider `episode.execution_result`). Errors become invalid outcomes (`work_operations.py`).

## Credit

Kind `operational` (`credit.py`). Live: `handoff_unit * 0 + acquired_record_unit * fraction`, where fraction is the mean over requested paths of newly received byte positions (union of windows, minus positions already in initial refs) divided by the requested span; for local file sources `acquired_record_unit * count of new acquisitions`. Binding versions `execution_received_selector_coverage_credit_v2` / `execution_received_records_credit_v1`. After closure (`closed_credit.py`) the credit view is the view captured in the closing facts, with digests of context, binding, completion, archive, observation history and receipt prefix; any later difference raises; later delivery never reprices it. Not bounded or rescaled.

## Continuation

Old `yield_estimator._results_yield_controller` (only with `require_private_yield`):
- selector with unbounded length: `results_yield_profiles['native_unbounded_<local|hpc>']` -> plain `YieldController(cutoff, parameters)`;
- finite selector: task profile `results:native_finite_<kind>`; remaining = `acquired_record_unit * (1 - original fraction)`; exact zero when nothing remains (`finite_result_selector_exhaustion_v1`); otherwise `estimate_bounded_credit_yield(maximum_credit=remaining)`; a supplied verified completion proof switches to the practical completion estimator;
- typed selector: task profile `results:typed_<kind>_<version>` with `PracticalYieldEstimator(verify_completion)`.
New estimators: finite selector -> bounded quality (maximum = remaining selector credit) together with completion with a target (the verified practical completion endpoint); unbounded selector -> accumulation; typed selectors -> completion with a target. Settings come from the per-task profiles (cutoff, parameters). Launch variants in this file are copies of the shared execution binding and are not used by the `results` role.

## What it reports to its parent

`to_parent.py`: `execution_handoff_refs`, `execution_result_refs` (results that contain windows), `execution_file_source_refs`, `execution_file_capture_outcomes`, `execution_result_origin` (current filesystem, attempt output unverified, separate reads, completion basis), `execution_completed`, FBA fact sources when FBA is configured, and the closed credit snapshot. `execution_result_refs` is a required return source when the parent is `biochemical_feasibility_evidence` and an annotation task is required. `validate_report` requires x-source fields to equal facts.
