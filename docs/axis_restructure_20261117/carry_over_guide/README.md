# Carrying an old episode over to the final form (19 November 2026)

This is the one guide for the carry-over. It replaces the five earlier guides of this folder (deciding, parent and
children, store/tools/records, progress and continuation, system recording). Four of them described an API that
no longer exists.

- **The final API:** [`BINDING_CONTRACT.md`](../BINDING_CONTRACT.md) is the source of truth. Every signature and
  name below was checked against `episode_runtime/` (`episode_type.py`, `runner.py`, `recording.py`,
  `store_scope.py`, `work_tables.py`, `services.py`, `journal.py`, `progress.py`), `method_loop/forms.py` and
  `yield_control/__init__.py`.
- **Worked examples of the final form** (real, tested): `episode_runtime/tests/fact_collection/` (a parent),
  `episode_runtime/tests/fact_collection/fact_extraction/` (its child), `episode_runtime/tests/probe/` (tools,
  services, a work table, two slots to one child, one slot to its own kind) and
  `episode_runtime/tests/sheet_library.py` (a library module with a declared work table).
- **Store calls of the library:** [`store-access.md`](store-access.md) maps each old raw-Store call pattern to its
  custody operation, or to "no replacement yet".
- **The source of each episode's intention:** its own files at commit `97308b94c`, under
  `gene_annotation_episode/episodic_workflow/root/<axis>/<role>_evidence/**` (202 episode folders). Read them with
  `git show 97308b94c:<path>`. Nothing outside those trees is a source.
- **Two name tables** list old names by family: section 6 says what their columns mean.
- **Where the library pieces live** (credit projectors, form helpers, instruction text, transports, operation
  receipts) and **which old estimator becomes which controller**: section 7.
- **Decisions of 19 November.** The five points the third audit left open are answered in `BINDING_CONTRACT.md`
  ("Decisions of 19 November 2026") and this guide follows them. By the owner's rules: nothing but the yield
  controller ends an Episode, `Done` is removed (T1); `credit` and `finding` are required fields of every return
  form and the system hands the Episode's credit to `final_to_parent` (T3). Provisionally: a pass carries only the
  records named, so every record the receiver reads is named (T5); what `decide` and `action` read from a
  service is recorded per unit position and replayed (T10); `action` may reject a model answer that names an
  unheld record, as an invalid answer and never as a check of a commission.

Old file and function names in this guide are from the a102 head and its monitor child at `97308b94c`. Other
episodes hold near-copies, sometimes split over more files.

## 1. The rules

These are the owner's rules (`AGENTS.md`: "Private episode bindings", "How the system fails and stops", "Removing
unwanted code"). They bind every line that is carried over.

| # | Rule | What it means in the carry-over |
|---|---|---|
| 1 | **A wrong commission fails.** | A parent knows how to call its child: that is what writing its `msg_to_child.py` and its prompt is for. A selection the child does not declare, an assignment the child's form does not admit, a record the parent does not hold, an error while the message is built: each raises (`FormError`, `CustodyError`, or the error itself) and the run fails with that error message. Nothing catches it, checks it beforehand, corrects it or returns it to the model. Nothing compares one episode's names with another's when a run is linked. Old code that did any of this for a commission is deleted, not carried. |
| 2 | **Stopping is the yield estimator's alone.** | Every unit's credit goes to the episode's yield controller, and the controller alone ends the Episode. Only the three `yield_control` controllers exist. There is no count, turn, time or token cutoff and no other stopping gate. No task ends its own Episode: `decide` and `action` always produce a unit, and old code that ended the episode by its own choice ("nothing left to request", "report written", "failed") is not carried as a stop. Whether a lookup, a wait or a check earns credit is that episode's own `credit.py` and settings. |
| 3 | **Custody only.** | No episode function and no library function touches the Store, its tables or its files directly. A tool uses `ctx.store`. A pure function uses `records`. A library function is handed one of the two and calls only what it offers. |
| 4 | **`yield_estimator.py` reads what `read_from_parent.py` produced.** | It never reads the raw assignment. `read_from_parent.py` is the only place an assignment is read. |
| 5 | **The child declares, the parent selects.** | A child declares every field it can return, in its own `return_form`. The parent selects among the selectable ones in `msg_to_child.py`. Credit and finding are always returned: both are required fields of every `return_form` (importing `episode.py` raises `TypeError` otherwise) and can never be selected. |
| 6 | **No fallbacks, aliases or shims.** | A case the code does not plan for raises. Delete what you replace, and delete it before porting onto the new path. Never restore deleted code to make something pass. |
| 7 | **Credit is never bounded, clamped or rescaled.** | Not by the system and not by carried code. Settings make credits comparable. |
| 8 | **Old-runner machinery is dropped; episode functions are kept.** | Every function that says what the episode does lands in one of its ten files, or in `episode_support/` as a library function with parameters. None is dropped. Recording, replay, custody bookkeeping and the old decision loop are not carried. |
| 9 | **Private bindings.** | An episode inherits only `episode_runtime.EpisodeBinding` and imports nothing from another episode. Similar episodes keep their own copies. Shared code is library functions only. |
| 10 | **The old shared root is never read.** | Files directly under `root/`, `root/library`, `root/scientific_process` and the duplicate top-level trees at `97308b94c` are not restored and not used as a guide. Where an old episode file called into them, carry what the episode's own file shows of the intention. |

## 2. The ten files

An episode folder holds exactly these files, plus `__init__.py`, `messages/__init__.py`, its child episode folders
and `tests/`. An episode without children has no `msg_to_child.py` and no `read_from_child.py`. The parameter
names are part of the form (`episode_type.SIGNATURES`); a wrong one raises `TypeError` when `episode.py` is
imported.

| File | Supplies (exact form) | What goes in it | What must not go in it |
|---|---|---|---|
| `goal.py` | `BINDING_PATH` (lowercase segments joined by `/`; the package path must end with it), `GOAL`, `UNIT`, `RESULT`: non-empty text | What the episode is for, what one unit of its work is, what it returns | Functions, prompt text, settings |
| `task.py` | `CHILD_SLOTS = {slot: child binding_path}`; `TOOLS = {name: tool}`; `SERVICES = (name, ...)`; `def decide(summary, feedback, ctx)`; `def action(response, summary, records, ctx)`; each tool `def tool(arguments, ctx)` or `async def tool(arguments, ctx)` | The instructions and output schema for the model, the choice of the next action, the validation of the model's answer, the tools. `decide` returns `ModelRequest(role, instructions, context, output_schema)`, `ToolCall(name, arguments)` or `ChildCall(slot, arguments)`. `action` returns `ToolCall` or `ChildCall`, or raises `Rejected(feedback)`. Neither can end the Episode: there is no `Done`. The task always offers a unit; a model answer that selects none is an invalid answer and `action` rejects it; `action` accepts at least one unit at every decision. A tool that takes the model's closing text or report (a `close` or `report` tool), when the episode has one | Any stop rule or counter. Any return that means "finished" (`None` raises `TypeError` and fails the run). Any write in `decide` or `action` (they only read). Recording or replay code. The Store itself. A tool defined elsewhere (a tool is a module-level function of `task.py`; its body calls library functions). `async` on `decide` or `action` |
| `credit.py` | `def credit(summary, records)` returns a finite number | The episode's credit as a function of its summary and of the records it holds. `records` offers every read-only operation of the custody API (the table below): single reads, the custody-limited inventories (`list`, `count`, `current_assessments`, `current_annotations`, `query_records`, ...), `is_current(ref)` and `table(...)`. A parent's credit is its own measurement of what it holds; it is never a sum of its children's credits | Services, clocks, writes, a bound, a clamp, a rescaling |
| `yield_estimator.py` | `def yield_controller(initial_credit, settings, parent_input)` returns an `AccumulationYieldController`, a `BoundedQualityYieldController` or a `CompletionYieldController` | The choice of controller kind, its cost and parameters from `settings`, its maximum or target from `parent_input` | The raw assignment, the Store, an estimator or controller of its own, any other stopping test |
| `episode.py` | Exactly one `class X(EpisodeBinding)` that assigns each member from its file (below) | Nothing else | Methods, dunders, another base, a mix-in, a metaclass, a second class |
| `messages/read_from_parent.py` | `ASSIGNMENT_FORM` (a `RecordForm`); `def read_from_parent(assignment, message)` returns the parent input (closed JSON) | Every field the commissioner supplies (`record_refs` fields for records passed in custody) and the one reading of the assignment | Store reads (it is handed no `records`), settings, anything about children |
| `messages/msg_to_child.py` | `def msg_to_child(slot, arguments, summary)` returns `ChildMessage(objective, message, assignment, selection)` | For each slot: the child's objective, its message, the assignment the child's form requires, and the selectable return fields this commission wants | Any test of the commission against the child, any handling of a commission that fails |
| `messages/read_from_child.py` | `def read_from_child(slot, result, summary, records)` returns the report (closed JSON) | What the parent takes from the child's admitted result (branch on `slot`) | Writes (it only reads; it is called once per child unit) |
| `messages/internal_summary.py` | `def internal_summary(view)` returns the summary (closed JSON) | Where the episode stands, as a pure function of the view: parent input, unit outcomes, child reports, controller state, held records | Clocks, services, writes, state kept between calls |
| `messages/final_to_parent.py` | `RETURN_FORM` (a `RecordForm` with the required fields `credit`, of type `number`, and `finding`, of the type and form the episode declares); `def final_to_parent(summary, completion, selection)` returns the result | Every field the episode can return: required ones (`Field(...)`, always returned; `credit` and `finding` among them) and selectable ones (`Field(..., required=False)`, returned when named in `selection`). `credit` is `completion['credit']`. `finding` is the episode's own typed finding (for an evidence episode the typed investigation finding: the actual source claim, the actual source subject and the qualification) | A second credit formula. A form written by the parent, saving of the result, release calls |

### 3a. Deciding

One decision is now: `decide` returns a `ModelRequest`; the system asks the model; `action` turns the answer into
one action or raises `Rejected(feedback)`; on a rejection `decide` is called again with that feedback. A rejection
creates no unit and gives the controller nothing. `decide` may also return an action directly, without the model.

- **A prediction made when commissioning is kept.** Put it in the `ChildCall` arguments or in
  `ChildMessage.message`; both are in the child unit's outcome.

unit that differs from its record raises `JournalError`. Episodes contain no code for any of this.

## 4. Checklist for carrying one episode over

1. **Read the intention.** List the episode's files at `97308b94c` (`git ls-tree -r --name-only 97308b94c -- <its
   folder>`) and read them. Write down its goal, its unit of work, its actions (tools, child roles, reasoning),
   what it reads from its parent, what it returns, its credit and how it decided to stop.
2. **Delete first.** Remove the hook-era files and classes in the episode's folder before writing the new ones,
   so that a hidden dependency fails at once.
3. **`goal.py`.** Write `BINDING_PATH`, `GOAL`, `UNIT`, `RESULT`. The package path must end with the binding path.
4. **`messages/read_from_parent.py`.** Declare `ASSIGNMENT_FORM`: one field per value the commissioner supplies,
   `record_refs` for records. Write `read_from_parent`. Put there what the continuation needs from the
   commission (target, maximum, credit task).
5. **`messages/final_to_parent.py`.** Declare `RETURN_FORM` from the old `fact_sources`: required fields (`credit`
   and `finding` among them, or the class is refused) and selectable fields. Write `final_to_parent` from the old
   `facts`; its `credit` is `completion['credit']`, never a second computation. Keep the old
   `validate_report` body and call it there: the episode checks its own report against its own facts before it
   returns (3b D2).
6. **`messages/internal_summary.py`.** Write the state the old task kept or restored as a pure function of the
   view. Nothing is recalled by hand.
7. **`task.py`.** Declare `CHILD_SLOTS`, `SERVICES`, `TOOLS`. Each old operation becomes a tool whose body calls a
   library function; each lookup becomes a tool. Write `decide` (instructions, context, output schema) and
   `action` (validation of the answer). The wait and redelivery actions are not carried. The task always offers
   a unit and `action` always accepts at least one: nothing in `task.py` ends the Episode. Where the old episode
   ended itself (nothing left to request, report written, source failed), keep the action it still had (a check,
   a wait, the report tool) and let the controller stop the Episode.
8. **Library functions.** Move each body the tools call to `episode_support/`, by function, with what differs
   between episodes as parameters. Hand it `ctx.store` or `records`; follow [`store-access.md`](store-access.md)
   for its Store calls; declare a work table for its own table. Section 7 says where the pieces that already
   exist live.
9. **`messages/msg_to_child.py` and `messages/read_from_child.py`** (when it has children). One branch per slot.
   Name every record the child's code will read (a passed record does not bring the records it names), select
   the return fields wanted.
10. **`credit.py`.** `credit(summary, records)`, unbounded. Decide here, with the settings, whether a lookup or a
    check earns anything. A parent measures its own credit; it does not add up its children's.
11. **`yield_estimator.py`.** Return one of the three controllers from `(initial_credit, settings, parent_input)`.
    Delete every other stop test the old episode had. The controller is the only thing that ends the Episode, so
    check that it can: a completion controller needs a credit that reaches its target, an accumulating one a cost
    above zero in the settings (at cost zero it never stops). Section 7 maps each old estimator to its controller; mind
    the completion-target trap.
12. **`episode.py`.** The one class. Importing it runs the class-definition checks; fix each `TypeError` in the
    file it names, never in the class.
13. **Settings and services.** Give the run's `continuation` collaborator an entry for the binding path and its
    `services` collaborator a factory for each declared name. A missing one is a `LinkError`.
14. **Sweep.** No recording, replay or custody code is left (list in 3e). No import from another episode. No
    `store.db`. No name of the removed hook API. Nothing kept "for compatibility".
15. **Tests**, in the episode's `tests/` folder:
    - they run the real runner: `link(registry, entry_path, {'assignment': ..., 'message': ..., 'selection': [...]},
      run_id=..., journal=RunJournal(path), collaborators={'store': Store(...), 'model_provider': ...,
      'continuation': {...}, 'services': {...}})`, then `asyncio.run(linked.run())`; a resume test uses
      `resume(registry, run_id=..., journal=..., collaborators=...)`;
    - the journal, the Store, `method_loop` and `yield_control` are the real ones. No fake, no scripted stand-in,
      no hand-assembled class, no model answers written by the test;
    - a test that needs a model answer is marked `@pytest.mark.model_run` and calls the real model
      (`gene_annotation_episode.model_provider.ModelProvider`). `pyproject.toml` deselects the marker by default;
      select it with `-m model_run`;
    - a test that needs an episode differing in one way gets a real package on disk (see `episode_variant` in
      `episode_runtime/tests/conftest.py`);
    - a service in a test is a real object behind a zero-argument factory (see `probe_world.py`);
    - assert on what the journal recorded (`journal.units`, `attempts`, `receipts`, `model_calls`,
      `controller_steps`, `run_failure`) and on the result; an interruption is a real exception in a real tool;
    - a wrong commission is tested as a failure: the run raises its error and resuming it raises the same error;
    - run them through the single-workflow launcher with their output under `runs/<run>/` (`AGENTS.md`, "Local
      execution policy").

### 7b. Old estimator -> controller

`yield_estimator.py` from `(initial_credit, settings, parent_input)`; `open_yield_controller` (3d) opens the same
three by kind.
