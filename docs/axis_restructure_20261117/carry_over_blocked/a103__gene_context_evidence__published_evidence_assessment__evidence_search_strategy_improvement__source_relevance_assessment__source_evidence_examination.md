## CONTRACT MISFITS

- new field: source_evidence_examination scope (assignment; the old episode took the Store scope from its request)
- new field: source_evidence_examination received_record_refs (assignment, `record_refs`; the old episode read `context.received_record_refs`). The parent must name the source, its artifact and the sources it derives from, since a pass carries only the records named. `question_context_refs` and `prior_delivery_refs` are `record_refs` fields too (the old schema had them as reference lists that were checked in scope), so the parent passes those records in custody as well.
- new field: source_evidence_examination gene_context_evidence (assignment, optional record; the old request message carried it and `to_child_*` forwarded it)
- new field: source_evidence_examination finding (return; the old episode returned the parent's requested form filled from the model's report update and had no fact sources). Own typed A103 finding form (`source_claim`, `source_subject`, `qualification`, `target_correspondence`, `readings`) and a `report` tool for the model's finding. A103 is not an A105/A108 episode, so no saved subscoring sheet applies. The return has no selectable field (the old fact sources were empty).
- The old `_PAGE` assignment was a bare page. The new ASSIGNMENT_FORM keeps its six property names flat (`version`, `source_ref`, `representation`, `artifact_ref`, `question_context_refs`, `prior_delivery_refs`). The three children each declare a nested `page` and a `selection`; `msg_to_child` builds that page from the flat fields. The children's forms differ among themselves: the table child takes `received_record_refs`, the other two `record_refs` (source, artifact, question context, prior deliveries, derived sources) and an optional `gene_context_evidence`. `msg_to_child` fills each as that child declares it; the table child declares no `gene_context_evidence`, so it is not forwarded to it.
- `msg_to_child` arguments (new): `{'objective', 'selection'}`. The old commission carried a goal text and the child's selection (`selection.assignment.selector` in the old model answer); the model now answers with the slot as its `operation`, an `objective` text and the `selection` that child's form takes (the table child's `selection` is one open record admitted against its table or window form).
- Tool names cannot contain dots: library names (`source.read`, ...) are carried as `source_read`, ... (`ACCESS` in `task.py`). `tool_catalog` is a new first lookup tool (the old services tool catalogue).
- `action` wraps the model's arguments into an envelope `{'arguments', 'scope', 'source_ref'}` so that the tool, which is handed no summary, can apply the source restriction and still return an `invalid` outcome that enters the iterator.
- Children return only credit and finding (no `record_refs`), so a child's work does not reach this episode's held records. `credit.py` is the old axis credit over the records this Episode holds (`A103ContextCredit`); the old credit was also read from the shared axis view after a child return, which the new contract has no channel for. Child credits are in the child reports of the summary; nothing in `credit.py` adds them.
- `final_to_parent` raises `a103_source_evidence_finding_not_reported` when the controller stops the Episode before any finding was reported (no fallback value).
- Settings the episode reads: `cost` and `parameters` (yield controller), optional `tool_registry`, `knowledge_library_directory`, `launch_instruction_directory`.
- The old controller was the old runner's default (None); the bounded-quality controller is chosen because `A103ContextCredit` declares yield_method bounded_quality with native_score_maximum (README 7b).
- `A103ContextCredit` is called with no proposed annotation (this assignment names none).
- Old tests: this episode had none at 97308b94c and the working tree held none, so the retired-tests file has only its header.
