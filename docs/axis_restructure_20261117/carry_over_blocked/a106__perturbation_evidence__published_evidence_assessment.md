## CONTRACT MISFITS

- new field: published_evidence_assessment scope (assignment; the old episode took the Store scope from its request)
- new field: published_evidence_assessment received_record_refs (assignment, record_refs; the old episode read context.received_record_refs). The commissioner must name the assigned sources with their artifacts, the question context and the proposed annotation (a pass carries only the records named).
- new field: published_evidence_assessment finding (return; the old episode returned the parent-written form). The episode declares `written`, `interpretation`, `sources`, `qualification` and a `report` tool for the model's closing text. A106 is not an A105/A108 evidence episode, so no grader sheet is coupled here.
- new service: `execution_binding` (SERVICES). The old binding's execution configuration (`_execution`, `binding.api_execution.services`) is the outside world; no such service exists in the repository. A run that links this episode must supply a zero-argument factory for it. Its value must offer: `execution_resources` (closed JSON `{'resource_ids': [...], 'intervention_contract_resource_ids': [...]}`, read by `decide` and `action` as a recorded read) and `resource(resource_id)` (the configured resource object with `.service` and the BV-BRC adapters `selected_adapter` takes, used by the contract tool). With no resource, `launch`, `results` and the contract tool are not offered (old `analysis_children`, `contract_catalog`).
- new settings read: `cost`, `parameters` (yield controller), `execution_handoff_unit` (credit one handoff earns: the old `handoff_unit` of the launch child's binding; `task.action` adds it to the launch commission as `handoff_unit`; a missing setting fails), optional `tool_registry`, optional `knowledge_library_directory`, optional `launch_instruction_directory`.
- new fields of the strategy commission the model writes (ChildCall arguments, slot `literature_strategy`): `objective`, `message`, `question_context_refs`, `prior_search_refs` (sources this episode holds) and `literature_task` (the old task schema without credit_unit and yield_settings). The child's scope is this episode's own; the child's `credit_unit` is this episode's own task credit unit (the old private yield binding filled it).
- new fields of the launch commission the model writes (slot `launch`): `objective`, `message`, `requests`, `immutable_input_versions`, `constraints`, `launch_instructions` (nullable), `input_refs` (records this episode holds that the requests name), `already_handed_off_resource_ids`; `handoff_unit` is added by `action` from the settings. new field: execution_job_submission scope is this episode's own scope.
