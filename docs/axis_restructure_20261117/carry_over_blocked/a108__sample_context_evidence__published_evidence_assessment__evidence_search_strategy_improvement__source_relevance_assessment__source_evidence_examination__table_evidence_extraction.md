## CONTRACT MISFITS

- new field: table_evidence_extraction scope (assignment; the old episode took the Store scope from its request)
- new field: table_evidence_extraction received_record_refs (assignment, record_refs; the old episode read context.received_record_refs). The parent must name the source, its artifact, the sources it derives from, the proposed annotation and its hypothesis's subjects, the scope's subjects (credit reads `records.roots` and `reference_subset`), and, for a lead, the lead's reference subject (decision T5: a record passed does not bring the records it names).
- new field: table_evidence_extraction finding (return; the old episode returned the parent-written form): the typed `FINDING_FORM` (`written`, `interpretation`, `source_claim`, `source_subject`, `readings`, `qualification`, `assessment_findings` (the committed assessments' typed `investigation_finding`), `committed_record_refs`, `graded_sheet_refs`) plus a `report` tool for the model's closing text. The committed records and saved sheets are returned in its `record_refs` fields; the parent also needs every record those name.
- The A108 sheet repositories and the coupled grader cannot save a sheet until the library is carried (see blocked), so no accepted interpretation is credited before its sheet exists and, today, none is accepted. `credit.py` does not itself check that a sheet exists (the old credit formula is kept unchanged); the coupling is the single transaction of `literature_required_grading.execute` inside the `reason` tool.
- `validate_form_not_built:a108` (see unplaced): README 7a says the carried episode writes its own `validate_form` for A108; the job says to write none and borrow none and to raise. The job was followed. `final_to_parent` therefore always raises until the validator exists, unless `NotImplementedError` for a selected unbuilt field comes first.
- The old selection was `anyOf [table, window]`; a RecordForm has one field set, so `selection` is one record whose table-only (`sheet_key`, `header_row`, `where`) and window-only (`representation`) fields are optional, and `read_from_parent` requires the fields of the shape the selection is. Old null `header_row` / `where` / `where.column` are omitted fields (the form has no null).
- Tool names cannot contain dots: library names (`source.read`, ...) are carried as `source_read`, ... (`LIBRARY_NAMES`, `POPULATION_NAMES` in `task.py`). The `reason` tool's arguments keep the old `kind: 'reason'` property of the required-grading action schema.
- `action` wraps tool arguments in an envelope `{'arguments', 'scope', 'page_source_ref', 'selection', 'assignment', 'task', 'proposed_annotation_ref'}` so tools (handed no summary) apply the page-source restriction, the sheet_key rule and build the library context.
- `LiteratureContext` (task.py, private copy of the library's context dataclass of A105/A106/A107, which A108 does not have) is the object the library repositories and `literature_required_grading.execute` read (`run_id`, `episode_id`, `scope`, `assignment`, `received_record_refs`, `dataclasses.replace`).
- Settings read: `cost`, `parameters` (yield_estimator.py), `tool_registry` (the `ToolRegistry` keyword arguments: `clients`, `job_limits`, optional `native_statistics`, `local_resources`, executables), optional `knowledge_library_directory`.
- The old `yield_settings` of the task (kind, cutoff, uncertainty_alpha, filled from the owner's yield bindings) are the episode settings now; the old no-private-binding case (`None`) is not carried: the controller is accumulation for verified_source_leads and completion (target `credit_unit`) otherwise.
- completion credit may pass its target: not expected; assessment and screening count at most one answer, and the target is `credit_unit`. (`credit.py` uses `max(covered, end)` only to merge screening intervals, not to limit credit.)
- Environment: the repository root has no `.git`; old code was read from `/home/chia/repos/gene_annotation_episode_disk`. The sibling A105/A106 table_evidence_extraction folders (same old code shape) were read as the shape of the shared pieces and copied privately (no import).
