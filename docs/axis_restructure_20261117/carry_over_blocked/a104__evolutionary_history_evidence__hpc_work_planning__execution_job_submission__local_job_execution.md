## Contract misfits
- Field names with a dot: the old fact sources `execution.masking_status`, `execution.masking_artifacts`, ..., `execution.blast_utility_status`, ... (21 names, always empty for a launch) cannot be fields of a `RecordForm` (field names are lowercase identifiers). They are not declared; the parent cannot select them.
- new field: local_job_execution record_refs (the records the job inputs name; the old code read them through the commissioning request and the launch request binding).
- new field: local_job_execution scientific_task (the old `services.scientific_parent_task`: `scientific_question`, `selected_tool_info`).
- new field: local_job_execution completion_target (the old code had a completion proof, not a number). It is derived inside `read_from_parent`, not an assignment field: the sum of the credits of every original `progress_requirements` entry. Consequence: the controller stops on its forecast or at the target, not at the verified completion alone (when requirements outside `completion_keys` stay unsatisfied the Episode goes on until its forecast no longer pays for a command).
- completion credit may pass its target: no (each requirement credit is at least zero and the target is their sum, so the practical credit, the sum of the satisfied ones, cannot pass it); the controller's `ValueError` is the failure if it ever did. `CompletionYieldController` also needs a cost below the target: a profile `cutoff` of at least the total requirement credit raises `completion_cutoff_must_be_below_target`.
- `ctx.settings` of this episode must hold `resources` (by resource id), `initial_information` (by resource id), `coordinator_workspace`, `launch_instructions_directory`, `tool_knowledge_directory` and `task_yield_profiles` (`{'launch_local:<request class>': {'cutoff', 'parameters'}}`, the old cutoff being the controller's cost).
- `job_access` must be supplied as a service factory (`SERVICES = ('job_access',)`); today none exists, so a run of this episode cannot link or run.
- Object-typed `execution_result_origin` (old value null for a launch) cannot be returned: a form has no null type; selecting it raises `NotImplementedError('no_null_form_type:execution_result_origin')`.
- The old `PracticalYieldEstimator` verified a completion proof; no controller input carries a proof (README 5 item 5): the proof is derived from the held receipts for the model and the report only.
- The old frozen closed credit has no counterpart: the system's closure credit (`completion['credit']`) is returned.
- A104 `validate_form(form, schema, resolver)` needs a JSON schema the parent no longer writes: `messages/final_to_parent.py::validate_form` builds a closed schema from the selected fields' old report schemas (`REPORT_SCHEMAS` and the library family sources) and resolves references against this episode's own receipts.
- The old tests: none existed for this episode (no tests folder at 97308b94c); `retired_tests/...local_job_execution.tsv` has only its header.
