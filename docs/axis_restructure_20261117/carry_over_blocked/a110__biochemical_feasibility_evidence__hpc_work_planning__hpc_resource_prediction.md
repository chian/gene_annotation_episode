## CONTRACT MISFITS

- new field: hpc_resource_prediction ledger_refs (`record_refs` of the assignment): the parent-owned HPC ledger (a SQLite file the sisters opened by path) is now the work table `hpc_evidence`; the parent names the commission and owner rows and every row the child reads. - new field: hpc_resource_prediction hpc_ledger_refs (required `record_refs` of the return form): the ledger rows this episode wrote, returned in custody. Also `hpc_result_refs` is now a `record_refs` field (held result Sources).
