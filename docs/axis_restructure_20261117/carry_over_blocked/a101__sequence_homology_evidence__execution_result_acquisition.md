The old source was read with `git -C /home/chia/repos/gene_annotation_episode_disk show 97308b94c:<path>` (26 files of the episode folder; the working tree is not a git repository). ## Contract misfits
- new field: execution_result_acquisition target (the old code read the target from the handoff record through the progress provider; the record kind is not defined, so the parent copies the `execution_target_v1` the handoff names into the assignment).
- new field: execution_result_acquisition acquired_record_unit (the old `acquired_record_unit` of the configuration; `credit(summary, records)` and `yield_controller` receive no settings, so the unit rides in the assignment).
- new field: execution_result_acquisition record_refs (the handoff and every record the selected native inputs name; the old `initial_references`).
- new field: execution_result_acquisition initial_result_refs (the earlier result acquisitions of this handoff the parent holds: the old `initial_known_record_refs` that were results; their artifacts are named in `record_refs`).
- new field: execution_result_acquisition scientific_task (the old `services.scientific_parent_task`: `scientific_question`, `selected_tool_info`).
- no completion target: the native byte family uses accumulation (unbounded selector) or bounded quality (finite selector), as the old estimators did. The bounded maximum is `acquired_record_unit`, not `acquired_record_unit * (1 - original fraction)`: the original fraction needs the initial results, which only held records give, and `yield_controller` is handed `parent_input` only. Credit counts only newly covered bytes, so it cannot pass the unit (never above the old maximum). The old exact-zero forecast when no uncredited requested bytes remain is not carried.
- completion credit may pass its target: not applicable (no completion controller is built; the typed and API families that used the completion proof raise `unplaced:<family>.credit_view` where their target would be set).
- the old tool names `execution.results.status|collect|read` have dots; tool names are lowercase identifiers: `execution_results_status`, `execution_results_collect`, `execution_results_read` (the descriptions give the old names). "Rename nothing" cannot be met for these three.
- 21 old fact sources have dotted names (`execution.masking_*`, `execution.blast_utility_*`) and cannot be declared in `RETURN_FORM` (`final_to_parent.NOT_DECLARABLE`): a parent cannot select them. Object-typed or nullable sources: a form has no null type, so `execution_result_origin` raises `NotImplementedError('no_null_form_type:execution_result_origin')` when selected and nothing is retained.
- `BLAST_GRADED_RETURN_SOURCE` (the typed BLAST grader return) and the AppService sources are not declared in `RETURN_FORM` (their modules are in no place now); the old `required_return_sources` is a parent selection.
- The old `validate_report` checked the report against the parent's JSON-Schema form. The parent writes no form now: `final_to_parent.validate_report` builds the closed schema of the selected fact fields from the library sources' own `report_schema` (the `finding` is the form's own and is admitted by the system) and calls the axis `validate_form` with a resolver over this episode's retained results and the handoff.
- The old frozen closed credit ("later reads return the original view") has no counterpart: the system's closure credit (`completion['credit']`) is returned. The old completion proof (`practical_completion_v1`, `supporting_receipt_sha256s`) is not a controller input (README 5 item 5): the completion is derived from the held results (`internal_summary._native_results_complete`) for the model and the report only.
- The returned `execution_handoff_refs` is the commissioned `handoff_ref` when held (the old `returnable_handoff` test is unplaced).
- `ctx.settings` of this episode must hold `log_window_bytes`, `launch_instructions_directory`, `tool_knowledge_directory`, `results_yield_profiles` (`{'native_unbounded_local'|'native_unbounded_hpc': {'cutoff', 'parameters'}}`) and `task_yield_profiles` (`{'results:native_finite_local'|'results:native_finite_hpc': {'cutoff', 'parameters'}}`), the old cutoff being the controller's cost. `job_access` must be supplied as a service factory (`SERVICES = ('job_access',)`); today none exists, so a real runner test of this episode cannot be written without a stand-in, which is forbidden; the tests cover the class, the folder, the forms, the assignment, the yield controller, the credit, the operations and the report.
- A wait that the parent commissions for an API target earns what the summary earns (nothing); no estimate or stop rule was added.
