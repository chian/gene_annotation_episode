- The old continuation was `BoundedYieldController(epoch, initial_credit, cutoff, remaining, ...)`. The intent record calls it "completion with a target"; README 7b maps the old bounded controller to bounded quality. Chosen: `BoundedQualityYieldController` with `maximum_credit` = `|permitted - received| * handoff_unit` (`cost` = the profile's cutoff). Credit cannot pass that maximum: a resource is credited only after this episode commissioned it, only permitted resources can be commissioned (`action` offers only those) and each counts once. (If the owner prefers completion, the target is the same value from `parent_input`; the credit formula is unchanged and does not pass it.)
- The old exact-zero estimator for "no uncredited request" (`no_remaining_requests`) is not carried (README 7b) and no bounded controller takes a maximum of 0: `yield_controller` raises `ValueError('launch_every_original_request_already_has_a_handoff')`.
