## CONTRACT MISFITS

- new field: source_relevance_assessment scope (assignment; the old episode took the Store scope from its request)
- new field: source_relevance_assessment received_record_refs (assignment, `record_refs`; the old episode read `context.received_record_refs`). The parent must name the search-result sources and their artifacts, since a pass carries only the records named. `question_context_refs` and `search_result_refs` are `record_refs` fields too (the old schema had them as reference lists checked in scope).
- new field: source_relevance_assessment gene_context_evidence (assignment, optional record; the old request message carried it)
- new field: source_relevance_assessment finding (return; the old episode returned the parent's requested form filled from the model's report update and had no fact sources). Own typed finding form: one judgement per source considered (`source_ref`, `merits_examination`, `reason`, optional `examination` with `source_claim`, `source_subject`, `qualification`, `target_correspondence`), written by the model with a new `report` tool. A103 is not an A105/A108 episode, so no saved subscoring sheet applies. The return has no selectable field (the old fact sources were empty); the commissioning parent (`evidence_search_strategy_improvement`) must read `credit` and `finding` only.
- new field: source_evidence_examination (child) commission fields. `msg_to_child` fills the child's declared `page_assignment_v1` fields (`version`, `source_ref`, `representation`, `artifact_ref`, `question_context_refs`, `prior_delivery_refs`, `scope`, `received_record_refs`, optional `gene_context_evidence`). `received_record_refs` is `[source_ref, artifact_ref]`, which this episode must hold (a held source it acquired by a tool counts). `ChildMessage.selection` is empty: the child declares no selectable field.
- `msg_to_child` arguments (new): `{'objective', 'source_ref', 'representation', 'artifact_ref', 'prior_delivery_refs'}`. The old commission carried a goal text and the selection the model made for the page. `action` rejects an answer whose source, artifact or prior deliveries this episode does not hold (the provisional held-record check on a model answer, never a check of a commission).
- Tool names cannot contain dots: library names (`source.read`, `public.pmc.files`, ...) are carried as `source_read`, `public_pmc_files`, ... (`ACCESS`, `ACQUISITION` in `task.py`). `tool_catalog` is a new first lookup tool (the old services tool catalogue).
- Changed from the old code: the old summary built the source custody from `assignment.get('source_refs', [])`, a field the assignment does not have (it names `search_result_refs`), so it was always empty. The new `internal_summary` builds it from `search_result_refs`: the prompt's "Callable supplied Sources" needs it.
- Children return only credit and finding (no `record_refs`), so the child's work does not reach this episode's held records. `credit.py` is the old axis credit over the records this Episode holds (`A103ContextCredit`); the old credit was also read from the shared axis view after a child return, which the new contract has no channel for. Child credits are in the child reports of the summary; nothing in `credit.py` adds them.
- `final_to_parent` raises `a103_source_relevance_finding_not_reported` when the controller stops the Episode before any judgement was reported (no fallback value).
- Settings the episode reads: `cost` and `parameters` (yield controller), optional `tool_registry`, `knowledge_library_directory`, `launch_instruction_directory`.
- The old controller was the old runner's default (None); the bounded-quality controller is chosen because `A103ContextCredit` declares yield_method bounded_quality with native_score_maximum (README 7b).
- `A103ContextCredit` is called with no proposed annotation (this assignment names none).
- Old tests: this episode had none at 97308b94c and the working tree held none, so the retired-tests file has only its header.
