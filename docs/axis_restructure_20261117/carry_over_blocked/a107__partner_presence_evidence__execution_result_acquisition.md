## Contract misfits
- new field: execution_result_acquisition target (the execution target the handoff names; old `job_progress_provider.targets.read_target(handoff_ref)`).
- new field: execution_result_acquisition acquired_record_unit (old configuration value; positive and finite).
- new field: execution_result_acquisition record_refs (every record the selected native inputs name; old `initial_references`).
- new field: execution_result_acquisition initial_result_refs (earlier result acquisitions of this handoff the parent holds; their artifacts also in record_refs).
- new field: execution_result_acquisition scientific_task (old `services.scientific_parent_task`: `scientific_question`, `selected_tool_info`).
- completion credit may pass its target: not applicable. No completion controller is built: the old completion-proof estimators (`results:api_*`, `results:typed_*`, `PracticalYieldEstimator(verify_completion)`) belong to families that read_from_parent refuses; the placed families use accumulation (unbounded requested length) or bounded quality (finite).
- The bounded-quality maximum is the whole `acquired_record_unit`, not the old `acquired_record_unit * (1 - original fraction)`: the original fraction needs the initial results, which only held records give and `yield_controller(initial_credit, settings, parent_input)` is handed none. Credit counts only newly covered bytes, so it cannot pass the unit.
- The old exact-zero forecast when no uncredited requested bytes remain (`finite_result_selector_exhaustion_v1`) and the endpoint-proof forecast are not controller inputs and are not carried.
- Dotted old fact-source names (21: `execution.masking_*`, `execution.blast_utility_*`) are not lowercase identifiers: "rename nothing" cannot be met; not declared (`NOT_DECLARABLE`), so a parent cannot select them.
- No null form type: `execution_result_origin` (null when nothing is retained) cannot be returned empty; selecting it without a retained window raises `NotImplementedError('no_null_form_type:execution_result_origin')`.
- The old `required_return_sources` (`('execution_result_refs',)` when the parent is `partner_presence_evidence` and an annotation task is required) is now the parent's selection of the selectable field `execution_result_refs` in its `msg_to_child`.
- The old `validate_report` body is kept in `final_to_parent.validate_report` (A107 `validate_form` with a resolver over this episode's retained results, and the fact-equality rule); the per-family `validate_received_report` calls (masking, utility, NMF, RNA, Infernal, UniProt, Rfam) belong to the unplaced classes.
- The result `finding` is the episode's own typed acquisition finding (completeness, acquisitions, invalid acquisitions, windows, bytes, failures). A107 is not an A105/A108 evidence episode: no investigation_finding and no subscoring sheet are involved.
- A selected tool that executed and returned an invalid outcome still returns it as its outcome (`_outcome(code=...)`) and enters the iterator with credit unchanged; a rejected model answer creates no unit.
- Family detection for RNA structure comparison (by selector version), RNA structure, standard BLAST database, BLAST database, HMMER, Infernal (by the `requested_job` key) uses no `is_*_target` predicate: none of them exists in the library for these families.
- `ctx.settings` must hold `log_window_bytes`, `launch_instructions_directory`, `tool_knowledge_directory`, `results_yield_profiles` (`native_unbounded_<local|hpc>`: `{'cutoff', 'parameters'}`) and `task_yield_profiles` (`results:native_finite_<local|hpc>`); the old A107 continuation `{'cutoff', 'parameters'}` per binding path is replaced by those profiles.
- `job_access` must be supplied as a service factory (`SERVICES = ('job_access',)`); none exists, so no real runner test of a unit can be written without a stand-in (forbidden). The test checks the class definition, the folder, the imports, the assignment, the credit and the return form only.
