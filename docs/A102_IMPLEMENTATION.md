# A102 structural-homology implementation

`A102Subtree` commissions the existing recursive `scientific_process` role with
published A102 instructions. `create_a102_workflow` installs
`A102StructuralCredit` for the parent; frozen A102 child selections select the
same scorer by code. `A102ServiceFactory` binds science, literature, launch,
local execution, monitor and results when supplied the actual
`A102ToolRegistry`. No other evidence axis is admitted below A102.

The structural registry adds explicit model binding, US-align, bounded Foldseek
discovery, feature geometry, functional contrast, reported comparisons and a
missing-model request. Original target coordinates survive region/product
mapping. The native RMSD profile uses symmetric extent once and a 2 Å kernel;
required functional geometry uses 1 Å. Functional support and contrast are
separate from controller B. Unknown features do not erase native credit.

Qualified native publication attaches the numerical grader and a narrow
`a102_scoring` receipt atomically. A descriptor or auxiliary artifact does not
grant numerical or coordinate access. The existing explicit-map CA producer
also publishes an A102 grade when it returns the actual saved-sheet grant and
received bound target/reference maps are available. `episode.credit` only
observes already graded records. Default typed returns deliver actual records;
parents recompute their own scope instead of adding child scalars.

Shared information needs, availability and dispositions use immutable Sources
and public participant handles, with private ownership indexes in the Store.
Received A102 records automatically publish availability. Publication metadata
does not admit referenced evidence. The ancestor selects an explicit read or
delivery and chooses any sibling investigation. Older metadata is pageable.
Restricted annotation roots have only these coordination tools in addition to
their commissioning interface.

All native work uses the shared host admission gate and durable native handles.
A102 defaults to one CPU, 2 GiB RAM and 1 GiB scratch per job, bounded by the
caller policy. Foldseek searches at most 32 explicitly received models in
exhaustive global TMalign mode, avoiding a large local k-mer index. A busy retry
uses the same context/operands/software-bound work directory and original
prepared handle, even when the next action has another runtime operation ID.
Launch handoffs deliver metadata; results collection delivers scientific grades.

Foldseek 10's printed transform maps reference to query and is rounded to
0.001 per entry. The adapter inverts that reported transform algebraically,
retains its precision bound and calculates pair distances without another
alignment or refit. Its printed RMSD is retained separately when it does not
reproduce those geometry cells. Native TM values retain their normalizations;
they do not replace the default RMSD profile.

Install the pinned small native tools under a run directory with
`python -m gene_annotation_episode.a102_native_setup --run-directory runs/a102-tools`.
Use the resulting executable paths when constructing `A102ToolRegistry`.
Run native checks with `A102_USALIGN` and `A102_FOLDSEEK` set to those paths,
and put pytest temporary/cache/log output under that run directory. Required
real coordinates, metadata and native replay fixtures are under
`tests/fixtures/a102`; native replay and fresh native execution are labeled
separately. `examples/a102_structural_investigation.py` runs fresh configured
model decisions with retained real inputs and a declared finite validation
budget; it supplies no expected function or score.

Validation includes eleven fresh native execution cases with scripted episode
choices, and four separate configured-model investigations: TPI, LacY, AtpG and
MJ0226. Each model investigation selects its scientific actions; the host
supplies one root commission and the sequence/model-file leads. Owner and
receiving-parent credit match, and the native action receives credit before
any credit-inspection call or subsequent reasoning. Real-case functional
feature and contrast outputs remain unknown where their grounded inputs are
absent. This finite validation budget does not establish optimal stopping.

Tool-specific attachment policies now run automatically at publication/receipt,
before the controller projection. `structure.bind` records model/entity
correspondence. Direct alignment/discovery and saved CA comparisons preserve
their native geometry. `structure.reference_align` keeps the actual Y/Z
subjects and qualifies its use for X with the exact received X/Y map and local
distance. Missing links create parent-facing needs; arrival of the link
regrades retained cells without another alignment. Excluded controls and
ambiguous primary model variants do not acquire credit through transfer.

`structure.reference_traits` distinguishes entity attribution from attribution
of residues, regions, motifs, chemical-role classes, shapes and discontinuous
sites. Its outputs include mapped target feature records and observations on
those subparts. The raw trait match, correspondence support, local distance,
unknown cells and original required denominator remain explicit. Conflicting
maps affect only their sites. Region-query positions are lifted to original
coordinates. Shape can be measured from target coordinates using composed
native transforms, or explicitly labeled as inferred reference-shape support.
No site fit or whole-function assertion is introduced.

`structure.feature_geometry` has per-feature local correspondence and construct
checks; `structure.interface_geometry` checks each required component and its
contact sites while preserving assembly/partner-presence limitations. Reported
comparisons receive subject/scope/distance checks and retain `native_B=null`.
Contrast panels consume qualified feature values. Each use has its own sheet;
there is no whole-A102 multiplier. Local trait/functional sheets remain separate
from controller fold correspondence and require explicit feature-to-whole
interpretation. The report vocabulary includes `local_trait_evidence` for this.

`examples/tool_attribution_investigation.py` demonstrates real reference-only
LacY geometry followed by a late real phmmer result. Its local trait definitions
are engineering probes, not characterized catalytic-site claims. It uses
scripted choices and a finite validation budget, with all execution output
under the requested `runs/` directory.

AlphaFold DB access retrieves existing models. Novel folding and external DALI
execution require an explicitly configured remote/API/HPC backend; the missing
model branch publishes a parent-facing need and creates no structural credit.
