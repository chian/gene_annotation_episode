**a104_fixture_request_without_transport_proof** (66). All 66 cases of `a104/.../test_proteome_saved_host.py` fail on `bvbrc_appservice_custody_parent_selection_invalid`, and its inner error is always `original_assignment_transport_mismatch`. The fixture saves the parent decision request as `{'context': {}, 'schema': ...}` (`R/a104/tests/proteome_partner/commissioned_records_fixture.py:68`). That request has no `assignment_transport` proof and no `decision_exchange_v1` marker, so `R/a104/runtime.py:318-319` rejects it. The product writer adds the proof (`R/a104/provider.py:55-58`). fp5.md names the symptom; the cause is new. Changes scientific behaviour: no. Fix site: the fixture, which should write the transport proof the product writes.

**role_only_binding_lookup** (55). This is the known C07 defect. Each test's symptom fits this: 0 actions, empty `provider.contexts`, `DID NOT RAISE KeyboardInterrupt`, `IndexError`, or `ended_by == 'source_failed'`. Every one of these tests uses the default bindings, which I checked, and the control test in the same file that passes `episode_binding_factories=()` passes. Changes scientific behaviour: no. Fix site: `R/composition_information.py:110`, using the path-aware `for_child(source.path, name)`.
